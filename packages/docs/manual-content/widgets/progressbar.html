Что такое ProgressBar?

Представьте: ваша игра загружает большой уровень, а на экране — тишина. Игрок не понимает: программа думает или зависла? Спасает заполняющаяся полоска — она честно показывает, сколько уже сделано и сколько осталось. Та же полоска пригодится и для шкалы здоровья героя.

В Idyllium такая полоска называется gui.ProgressBar. Вот как выглядит простейший прогрессбар, заполненный на 24%:

24%
📊 ProgressBar наглядно показывает процент выполнения. Здесь — 24%.

Стандартные свойства виджетов

Как и все виджеты в Idyllium, ProgressBar имеет стандартный набор свойств для позиционирования:

  • x — расстояние от левого края окна (в пикселях)
  • y — расстояние от верхнего края окна (в пикселях)
  • width — ширина виджета
  • height — высота виджета

Эти свойства есть у каждого виджета — от кнопки до выпадающего списка.

А своё, особенное, у полоски — orientation: по умолчанию она горизонтальная ("horizontal"), но бывает и вертикальная, заполняющаяся снизу вверх — как столбики эквалайзера в музыкальном плеере или шкала опыта рядом с героем. Поменяйте местами ширину и высоту: вертикальной полоске нужна маленькая width и большая height.

65%
65%
📊 Одно и то же значение, две ориентации: "horizontal" растёт слева направо, "vertical" — снизу вверх.

Свойство value — уровень заполнения

Главное свойство прогрессбара — value. Оно имеет тип int. Пока вы не трогали другие настройки, value — это просто проценты: от 0 (пусто) до 100 (полно).

Три прогрессбара с разными значениями:

0%
50%
100%
📊 value = 0 — пусто, value = 50 — половина, value = 100 — полностью заполнено.

Обратите внимание: процент заполнения отображается прямо на полоске — дополнительный лейбл не нужен.

Своя шкала: min и max

Проценты — это только случай по умолчанию. На самом деле у прогрессбара есть ещё два свойства: min (начало шкалы, обычно 0) и max (конец шкалы, обычно 100). Значение value всегда живёт между ними.

Пусть у героя игры 200 очков здоровья. Тогда удобно задать шкалу от 0 до 200 и хранить в value настоящее здоровье, а не проценты:

75%
❤️ 150 очков из 200 — это три четверти шкалы, поэтому полоска заполнена на 75%. Надпись на полоске всегда показывает проценты.

Соберём все свойства прогрессбара в одну таблицу:

СвойствоТипЧто означает
valueintуровень заполнения; всегда между min и max
minintначало шкалы (по умолчанию 0)
maxintконец шкалы (по умолчанию 100)
x, yintположение внутри окна
width, heightintразмеры полоски

Пока min = 0 и max = 100, значение value читается как обычные проценты.

Динамическое изменение значения

Как и любые другие свойства, value можно менять во время работы программы. Вот пример, где кнопка устанавливает прогрессбару случайное значение:

0%
🎲 Каждое нажатие кнопки генерирует случайное число от 0 до 100 и обновляет прогрессбар.

Точно так же шкала здоровья будет обновляться после каждого удара, а полоска загрузки — расти по мере скачивания файла.
