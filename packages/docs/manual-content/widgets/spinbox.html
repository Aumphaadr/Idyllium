Сколько игроков будет в игре?

Представьте: вы делаете игру, и в лобби нужно выбрать количество игроков. Дать обычное поле для текста — рискованно: кто-нибудь обязательно впишет туда «восемь», «-3» или «котик». А нужно строгое целое число, да ещё и в разумных пределах.

Для таких случаев в gui есть gui.SpinBox — поле для целых чисел со встроенными кнопками ▲ и ▼. Ввести в него «котика» не получится при всём желании. А для дробных чисел у SpinBox есть брат — gui.FloatSpinBox, до него дойдём чуть позже.

Основные свойства SpinBox

Наш счётчик уже ведёт себя прилично, хотя мы ничего ему не настраивали. Это работа значений по умолчанию: свежий SpinBox рождается с min = 0, max = 100 и step = 1 — стрелки не уведут его ни в минус, ни за сотню. Но диапазон «от 0 до 100» подходит не каждой задаче, поэтому все границы настраиваются:

  • value — текущее значение (int); по умолчанию 0
  • min — минимальное допустимое значение; по умолчанию 0
  • max — максимальное допустимое значение; по умолчанию 100
  • step — шаг изменения при нажатии на стрелки; по умолчанию 1

Границы сторожат все способы ввода: стрелки и колесо мыши не докрутят до 101, а число, набранное с клавиатуры, зажмётся в диапазон в момент подтверждения — когда поле теряет фокус или нажат Enter. Наберите 999 при max = 100 — в поле и в value окажется 100. Стереть всё и уйти тоже безопасно: пустое поле откатится к последнему значению.

FloatSpinBox — для дробных чисел

Количество игроков дробным не бывает. А вот, например, множитель скорости игры — запросто: 0.5 — вдвое медленнее, 1.0 — обычная скорость. Для таких значений и нужен gui.FloatSpinBox: он работает так же, как SpinBox, но хранит дробные числа (float):

Событие on_change

Вернёмся в лобби. Когда пользователь меняет значение (через стрелки, клавиатуру или прямой ввод), срабатывает событие on_change. Пусть подпись рядом всегда показывает, сколько игроков выбрано:

Типичная ошибка: дробное число в SpinBox

Рано или поздно каждый пробует записать в обычный SpinBox дробное число:

main.idyl:5:18: compile error: cannot assign 'float' value to 'int' variable

Свойство value у SpinBox — типа int, а 0.5 — это float. Компилятор такое не пропустит — и правильно сделает: половины игрока не бывает.

Если значение должно быть дробным — это не повод воевать с компилятором. Просто возьмите gui.FloatSpinBox: у него value, min, max и step как раз типа float.
