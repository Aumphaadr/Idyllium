Урок-факультатив: витрины данных

Этот урок — по желанию: четыре виджета, которые понадобятся не каждой программе, но целиком меняют жанр тех, которым понадобятся. Вы уже умеете читать данные откуда угодно — из массивов, файлов, JSON и баз. А показывали их до сих пор консолью да лейблами. Пора честно: таблицу — таблицей, сравнение — столбиками, доли — пирогом, изменение — линией.

gui.Table — таблица

Колонки задаются один раз, строки добавляются по одной. Всё — строки: числа переводите через to_string(), как в лейблах:

ИмяКлассУровень
Мирамаг12
Кайвоин9
Никажрица21
📋 Полосатость, рамки и прокрутка (когда строк много) — сами собой, из темы окна.

Ошибиться в количестве значений не получится — таблица сторожит: Table.add_row() expects 3 values (one per column), got 2. Для «живых» таблиц есть set_cell(строка, колонка, текст), remove_row(строка) и clear(); свойство row_count знает, сколько строк сейчас.

Таблица умеет отвечать на клик: свойство selected_row хранит номер выбранной строки (−1 — ничего), а событие on_select срабатывает при выборе:

ИмяУровень
Мира12
Кай9
Выбрана строка №2
🖱️ Клик подсвечивает строку и зовёт on_select — как on_click у кнопки, только с номером в придачу.

gui.BarChart — столбики сравнивают

📊 Кто богаче — видно без единого числа (но числа над столбиками есть: show_values, по умолчанию включено).

Цвет столбиков — один на всех (bar_color; не задали — акцентный цвет темы): сравнение честно, когда столбики отличаются только высотой. Обновлять данные на ходу — set_value("Мира", 900); шкалу можно зафиксировать парой min_value/max_value, знакомой по слайдеру, — а можно не трогать, и она подстроится сама.

gui.PieChart — пирог делит целое

🥧 Проценты пирог считает сам — вы даёте «сколько кого», доли — его забота. Цвета долек тоже автоматические.

gui.LineChart — линия наблюдает

Столбики сравнивают «кто больше сейчас», линия отвечает на другой вопрос — «как менялось». Точки добавляются по одной и идут слева направо. Главный напарник линии — таймер:

📈 max_points = 60 превращает график в бегущую ленту: новая точка приходит — самая старая уезжает влево. Осциллограф из урока про таймер готов.

Витрина + данные = дашборд

Настоящая сила этих виджетов — в связке с разделами про данные, которые ждут вас впереди (JSON и SQLite) или уже пройдены (файлы, массивы). Прочитал — показал: цикл по данным перекладывает строки в add_row, суммы — в add_value. Одно окно с таблицей и парой графиков по одной базе называется взрослым словом дашборд — приборная панель. После раздела SQLite соберите свой: это законный финальный проект всего курса виджетов.

ВиджетДанные кладут такОсобое

Общие правила у всех четырёх прежние: координаты и размеры, visible/enabled, IdySS-наклейки, clear() — начать заново.
