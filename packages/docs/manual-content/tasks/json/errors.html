Блок 6. Со звёздочкой

Задание 16 ⭐. Обстрел читалки

Раздатка: целый camp_save.json и ваша задача навылет — написать неубиваемую читалку лагеря: название, день, дежурный (может быть null!), и чтобы никакая порча файла её не роняла. Работа в три шага, как у взрослых испытателей:

1. Тест-план обстрела: список порч файла по каталогу книги (хвостовая запятая, комментарий, ключ без кавычек, не тот тип, пропавший ключ, null там, где ждали строку...) — не меньше шести, с прогнозом: какое сообщение выдал бы голый parse на каждой.

2. Обстрел хрупкой версии: читалка без проверок + все порчи по очереди — записать фактические сообщения (сверить с прогнозами!).

3. Броня: is_valid на входе + has/is_*-лесенки на каждом чтении; повторный обстрел — ни одного падения, на каждую порчу — осмысленная строка.

Сдача — сам тест-план с двумя колонками прогонов («до брони» / «после») и живой обстрел одной порчей по выбору преподавателя.
