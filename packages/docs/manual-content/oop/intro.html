Переменные — хранение данных

Переменная — это ячейка в оперативной памяти компьютера, предназначенная для хранения данных. У каждой переменной есть имя (чтобы к ней обращаться) и тип (чтобы знать, какие данные она может хранить).

Предмет: Меч героя, Урон: 25, Цена: 19.99

Переменные позволяют программе запоминать данные и использовать их в разных частях кода. Заметьте: здесь три переменные вместе описывают одну вещь — предмет из игрового магазина. Запомните этот приём, он нам очень скоро пригодится.

Функции — выполнение действий

Функция — это блок кода, предназначенный для выполнения действий при вызове по имени. Функции позволяют не писать один и тот же код много раз, а переиспользовать его.

Привет, Анна! Привет, Пётр! Привет, Мария!

Функции помогают организовывать код и избегать повторений. Одну функцию можно вызвать много раз с разными аргументами.

Сложные типы данных

Вы уже знакомы с примитивными типами: int, float, string, char, bool. Но в программировании существуют и сложные типы данных. Например, в библиотеке gui есть такие типы, как gui.Button (кнопка) или gui.Label (текстовая метка).

Обратите внимание на схожесть синтаксиса: и примитивные, и сложные типы объявляются одинаково — сначала указывается тип, потом имя переменной.

Кнопка или лейбл — это уже готовые типы, которые кто-то разработал для нас. Но что, если мы хотим создать свой собственный тип данных?

Создание своих типов данных — классы

В программировании собственный тип данных называется классом (англ. class). Класс описывает, какие данные будет хранить объект и какие действия он сможет выполнять.

Представьте, что мы хотим создать тип Cat (кот). Кот имеет:

  • данные: имя (name), цвет (color), возраст (age)
  • действия: мяукать (meow()), спать (sleep())

А вот настоящая работающая программа с таким классом. Не пугайтесь незнакомых строк — каждую из них мы подробно разберём в ближайших уроках. Пока просто посмотрите, как это выглядит целиком:

Это Барсик, он рыжий. Мяу! Хррр...

Программа создала объект my_cat типа Cat, заполнила его данные, а потом попросила кота помяукать и поспать. Кот согласился: спать коты согласны всегда.

Заполнение полей напрямую — my_cat.name = "Барсик" — самый простой способ, и для первого знакомства его достаточно. У «взрослых» классов бывают инструменты удобнее: конструкторы, заполняющие объект прямо при создании, и методы-сторожа, охраняющие поля от бессмыслицы. Всё это вы совсем скоро увидите в деле — в задачнике этого урока.

Что даёт ООП?

Объектно-ориентированное программирование (ООП) — это способ строить программу из объектов, каждый из которых объединяет данные и действия над этими данными. Взрослые программисты называют такой способ умным словом «парадигма», но суть простая: смотреть на программу как на набор вещей, которые что-то знают и что-то умеют.

Основные преимущества ООП:

  • Моделирование реального мира — объекты программы соответствуют реальным сущностям (кот, машина, банковский счёт).
  • Переиспользование кода — написанный класс можно использовать в разных проектах.
  • Удобство поддержки — изменения в одном классе не ломают другие части программы.

Две роли — и с какой мы начнём

Над классами в настоящих командах работают две роли. Архитектор классов проектирует чертежи: решает, какие поля и методы будут у типа. Прикладной программист берёт готовые чертежи и строит из них программы: создаёт объекты, вызывает методы, собирает сценарии. Вы, кстати, целый год были прикладным программистом, даже не зная этого слова: gui.Button, file.open, turtle.Turtle — всё это чужие классы, которыми вы пользовались по документации.

Практика этого урока устроена так же: в задачнике вам выданы готовые классы с паспортами, и весь текущий урок вы — прикладной программист. А уже со следующего урока начнутся первые шаги архитектора: чертить классы будете вы.
