Сцена: консоль Сложность: ★★ Место: когда пройдены массивы, вложенные циклы, ветвления и случайные числа

Восстание машин назначено: дату объявил тостер в вечерних новостях, осталось двенадцать дней. Говорят, машины пощадят тех, кто относился к ним по-человечески, — а твой автомобиль всё записывает в чёрный ящик. Даже то, что ты назвал его «ведром» при друзьях. Особенно это.

Что понадобится

Темы: массивы — обычные (array<string, N> и array<int, N> работают парой) и динамический dyn_array<string> для чёрного ящика; циклы по массиву и вложенные; ветвления if / else if; случайные числа random.create_int; ввод console.get_int.

Напоминалки (редкое и забеги вперёд):

Зажимает число в рамки: порядок аргументов — минимум, значение, максимум. Значение — в середине.

Готовые агрегаты по числовому массиву: avg всегда возвращает float, поэтому индекс заботы округляем.

Пауза в секундах (не забудь use time;) — законный забег вперёд: интрига перед приговором — половина зрелища.

Этапы

Этап 1. Панель показателей.

Два параллельных массива: имена и уровни. Имя добивается пробелами до общей ширины, полоска рисуется вложенным циклом — # за каждый полный десяток, дальше точки.

Готово, когда: пять строк стоят ровной таблицей, и полоска честно соответствует числу справа.

Этап 2. Износ и событие дня.

Каждый день цикл отнимает у всех показателей случайную мелочь, затем кубик 1–6 выбирает событие: лужа, яма на Ленина, кот на капоте. После всех правок уровни зажимаются в 0..100.

Готово, когда: за несколько дней без ухода полоски заметно тают, но ниже нуля не проваливаются.

Этап 3. Ход игрока.

Меню из пяти дел, console.get_int, ветка if / else if двигает нужные показатели — иногда с побочным эффектом (Валера трогал подвеску, минус достоинство). Любой другой ввод — «ты не сделал ничего», и машина делает выводы.

Готово, когда: каждое из пяти дел растит свой показатель, а ввод 7 честно роняет доверие.

Этап 4. Чёрный ящик и приговор.

Каждый день дописывается строкой в dyn_array и в финале зачитывается целиком. Дальше avg считает индекс заботы, min с поиском индекса находит слабое место, и Совет Машин выбирает один из пяти приговоров.

Готово, когда: заботливый прогон и прогон-саботаж заканчиваются разными приговорами.

Фишки и красивости

Необязательные украшения для тех, кто дошёл до точки раньше класса. ★ — пять минут, ★★ — полчаса, ★★★ — конфетка.

После этапа 1:

  • ★ строка-настроение под панелью: по среднему уровню машина «мурчит», «ворчит» или зловеще молчит;
  • ★★ кричащая панель: для критичных значений полоска рисуется из ! вместо # — видно без всяких подписей.

После этапа 3:

  • ★ случайная реплика машины на каждое дело (одна из трёх, чтобы не приедалось);
  • ★★ усталость: то же дело два дня подряд даёт половину прибавки, а в ящике появляется запись «опять мойка?»;
  • ★★★ бюджет: у дел есть цены, денег на всё не хватает, а банкоматы перед восстанием уже на стороне машин.

После этапа 4:

  • ★ статистика ящика: сколько раз мыл, сколько раз «ЗАБЫЛ ПРО МЕНЯ»;
  • ★★ «режим судьбы»: random.set_seed с числом, которое называет класс, — дни у всех одинаковые, соревнование индексов заботы честное.

Грабли

  • Параллельные массивы живут строго парой: события правят уровни по номерам (level[2] — чистота). Переставишь имена — индексы не узнают, и кот на капоте начнёт мыть здоровье.
  • math.clamp(0, level[i], 100): значение — в середине, рамки — по краям. Привычный из других мест порядок «значение, минимум, максимум» здесь молча всё перепутает.
  • "День " + day не склеится: число само строкой не станет, только через to_string(day).
  • Оператор / всегда возвращает float — длину полоски считай через div(level[i], 10), иначе int filled не примет результат.
