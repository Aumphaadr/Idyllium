Сцена: окна Сложность: ★★★ Место: когда пройдены таймеры, массивы виджетов и обработчики из циклов

Мини-игра взлома по мотивам Breach Protocol из Cyberpunk 2077, с настоящими правилами оригинала: первый код берётся из верхней строки, каждый следующий — из столбца или строки последней ячейки попеременно, использованное блокируется, цель собирается в буфер подряд, время тикает. Матрица 5×5 из живых кнопок — и 25 обработчиков, каждый из которых помнит координаты своего рождения.

Как это выглядит

Поле готово к взлому — и протокол взломан по маршруту строка→столбец→строка:

Что происходит:

  1. Поле 5×5 заполняется кодами: сначала мусором, потом в него незаметно вписывается гарантированный путь к цели.
  2. Кликается только допустимое: активная строка или столбец подсвечены, остальные ячейки гаснут — правила игры видны прямо в интерфейсе.
  3. Каждый клик кладёт код в буфер (6 ячеек) и блокирует ячейку; чередование строка/столбец переключается.
  4. Цель подряд в буфере — победа; кончились ходы или время — «Netwatch вас вычислил». «Новая попытка» строит новое поле.

Что понадобится

Темы: матрица кнопок array<array<gui.Button, 5>, 5>, обработчики, навешанные двойным циклом (с захватом координат!), параллельные матрицы данных, таймер с прогрессбаром, функции с общим состоянием, contains для проверки буфера, стили подсветки.

Напоминалка:

Каждый обработчик из цикла запоминает СВОИ координаты — 25 кнопок, одна функция, и никто не путает себя с соседом. Это кульминация «счётчик цикла — тоже переменная» всего курса.

Этапы

Этап 1. Матрица.

Поле 5×5 кнопок двойным циклом, случайные коды, клик печатает координаты ячейки.

Готово, когда: любая ячейка честно называет своё (строка, столбец).

Этап 2. Правила движения.

Чередование строка/столбец, блокировка использованных, паттерн «включены только допустимые» с подсветкой.

Готово, когда: по полю можно ходить только по правилам, и допустимое видно глазами.

Этап 3. Буфер и цель.

Сбор кодов в буфер, проверка победы, поражение по исчерпанию ходов.

Готово, когда: игра выигрывается и проигрывается — а победа не срабатывает на случайном совпадении с чужим куском буфера (разделители!).

Этап 4. Гарантированный путь.

Генератор: мусор — потом путь поверх него, формой подчинённый чередованию. Главный алгоритмический разговор проекта: почему путь вписывается после мусора и почему он всегда проходим.

Готово, когда: десять новых полей подряд — и каждое взламываемо (проверьте честно!).

Этап 5. Время и стиль.

Таймер с прогрессбаром, «Новая попытка», тёмная тема — терминал взломщика обязан выглядеть как терминал взломщика.

Готово, когда: проигрыш по времени работает, а окно не стыдно показать фанату оригинала.

Переодень сюжет

Механика общая, слова и темы — твои: сейф музея с кодовыми пластинами, дешифровка древней плиты, распутывание проводки новогодней гирлянды (чередование — «по горизонтали/по вертикали»).

Фишки и красивости

★ — пять минут, ★★ — полчаса, ★★★ — конфетка.

После этапа 3: ★ звуковой стиль сообщений («ACCESS GRANTED»); ★★ счёт очков за скорость и оставшиеся ходы.

После этапа 5: ★★ вторая цель с отдельной наградой (как в оригинале — можно собрать обе!); ★★★ уровни: размер поля и длина цели растут с победами.

Грабли

  • Путь может случайно продублироваться мусором — это не баг: лишние совпадения только помогают игроку. А вот победа от склейки кодов без разделителей — баг: «BD1C» в буфере не равен цели «BD 1C».
  • После КАЖДОГО изменения состояния — пересчёт допустимых ячеек. Забыли один вызов — интерфейс врёт, и игрок кликает в «мёртвые» кнопки.
  • Чередование легко перепутать местами. Плакат «строка → столбец → строка» на видном месте экономит полчаса отладки.
