Задание 21 ⭐. Раскрась ответ

Помните цветной вывод через \e[..m? Соедините его с условием. Программа спрашивает «Сколько будет 6 × 7?», принимает ответ и красит реакцию: верно — зелёным, неверно — красным.

Задание 22 ⭐. Тайна одной чёрточки

Вы уже ловили ошибку из задания 3: Idyllium не даёт написать if (code = 7766). Разберёмся, почему он так строг.

== — вопрос «равны?», а = — приказ «стань равным». Перепутать их — классическая ловушка. И вот как с ней обходятся разные языки, если написать if (x = 5):

  • Idyllium — отказывается компилировать: «так нельзя». Ошибку видно сразу.
  • Python — тоже запрещает, ругается похоже.
  • C++ и JavaScript — молча соглашаются! Присваивают x пятёрку, считают её «истиной» и всегда заходят в if. Программа работает не так, как задумано, а ошибки не видно — её потом ищут часами.

Idyllium сознательно встал на сторону Python: лучше честно отказать сейчас, чем подсунуть коварный баг потом. Проверьте — верните = в любую программу с условием и полюбуйтесь, как язык вас останавливает.

Задание 23 ⭐. Почему if (5) не работает

Попробуйте написать совсем коротко:
