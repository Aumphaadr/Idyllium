Задание 7. Пыль на компасе

Эксперимент. В прошлой книге щель в контуре оставляло обрезающее div(), а честная дробь 360.0 / 7 замыкала фигуру идеально. Сегодня зайдём с прибором точнее глаза: пусть черепаха нарисует такой семиугольник, а потом доложит числа.

x = 0 y = 0 heading = 5.684341886080802e-14 нос чист: true

Координаты — ровные нули: поле округляет их за вас, спасибо среде. А вот в носу осталась пыль: 5.684341886080802e-14 — это научная запись числа 0,000000000000057. Откуда? Дробь 360.0 / 7 не хранится в компьютере точно (как 1/3 не записывается конечной десятичной дробью), и семь сложений неточного числа дают не ровно 360. Для глаза это ноль, для оператора == — нет! Отсюда железное правило взрослых программистов, которое пригодится далеко за пределами черепахи: дробные числа сравнивают не на равенство, а на близость — math.abs(t.heading) < 0.001. Проверьте заодно: t.heading == 0 — что напечатает?

Три открытия на пять строк: два left(30) складываются, а два set_heading(90) — нет (второй ничего не меняет: черепаха уже смотрит на 90); угол 405 черепаха нормализует в 45 (лишний полный оборот отброшен). И помните из урока: записать t.heading = 90; нельзя — свойство только для чтения, среда ответит property 'heading' is read-only. Поворачивает только команда.
