Задание 7. Число не лезет в строку

Двойная прививка типов. Первая: напишите scoreboard.text = clicks; — компилятор: cannot assign 'int' value to 'string' variable; текст есть текст, числа возит to_string. Вторая, коварнее: заведите int height = 196 - drone.y; (вычитание с полем фигуры) — cannot assign 'float' value to 'int' variable: поля фигур дробные (вспомните кота с долей 0.02 — он бы не смог красться по целым числам!), и для целых показаний приборов нужен старый друг to_int: int height = to_int(196 - drone.y);. Обе ошибки — громкие, оба лекарства — из консольного детства.

Минутка из внешнего мира. Почему у программистов все буквы одинаковой ширины

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

Присмотритесь к встроенному шрифту: буква «i» занимает столько же места, сколько «Ш». Это моноширинный шрифт — наследник печатных машинок, где каретка сдвигалась на одинаковый шаг. Обычные шрифты (как Lobster) — пропорциональные: каждой букве по фигуре. Зачем программистам машинописная древность? Код читается колонками: отступы, выравненные скобки, таблицы данных — всё держится на том, что десятый символ строки стоит под десятым символом соседней. И ещё: в моноширинных шрифтах специально различают ноль и букву О, единицу и букву l — цена путаницы у программиста выше, чем у поэта. Source Code Pro так и переводится: «исходный код, профессиональный». А Lobster хорош там, где буквы — праздник: на афише, которую вы сделаете через две задачи.

Задание 15. Светофор обретает голос

Светофор с пультом (№4 з.10) дорастает до городского: рядом с лампами — крупная надпись состояния: «СТОЙ» красным при красной лампе, «ЖДИ» жёлтым, «ИДИ» зелёным.
