Блок 2. Экспертиза

Задание 5. Обещание и правда

Урок говорит: «его переменные и функции становятся доступны как scene.имя». Проверим. Допишите в main з.1 строку scene.ball.x = 0; — и компилятор откажет: module 'scene' has no member 'ball'. Функции модуля видны, а вот переменные в текущей версии языка снаружи не видны — только изнутри модуля. Расстраиваться не будем — вспомните private из ООП: скрытое состояние это защита: никто снаружи не сломает шар в обход правил модуля. Хотите подвинуть шар — просите функцию: scene.on_mouse_move двигает, з.3 добавила сброс. Запишите правило книги: состояние модуля — за дверью; двери — это функции.

Задание 6. Тройная прививка подключения

Три классические поломки за пять минут — все громкие, все с внятными письмами. Первая: опечатка use scena; → module 'scena' was not found — компилятор ищет файл scena.idyl и не находит. Вторая: правильный use, но вызов без префикса — init() вместо scene.init() → function 'init' was not declared in this scope — без префикса main ищет функцию у себя. Третья: переименуйте сам файл scene.idyl во что-нибудь другое и запустите → снова was not found: подключение — это имя файла, ничего больше. Верните всё на место; диагнозы — в тетрадь.

Задание 7. Два тёзки

Предсказание перед запуском — обязательно. Два модуля: alpha.idyl с функцией hello(), печатающей «привет из alpha», и beta.idyl с такой же по имени hello(), печатающей «привет из beta»; main зовёт alpha.hello(); и beta.hello();. Вопрос до запуска: поссорятся ли тёзки? Ответ: нет — у каждого файла своё пространство имён, и префикс всегда говорит, чей это hello. Поэтому в каждом модуле может жить своя redraw, своя init — и никакой путаницы. Имя функции — местное; полное имя — «файл точка функция».

Задание 8. Кольцо

Могут ли два модуля дружить взаимно? Файл ping.idyl пишет use pong;, файл pong.idyl пишет use ping;. Запустите: compile error: module import cycle detected: ping -> pong -> ping — компилятор прошёл по стрелкам и упёрся в кольцо. Правило на всю жизнь: зависимости — дерево, не кольцо; кто главнее — тот и подключает (main подключает сцену; сцена не подключает main). Если двум модулям взаимно нужны друг у друга функции — это знак, что общую часть пора выселить в третий файл, который подключат оба.
