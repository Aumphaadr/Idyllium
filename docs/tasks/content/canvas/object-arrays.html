Минутка из внешнего мира. Системы частиц

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

Дождь в гоночной игре, искры от меча, дым над трубой, конфетти после победы — всё это системы частиц: сотни и тысячи крошечных объектов, у каждого — позиция, скорость, время жизни. Узнаёте? Это ровно ваш сегодняшний снегопад, только массив побольше: профессиональный движок гоняет по сто тысяч частиц кадр за кадром тем же самым способом — «каждой частице update, каждой draw». Художника по частицам в игровых студиях называют VFX-artist, и его рабочий день — подбор конструкторов: с какой скоростью разлетается, как быстро гаснет, какого цвета рождается. Ваша снежинка с random-скоростью — первая настоящая частица. Осталось набрать штат.
