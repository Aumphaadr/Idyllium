Ползунок вместо цифр

Откройте настройки любой игры — там почти наверняка живёт регулятор громкости. Вводить громкость числом с клавиатуры было бы странно: хочется просто потянуть ручку влево-вправо и сразу услышать разницу. Так же устроены яркость в фоторедакторе и фильтр цен в интернет-магазине.

Для таких случаев в gui есть gui.Slider — ползунок, который выбирает значение из диапазона движением ручки.

Вот ползунок громкости, выставленный ровно на середину:

🎚️ Мы не задавали min и max — по умолчанию они равны 0 и 100, поэтому 50 — ровно середина. Попробуйте подвигать.

Основные свойства Slider

Как и SpinBox, Slider имеет свойства для настройки диапазона. Вот опорная таблица:

СвойствоТипПо умолчаниюЧто делает
valueint—текущее положение ручки
minint0минимальное значение
maxint100максимальное значение
stepint—шаг, с которым двигается ручка
on_changeсобытие—срабатывает при каждом изменении значения

Запомните пару 0 и 100: если min и max не задавать, Slider сам выберет именно их — как в примере выше. А когда диапазон нужен другой, задайте его явно:

🎯 Диапазон 0–300, шаг 50. Ползунок делает более резкие прыжки.
Ему становятся доступны значения: [0, 50, 100, 150, 200, 250, 300].

Тонкость на случай опечатки: если записать в value число вне диапазона (скажем, 150 при max = 100), программа не упадёт — в свойстве честно будет лежать 150, а ползунок на экране прижмётся к ближайшему краю. Как только пользователь его подвинет, value вернётся в диапазон. Ошибкой это не считается сознательно: порядок настройки свободный, и value = 150 с последующим max = 300 — обычное дело.

И последнее свойство — orientation. По умолчанию ползунок горизонтальный ("horizontal"), но бывает нужен вертикальный, как регулятор громкости на музыкальном пульте: задайте orientation = "vertical", сделайте виджет узким и высоким — и минимум окажется внизу, как у настоящего фейдера.

🎚️ Оба ползунка стоят на одном значении: "horizontal" тянется вправо, "vertical" — вверх, минимум внизу.

Событие on_change

Ползунок, который молчит о своём значении, — только половина дела. Как и у SpinBox, у Slider есть событие on_change, которое срабатывает при каждом изменении значения. Вернёмся к громкости и подключим подпись, чтобы она обновлялась, пока вы тянете ручку:

Громкость: 50

Slider vs SpinBox

В чём разница и что выбрать?

  • Slider — быстрый, наглядный, но не точный. Хорош для грубой настройки (громкость, яркость).
  • SpinBox — точный, но требует больше кликов. Хорош, когда важна точность (количество игроков, размер массива).

Типичная ошибка: строка вместо числа

Значение ползунка — всегда число. Записать в value строку, даже такую «числовую», как "50", не выйдет:

main.idyl:5:20: compile error: cannot assign 'string' value to 'int' variable

"50" в кавычках — это string, а value у Slider — int. Кавычки убрать — и компилятор доволен.

А вот за диапазоном компилятор не следит: код slider.value = 500; при max = 300 спокойно проходит проверку. Компилятор проверяет типы, а не диапазоны, поэтому держать value в пределах min и max — забота программиста.
