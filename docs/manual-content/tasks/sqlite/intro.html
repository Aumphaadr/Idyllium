Задание 7. Разговор с закрытой дверью

db.close() — и затем db.execute(...) → sqlite database is already closed. Дословно и мгновенно. Дисциплина в тетрадь: закрыл — не трогай; проверить живость можно через is_open, но лучше строить программу так, чтобы после close к объекту не возвращаться (закрытие — последняя строка работы с базой, как close у файлов).

Задание 8. SQL проверяет грамотность

Опечатка: CREATE TABEL pets (...) → sqlite execution failed: near "TABEL": syntax error — SQLite называет место: возле какого слова споткнулся. Испытайте ещё пару опечаток (пропущенная скобка? запятая?) и почитайте письма: у SQL свой компилятор со своим почерком, и near "..." — его фирменное «вот тут». Двухэтажная диагностика раздела: Idyllium говорит, ЧТО провалилось (execution failed), SQLite уточняет, ГДЕ.

Минутка из внешнего мира. База в каждом кармане

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

SQLite — самая распространённая база данных на планете, и с большим отрывом: её копий больше, чем людей. Она сидит в каждом Android и iPhone (история звонков, сообщения, настройки приложений), в каждом браузере (история, куки), в мессенджерах, фотоаппаратах, автомобилях и самолётах. Причина — та самая, из-за которой мы начали с неё: не нужен сервер — вся база живёт в одном файле, а движок весит меньше мегабайта. Автор — Ричард Хипп — сделал ещё один необычный ход: отдал SQLite в общественное достояние, без лицензий и платежей вовсе, — бери кто хочет. Взяли все. Так что ваша pets.db — не учебная игрушка, а тот же самый механизм, что прямо сейчас хранит переписку в телефоне у вас в кармане.
