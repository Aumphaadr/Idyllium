Блок 2. Экспертиза

Задание 5. Один герой в двух ячейках

Врезка урока — руками. Соберите таблицу «неправильно»: одна переменная tmp, два захода: add полей → в массив → set новых значений → снова в массив. Напечатайте: [{"n":2},{"n":2}] — обе записи одинаковые, и обе — последние! В массиве лежат две ссылки на один объект: json.Value(объект) упаковывает не копию — ссылку (урок прямо отсылает к врезке «Объект — это ссылка» из ООП). Почините двумя способами: своя переменная каждому (стиль урока) или переменная внутри блока (Бобики!). Это четвёртая встреча с законом ссылок — ООП-this, ловушка tmp, дверь №5, теперь массив записей: закон один, декорации разные. Диагноз вечен: все записи одинаковые → ищи общую переменную.

Задание 6. Дверь в запись

Обратная сторона того же закона — во благо: players.at(0).to_object() — тоже дверь: set через неё меняет запись прямо в таблице (напечатайте таблицу после — уровень изменился!). То, что в з.5 было ловушкой, здесь — инструмент: редактирование таблицы на месте, без пересборки. Ссылки не добрые и не злые — они просто ссылки; разницу делает то, знаете ли вы о них.

Задание 7. Пропущенная ступенька

Забудьте to_object(): players.at(i).get("name") → compile error: type 'json.Value' has no method 'get' — у нераспакованного Value нет get! Заметьте уровень ошибки: компилятор, до запуска (сравните с runtime-письмами типов — эта ловится ещё дешевле). Диагноз: между at и get всегда стоит to_object — ступенька, которую не перепрыгнуть.

Минутка из внешнего мира. CSV против JSON: дуэль форматов

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

Помните scores.txt — «Мира;1250» строка за строкой? Это формат CSV (comma-separated values — значения через разделитель), и он старше JSON на десятилетия: таблицы экспорта из Excel, банковские выписки, научные данные — всё ездит в CSV. Дуэль честная: CSV короче (никаких ключей в каждой строке — колонки названы один раз или вообще подразумеваются), JSON — самоописаннее (каждая запись носит свои подписи с собой, вложенность и типы встроены). Поэтому мир поделился: гигантские однородные таблицы — CSV, структуры и API — JSON. А боль у них общая — та самая, из вашей первой звезды: точка с запятой внутри имени ломает CSV, и взрослые решают её кавычками с правилами экранирования... которые в JSON были встроены с рождения (книга №2 показала). Иногда «многословный» значит «надёжный».
