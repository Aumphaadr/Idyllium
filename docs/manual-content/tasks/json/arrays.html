Блок 1. Список в коробке

Практика с преподавателем

Задание 1. Три предмета в скобках

Начните с текста — массив глазами: ["sword", "shield", "potion"] — читается как «первый — меч, второй — щит, третий — зелье»: номера не подписаны, порядок и есть номер. Затем — сборка и чтение:

Проговорите три вещи. Первая: элементы — те же json.Value, упаковка обязательна (в ячейках списка — коробки одного формата, как у объекта!). Вторая: at(0) — первый, индексы с нуля, как везде в Idyllium. Третья: length — свойство, и цикл по массиву пишется как по родному. Урок держит массивы однотипными — и мы будем: строка к строке, число к числу.

Блок 2. Экспертиза

Задание 5. Шестой лишний, издание JSON

at(5) на массиве из трёх → runtime error: json array index 5 out of bounds (size 3, valid indices 0-2). Семейство знакомо до буквы (dyn_array в №5-консоли, json.Object без ключа в №3): размер, законные номера, ваш неправильный. И классика цикла: i <= length вместо < — прогоните и увидьте ту же ошибку на последнем витке. Границы — вечные, письма — честные.

Задание 6. Забытая упаковка

items.add("sword") без json.Value → compile error: 'add' argument 1 expects 'json.Value', got 'string' — компилятор ловит до запуска и называет ожидаемое против принесённого (expects/got — читаем как в №7-canvas!). Заметьте разницу с ошибками №5: та — рантайм (узнаётся в полёте), эта — компилятор (узнаётся до старта). Чем раньше ловится — тем дешевле.

Задание 7. Перепутанные превращения

to_object() на распарсенном массиве → runtime error: json value is array, expected object (и зеркально: to_array() на объекте — проверьте!). Письмо из семейства типов №3 — «что лежит, чего ждали». Диагноз: посмотри на первый символ файла: { — объект, [ — массив; превращение выбирает файл, а не желание.

Задание 8. Поиск без сервиса

Есть ли «зелье маны» в инвентаре? У dyn_array был готовый contains — у json.Array его нет: только цикл с флагом (bool found + сравнение at(i).to_string()). Напишите поиск руками и проговорите философию: JSON-массив — хранилище, а не швейцарский нож: формат хранит, программа думает. (Функция-искалка bool function has_item(json.Array, string) — кандидат в личную библиотеку!)

Минутка из внешнего мира. Топ-10, который живёт в скобках

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

Откройте таблицу рекордов в любой игре — вы смотрите на JSON-массив. Лидерборды, история сообщений в чате, список друзей, очередь загрузок, «недавно играли» — всюду, где важен порядок, сервер шлёт вашему клиенту массив: первый элемент — чемпион, последний — новичок. Знаменитая страница «Топ-100» в онлайн-игре — это буквально [...] на сто элементов, и когда вы врываетесь на 37-е место, сервер вставляет вас между 36-м и 38-м (вставками мы займёмся через пару книг!). А порядок массива — это обещание: если сервер прислал топ по убыванию очков, клиент рисует его сверху вниз не глядя в числа. Порядок — тоже данные; вы знали это с первой задачи книги.

Блок 5. Полигон

Задание 17. Аналитик лидерборда

top_scores.json — топ-6 очков по убыванию. Программа-аналитик: показать таблицу с местами; рекорд и среднее; затем — спросить ваш результат и объявить, какое место он занял бы: пройти топ сверху и найти первую позицию, где ваш счёт больше («Вы заняли бы 3-е место, потеснив 1660»); не дотянули до шестёрки — «пока вне топа, до шестого места не хватает N». Честный крючок вслух: показать место мы умеем, а вставить в топ — пока нет: вставками занимается седьмая книга, и ваш аналитик тогда дорастёт до регистратора. Сдача сценарием: результат-чемпион, результат-середняк, результат-мимо.

Задание 19 ⭐⭐. Колода

Генератор во всей красе: собрать колоду из 36 карт двойным циклом по двум обычным массивам-заготовкам (4 масти × 9 рангов — конкатенация «ранг + пробел + масть»); записать колоду в deck.json (36 строк в pretty — внушительный документ!); и сдать три карты на руку — три случайных at (random-индексы в законных границах!). Проверки достоинства: length ровно 36; в файле нет двух одинаковых карт (аудит з.18 — придёт на помощь!). Кто сделает раздачу без повторов карт (вытянутая не выпадает снова — а удалять из json.Array мы ещё не умеем... значит, помнить вытянутые индексы в dyn_array и перебрасывать random при повторе — честная хитрость до седьмой книги!) — тот собрал настоящий карточный стол. Двойной цикл рождает данные, random их раздаёт, JSON хранит: генератор, казино и склад в сорока строках.
