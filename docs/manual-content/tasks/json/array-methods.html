Минутка из внешнего мира. Ctrl+Z — это pop

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

Стопка блинов из з.4 — снял верхний, под ним предыдущий — в программировании зовётся стек (stack, «стопка»), и на ней стоит половина привычного мира. Ctrl+Z в любом редакторе — стек отмен: каждое ваше действие кладётся сверху, каждое «отменить» — pop последнего. Кнопка «назад» в браузере — стек посещённых страниц. Вызовы функций в самом Idyllium — тоже стек (помните «maximum call depth» из ООП? Это стопка переполнилась!). А очередь из з.10 — противоположный характер: уходят с головы, приходят в хвост — так живут печать документов, сообщения в чатах, загрузки. Два порядка — LIFO (последний пришёл — первый ушёл, стек) и FIFO (первый пришёл — первый ушёл, очередь) — и оба вы сегодня собрали из pop, add и remove(0). Звезда №19 доведёт стек отмен до рабочего Ctrl+Z — не переключайтесь.

Задание 19 ⭐⭐. Ctrl+Z своими руками

Минутка обещала — собираем стек отмен. Редактор списка покупок с командами: добавить (add), удалить по номеру (remove) — и U — отменить последнее действие. Механика: каждое действие кладёт в undo_stack (второй json.Array!) обратную команду — объект-запись (№6!): для добавления — {"action": "remove_last"}, для удаления — {"action": "insert", "index": i, "value": удалённое} (значение едет в команде — иначе что возвращать?). U — pop() из стека (LIFO — отменяется последнее!) и исполнение по action (if-диспетчер); стек пуст — вежливое «отменять нечего» (з.6 привита!). Прогоните сценарий: три добавления, удаление, четыре отмены — список должен вернуться к пустоте шаг за шагом, в обратном порядке. Вы собрали настоящий Ctrl+Z — командный паттерн, на котором стоят все редакторы мира: действие — это данные, отмена — это исполнение обратных данных. Кто добавит Redo (второй стек, куда U перекладывает отменённое) — тому больше нечему учиться у кнопки «отменить».
