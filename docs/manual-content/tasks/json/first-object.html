Блок 1. Коробка с ячейками

Практика с преподавателем

Задание 1. Анкета в коробке

Начните с текста — покажите JSON глазами, до всякого кода:

{
    "name": "Liam",
    "age": 12,
    "is_admin": false
}

Прочитайте вслух как анкету: имя — Liam, возраст — 12, администратор — нет. Правила записи: ключи — всегда в двойных кавычках; строки — в кавычках, числа и true/false — без. Затем — сборка кодом:

Вывод: {"name":"Liam","age":12,"is_admin":false} — та же анкета, сжатая в строку. Проговорите три вещи. Первая: json.Value(...) — упаковка: в ячейках коробки лежат только Value, поэтому и строку, и число, и false заворачиваем одинаково. Вторая: порядок ключей в выводе — порядок ваших add (проверено — вывод предсказуем до символа!). Третья: to_pretty_json(4) печатает ту же коробку «для людей» — с отступами (4 — ширина отступа) — и именно её мы пишем в файлы: fout.write_line(root.to_pretty_json(4)).

Самостоятельная практика

Задание 2. Анкета о себе

Соберите объект о себе: имя, возраст, любимое число, есть ли кот (bool!). Сначала — предсказание: напишите в тетради, как будет выглядеть компактный вывод, вплоть до каждой кавычки и запятой. Потом запустите и сверьте посимвольно. Двусторонность — фирменный жанр раздела: кто предсказывает вывод, тот понимает формат, а не заклинание.

Задание 3. Диктант наоборот

Дан JSON-текст — напишите код, который печатает ровно его (компактно):

{"title":"Второй носок","count":2,"lucky":true}

Сверка — посимвольная. Подвох на внимательность: порядок add должен повторить порядок ключей (иначе совпадёт всё, кроме порядка, — и это уже не «ровно он»).

Задание 4. Карточка предмета

Соберите карточку предмета в духе раздатки («Зелье от прокрастинации»: title, count, equipped) и запишите красивую версию в item.json. Затем — откройте файл глазами (редактором) и убедитесь: в файле лежит аккуратный читабельный JSON с отступами. Файл, который приятно открыть человеку, — это уже не шкаф из безымянных строчек: у каждого значения — подпись.

Блок 2. Экспертиза

Задание 5. Дважды новосёл

Добавьте один ключ дважды: root.add("name", ...) и снова add("name", ...) → runtime error: json object already has key 'name'. Коробка не терпит двух ячеек с одной подписью — «как две папки с одинаковым названием». Правило: add — новосёл; на занятое место новосёла не селят. А кто меняет жильца — узнаем через задачу.

Задание 6. Ремонт пустоты

Зеркальная поломка: set("level", ...) на объекте, где ключа level нет → json object has no key 'level'. set — ремонт; ремонтировать нечего. Двойной детектор в тетрадь таблицей: add на занятое — падает; set на пустое — падает; add на пустое и set на занятое — работают. Пара инструментов с зеркальными характерами — перепутал — узнаешь от рантайма, громко и с именем ключа.

Задание 7. Вежливый заселитель

Узор «добавь или обнови» — своими руками: функция... нет, пока просто код: if (root.has("level")) { root.set(...) } else { root.add(...) } — работает и на пустом объекте, и на занятом (прогоните оба случая!). has — разведка перед действием, знакомая вежливость (exists у файлов из №1!). Запомните узор — он понадобится всякий раз, когда неизвестно, первый ли это визит.

Задание 8. Формат защищает себя

Драматургическая вершина экспертизы. В книге №1 самодельный формат умер от двоеточия в имени. Испытайте JSON тем же ядом: json.Value("Сказал: \"Привет\"") — строка с кавычками внутри (в коде их приходится экранировать бэкслэшем — обсудите это один раз: \" — «кавычка как символ, не как конец строки»). Напечатайте to_json: {"quote":"Сказал: \"Привет\""} — формат сам заэкранировал кавычки в данных! Добавьте путь C:\games — и \\ тоже появится само. Значение может содержать что угодно — кавычки, двоеточия, запятые — и коробка не сломается: подписи и содержимое разделены не честным словом, а правилами формата. Вот чем стандарт отличается от самоделки.

Блок 3. Мастерская объектов

Практика с преподавателем

Задание 9. Три ширины красоты

У доски: один объект — три печати: to_pretty_json(4), to_pretty_json(2), to_pretty_json() (без аргумента — тоже 2, проверено). Сравните столбиком; обсудите: компакт — для машин и передачи, красота — для людей и файлов; ширина отступа — вкус команды (в раздатке сайта — 4, его и держим). И запишите «золотой стандарт файла»: fout.write_line(root.to_pretty_json(4)); — так выглядят все наши будущие сохранения.

Самостоятельная практика

Задание 10. Опросник-генератор

Программа спрашивает пользователя (console.read_line — багаж): имя питомца, вид, возраст, умеет ли давать лапу (да/нет → bool!) — и собирает pet.json. Ввод живой — файл каждый раз разный. Вы написали генератор данных: первая программа курса, чей продукт — не вывод на экран, а файл-документ.

Задание 11. Настройки под отвёрткой

Соберите объект настроек игры в духе save.json: music (true), volume (60), difficulty («нормально»). Напечатайте. Теперь — сеанс правок тем же объектом: выключить музыку (set!), убавить громкость до 20, а сложность... поднять до «кошмар» — но сначала has-проверка з.7 (вдруг ключа нет?). Финальная печать. Объект живёт и меняется в программе — а файл вы запишете, когда правки закончатся (порядок «наигрался — сохранил» — как в настоящих играх).

Задание 12. Фабрика героев

Функция-фабрика: json.Object function make_hero(string name, int level) — собирает и возвращает коробку (функции возвращают объекты — багаж ООП!). Три героя тремя вызовами, три печати. Одна фабрика — сколько угодно одинаково устроенных коробок: заготовка конвейера, который развернётся в книге о массивах объектов.

Минутка из внешнего мира. Человек, который не изобрёл JSON

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

У JSON есть «отец» — американец Дуглас Крокфорд, — но сам он упорно говорит: «Я не изобрёл JSON. Я его обнаружил — он уже существовал в природе». В начале двухтысячных Крокфорд заметил, что кусочек языка JavaScript — запись объектов в фигурных скобках — идеально подходит для обмена данными: проще некуда, читается человеком, парсится машиной. Он описал правила на одной страничке (сайт json.org до сих пор помещается на экран), дал имя — JavaScript Object Notation — и... всё. Ни патента, ни комитета, ни версии 2.0: JSON принципиально закончен. Сегодня на нём разговаривает весь интернет — настройки игр, ответы серверов, конфиги программ, — и всё это из-за странной скромности формата: он умеет так мало, что его невозможно усложнить. Ваша коробка с ячейками — ровно та, что Крокфорд «нашёл в природе».

Блок 4. Сцены с управлением

Задание 13. Двусторонний диктант

Серия на скорость и точность — пять раундов: три JSON-текста → написать код (посимвольное совпадение!); два фрагмента кода → предсказать вывод в тетради до запуска. Тексты подбирает преподаватель по силе группы (наши: пустой объект {}; одноключевой; трёхключевой со всеми типами; с русским значением; с дробью 4.5 — да, дроби в JSON живут, хоть урок о них молчит!). Кто прошёл все пять без расхождений — переводчик «текст ↔ код» аттестован.

Задание 14. Карточка товара

Обратный скаффолд: «Интернет-лавка гильдии заводит карточки товаров. Поля: title (строка), price (целое, в монетах), in_stock (bool), rating (дробное — 4.8, со сноской: дроби легальны). Собрать карточку любимого товара из game_items.txt (файл с сайта — выберите глазами!), записать красиво в card.json, показать файл». Соберите. Четыре типа значений в одной коробке — полный ассортимент склада JSON.

Задание 15. Конструктор персонажа

Условная сборка: опросник спрашивает имя и класс персонажа; набор ключей зависит от ответа: магу — mana (спросить сколько), рыцарю — armor, барду — songs_known. У разных персонажей — разные ячейки, и это законно: коробки не обязаны быть одинаковыми (в отличие от шкафа №1, где новое свойство означало пятый файл на ВСЕХ!). Соберите двух разных персонажей за два запуска и сравните их файлы глазами.

Задание 16. Обратная разработка

В раздатке — reference_card.json: образец, собранный неизвестным мастером. Ваша задача — написать код, который производит точно такой же файл: изучите образец глазами, повторите ключи, значения, порядок и отступ. Проверка — программой: прочитать образец read_all(), сравнить с вашим to_pretty_json(4) (.trim() у прочитанного — хвост!): «СОВПАЛО С ОБРАЗЦОМ» или показать свой вариант для сверки глазами. Обратная разработка по образцу + самосверка строкой — так тестируют настоящие генераторы данных.

Блок 5. Полигон

Задание 17. Паспортный стол гильдии

Полный цикл производства документов: программа-опросник принимает новых членов гильдии в цикле («ещё анкета? да/нет»): для каждого — имя, класс (с условными полями з.15!), уровень; каждому — свой файл member_1.json, member_2.json... (номер — из счётчика, имя файла — конкатенацией!); в конце — сводка: «Оформлено паспортов: N» и список файлов. Сдача: три персонажа за один запуск, три аккуратных файла на диске, каждый открывается глазами и читается как документ. Фабрика (з.12) + опросник (з.10) + условная сборка (з.15) + файлы — мастерская работает серийно.

Блок 6. Со звёздочкой

Комбинацию инструментов не подсказываем — в этом и звёздочка.

Задание 18 ⭐. Великое переселение

Мост между книгами: прочитать старый шкаф hero_names.txt + hero_levels.txt (раздатка №1!) — и переселить каждого героя в собственную коробку: цикл по массивам, на каждого — объект name+level (фабрика з.12!), каждому — файл hero_1.json ... hero_5.json (красивая печать). Отчёт: «Конвертировано героев: 5». Откройте пару файлов глазами: Мира, жившая строчкой №1 в четырёх ящиках, теперь — цельный документ. Шкаф не выброшен — он переселён; правда, пять файлов на пять героев — тоже не предел мечтаний... (массив объектов в одном файле — уже скоро, и вы к нему готовы).

Задание 19 ⭐⭐. Генератор случайных легенд

Мастерская на автопилоте: программа сама сочиняет N персонажей (N спросить): имя — из массива заготовок + случайный номер («Бард-77»), класс — random-выбор из массива, уровень — random 1–20, деталь по классу (условные ключи з.15!); каждому — файл; в конце — сводка с перечнем. Запустите на N=5 и покажите урожай. Тонкость мастера: имена файлов не должны совпасть (счётчик в имени — гарантия). Генераторы тестовых данных — настоящая профессия инструментальщика в игровых студиях: когда дизайнеру нужно «сто врагов для проверки баланса», их не пишут руками — их генерируют. Вы теперь умеете.
