Задание 2. Визитка навсегда

Программа-первая: спросить у пользователя имя, любимое блюдо и девиз (console.read_line() — багаж!), записать три строки в card.txt. Задание 3. Счётчик запусков

Классика первых сохранений: программа печатает «Эта программа запускалась N раз(а)» — и не врёт. Схема: если counter.txt существует — прочитать число; +1; переписать файл; напечатать. Подарок сверх урока (с напоминанием — в уроках раздела его нет): file.exists("counter.txt") возвращает bool — первый запуск без файла программа переживёт, начав с нуля (раздаточный counter.txt с нулём — для тех, кто до exists не дотянулся: оба пути законны, сравните их). Запустите пять раз подряд — программа помнит вас.

Задание 4. Метеостанция

Файл weather.txt — семь температур за неделю (есть морозные!). Прочитать в массив чисел и отчитаться: средняя температура (осторожно — деление и дробность, багаж!), самый тёплый и самый холодный день (номера дней — из индексов!). Файл + знакомая математика массивов: данные приходят извне, обработка — ваша.

Блок 2. Экспертиза

Задание 5. Хвостатая строка

Уберите .trim() при чтении имени и напечатайте результат в квадратных скобках: console.writeln("[", name, "]") — закрывающая скобка спрыгнула на новую строку! Строка утащила с собой невидимый перевод строки. Доказательство длиной: name.length без trim — 5, с trim — 4 (у «Liam»!). Диагноз в тетрадь: строка из файла — с хвостом; trim — расчёска. А теперь уберите trim у числа — to_int перед переводом строки... работает? Проверьте — и запомните: где-то простит, где-то нет, расчёсывать — всегда.

Задание 6. Призрачный файл

file.open("ghost.txt", "read") → runtime error: file.open() cannot open 'ghost.txt' for reading: file does not exist — семейство знакомо по шрифтам и картинкам: не нашёл — так и говорю. Вежливое лечение — з.3 уже показала: file.exists перед открытием и человеческое сообщение («Сохранений пока нет — начинаем новую игру!») вместо падения. Перепишите з.6 вежливо.

Задание 7. Жадное чтение

В names.txt две строки — прочитайте три: istream.read_line() cannot read past end of file. Честно и сразу. Дисциплина из урока: читаешь в цикле — спрашивай has_next_line(); жадность наказуема. Сравните с массивами: та же философия границ («лучше упасть сразу, чем молча вернуть странное»), тот же характер ошибок.

Задание 8. Праздник испорчен

Главная экспертиза книги. Файлы guests.txt (четыре гостя) и gifts.txt (подарки) — программа раздаёт: «Мира получает: Носки с драконами...» И на четвёртом госте — крах: array index 3 out of bounds (size 3, valid indices 0-2). Подарков — три. Кто виноват? Никто и все: оба файла честные, программа честная — а данные рассинхронизированы, и узнали вы об этом в момент падения, на глазах у Бориса. Почините (допишите подарок в файл) и запишите вывод крупно: параллельные файлы никто не сторожит — они расходятся молча. Это не последняя встреча с этой болью — это её знакомство.

Минутка из внешнего мира. Батарейка внутри картриджа

Блок 6. Со звёздочкой

Комбинацию инструментов не подсказываем — в этом и звёздочка.

Задание 18 ⭐. Одна строка — один герой

На сайте лежит scores.txt — двенадцать строк вида Мира;1250: имя и очки в одной строке через точку с запятой. Кто-то уже пытался лечить шкаф — склеил два ящика в один! Напишите читалку: row.split(";") разрезает строку на части (метод строк — багаж), дальше — имя и число. Отчёт: сколько игроков, у кого рекорд. А потом — вопросы на вырост: что сломается, если в имени будет «;»? А если у игрока появится третье поле — все двенадцать строк переделывать? А если кто-то забудет точку с запятой в одной строке? Самодельный формат работает, пока все помнят его правила наизусть, — а помнить их за всех обычно некому.

Инструмент, который стоило бы иметь каждой гильдии: программа-ревизор проверяет шкаф broken_guild_*.txt (раздатка: names, levels, coins — и один из ящиков болен!): для каждого файла — file.exists (пропал целиком? — доложить!), затем счёт строк функцией count_lines(имя) (файл → int, своя функция — багаж!); все длины сравниваются с первой; итоговый вердикт: «шкаф цел» или «ШКАФ БОЛЕН: файл такой-то, строк столько-то вместо стольких». Прогоните на больном шкафу (найдёт недостачу в levels!) и на здоровом hero_* (оправдает). Вы написали сторожа, которого у параллельных файлов никогда не было, — и заметьте горькую иронию: сторожа приходится писать отдельной программой, а он всё равно скажет лишь «болен», но не «чем лечить».
