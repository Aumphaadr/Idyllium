Практика с преподавателем

Задание 1. Герой в одну строку

Собираем у доски:

Проговорите три вещи. Первая: constructor Hero(...) — метод, чьё имя совпадает с именем класса, и вызывает его не программист, а само создание объекта (третий ответ на вопрос «кто вызывает эту функцию?»: нажатие, время — а теперь и рождение). Задание 4. Класс без конструктора не сломан

Эксперимент-паспорт. Класс Empty с одним полем и без конструктора: Empty first; — работает (поля-заготовки, как всю дорогу); Empty second = Empty(); — тоже работает! А вот Empty broken(7); — отказ: 'Empty' expects 0 arguments, got 1 — «ждал ноль аргументов, получил один»: раскладывать семёрку по полям некому. Вывод в тетрадь: конструктор — не обязанность, а удобство; но если аргументы передаёшь — должен существовать тот, кто их примет.

Блок 2. Экспертиза рождения

Задание 5. Недодал

Герою из з.1 передайте один аргумент вместо двух: Hero broken("Кузнец");. Ответ: 'Hero' expects 2 arguments, got 1 — знакомая арифметика ожиданий (вы видели её в з.4 с нулём). Конструктор — контракт: сколько параметров объявлено, столько аргументов и неси (пока без дефолтов — они в блоке 3 и меняют правила игры).

Задание 6. Перевёртыш

Теперь аргументы по счёту верные, но местами перепутаны: Hero swapped(500, "Кузнец");. Читайте ответ внимательно — сообщений два, и они зеркальны: argument 1 expects 'string', got 'int' и argument 2 expects 'int', got 'string'. Компилятор дважды описал одну беду с двух сторон — такая пара сообщений почти всегда значит «перепутан порядок». Порядок аргументов — это порядок параметров конструктора, и никак иначе (именованное исключение — в блоке 3).

Задание 7. Роддом ведёт журнал

Эксперимент: добавьте в конструктор героя строку console.writeln("Родился герой: ", this.name); — и создайте трёх героев между двумя печатями-маркерами «--- До создания ---» и «--- После создания ---». Запустите: журнал рождений показывает, когда именно срабатывает конструктор — ровно в строке создания, ни раньше, ни позже. Печать в конструкторе — легальный приём отладки: рождение перестаёт быть невидимым.

Задание 8. Дело о призраке

Продолжение з.7 — детектив. После маркера допишите одну строку: Hero("Призрак", 99); — вызов конструктора без имени переменной. Предскажите вывод и запустите: журнал честно печатает «Родился герой: Призрак» — конструктор отработал, объект существовал! — но обратиться к нему не выйдет никак: имени нет, ссылки нет, герой потерян в момент рождения. Ошибки не будет — это молчаливая поломка нового поколения: объект-призрак. Диагноз в копилку: «конструктор сработал, а объекта не найти → ищи вызов без присваивания».

Задание 12. Дефолт не с той стороны

Поломка на правило из з.9: объявите constructor Hero(int ex_hp = 100, string ex_name) — дефолтный параметр раньше обязательного. Компилятор отвечает развёрнутой формулой: parameter 'ex_name' without default value cannot follow a parameter with default value — «параметр без умолчания не может идти после параметра с умолчанием». Правило урока продиктовано дословно в сообщении — переведите его вслух и почините перестановкой. Заодно обсудите, почему так: если бы дефолт стоял первым, компилятор не смог бы понять, кому достался единственный аргумент.

Задание 14. Фабрика чудищ

Функция может возвращать свежий объект — это и есть фабрика: Monster function random_monster() с return Monster(random.choose_from(kinds), random.create_int(20, 60)); внутри. Фабрика прячет рецепт случайности в одном месте: main просит «дай чудище» и не знает подробностей.

Задание 15. Кубик на один бросок

Тем, что здесь объект успел поработать до исчезновения — мы забрали у него roll(). Одноразовый объект — законный приём; потерянный объект — поломка. Граница — в том, спросили ли его о чём-нибудь.

Задание 19 ⭐. Первый блин

Конструктор умеет не только раскладывать аргументы — он умеет вычислять. Класс Pancake: номер и bool lumpy;, причём комом ли блин, решает сам конструктор из одного аргумента-номера: первый — комом, остальные — нет (одна строка с сравнением, без единого if). Масленица: тарелка dyn_array наполняется циклом от 1 до 5 конструктор-выражением, опись блинов подтверждает: «Блин 1: комом = true», остальные удались. Поле, рождённое вычислением, — приём, на котором стоят взрослые конструкторы: аргументы — сырьё, поля — продукт.
