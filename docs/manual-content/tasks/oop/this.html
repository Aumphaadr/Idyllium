Блок 2. Экспертиза

Задание 5. Голое имя

Уберите this. из метода meow() — оставьте console.writeln(name, " мяукнул!");. Компилятор: 'name' was not declared in this scope. Знакомое сообщение? В прошлых книгах оно значило «класс-склад» — теперь у него вторая жизнь: «забыл this в методе». Оба диагноза — одно правило: голого имени поля не существует нигде, ни в main, ни внутри метода. Поле всегда живёт в объекте; внутри метода этот объект зовётся this.

Диагноз в копилку молчаливых: одинаковый вывод у разных объектов → ищи в методе константу на месте this.поля.

Минутка из внешнего мира. Самое хитрое слово языка

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

«Я» — самое хитрое слово русского языка: его значение меняется от того, кто говорит. В устах Ани «я» — это Аня, в устах Бори — Боря, и никто не путается. Лингвисты зовут такие слова дейктическими — «указывающими от говорящего». this — ровно такое слово, «я» для объектов: один и тот же метод, произнося this.name, каждый раз говорит о том, кто сейчас «на трибуне». Кстати, в разных языках программирования это слово своё: в C++ и Java — this, в Python — self («сам»), а в старом добром Паскале и вовсе не было нужды его писать. Idyllium выбрал строгий вариант: всегда явно, всегда this — чтобы глаз сразу видел, где метод говорит о себе.
