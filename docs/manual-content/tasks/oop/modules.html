Задание 2. Кот съезжает (два файла)

Переезд знакомца: класс Cat с info() из прошлой книги — в собственный файл cat.idyl. В main.idyl — три кота с визитками, все обращения — cat.Cat. Критерий сдачи: вывод до буквы совпадает с однофайловой версией — переезд меняет прописку, не поведение.

Задание 3. Голое имя класса

В рабочем проекте из з.2 сотрите префикс в одной строке: Cat extra; вместо cat.Cat extra;. Компилятор: unknown class 'Cat' — «не знаю такого класса», хотя файл лежит рядом! Правило урока без исключений: класс из файла существует только под полным именем. Верните префикс. Задание 4. Двойник ошибки

Опечатайтесь в имени класса: cat.Cta c;. Компилятор: unknown class 'Cta' — то же сообщение, что в з.3, но причина другая! Одна формулировка — две болезни: потерян префикс или наврано имя. Минутка из внешнего мира. Города из файлов

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

«Одна программа — один файл» умерло примерно тогда же, когда и чёрно-белое кино. Современный браузер — десятки миллионов строк кода в десятках тысяч файлов; большая игра — тысячи файлов, и у каждого имя-обещание: weather.cpp про погоду, inventory.cpp про рюкзак. Программисты ориентируются в таких городах не памятью, а адресами: болит прыжок героя — открывай jump, что бы там ни было внутри. Ровно этому правилу вы сегодня научились: имя файла — это обещание содержимого, и лучший комплимент вашему проекту — «я нашёл нужное с первой попытки». А use console;, который вы пишете с первого дня, — то же самое подключение: просто до сегодняшнего дня все библиотеки писали за вас.

Задание 19 ⭐. Визитка научилась отдавать

Тихая революция: метод-визитка, который не печатает, а возвращает строку. Класс Robot: имя, заряд; string function passport() — return склейки («Альфа (заряд 90%)» — вспомните to_string). Три робота — и main печатает рапорт одной строкой: «На смене: Альфа (заряд 90%), Бета (заряд 40%) и Гамма (заряд 15%)». С печатающим info() из прошлой книги такое не собрать — он выводит сам и сразу; возвращающий passport() отдаёт текст, а main решает, как его сервировать. Вопрос на сдаче: когда какой вариант удобнее?
