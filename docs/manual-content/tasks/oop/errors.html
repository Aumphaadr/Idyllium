Ваш чек-лист тихой зоны — из той же профессии, что и чек-листы, которые после таких историй появились в авиации и космонавтике.

Задание 18 ⭐⭐. Сапёр наоборот

Финал раздела — вы автор мины. Сочините детектив для соседа по правилам жанра:

1. Честная формулировка задачи + образец правильной работы.

2. В коде — ровно три ошибки, по одной с каждого этажа: одна громкая (компиляция), одна с крушением на ходу (рантайм) и одна тихая с территории человека (из чек-листа — на выбор: parent, тень, приблуда, двойник, немой круг).

3. Своя починенная версия прогнана заранее.

4. Ошибки честные: просчёт спешащего автора, а не шифровка.

Обмен, расследование, двойная сдача: как сапёр — три ошибки соседа найдены и починены; как минёр — разбор «какая из трёх держалась дольше всех». Ставим на тихую: против неё у соседа только чек-лист — и это лучший экзамен по всему разделу.
