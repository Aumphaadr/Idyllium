Для каждой main бросает кубик задымления random.create_int(0, 10), печатает его («Кухня, дым: 9») и решает: больше семи — panic(), иначе — beep(). Заметьте расстановку ролей и проговорите её: методы глупые, main умный — решения принимает программа снаружи, объект лишь исполняет. Позже (не сегодня) объекты поумнеют.

Задание 13. Попугай-рандомайзер
