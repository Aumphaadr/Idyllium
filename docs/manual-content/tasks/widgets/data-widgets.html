Минутка из внешнего мира. Медсестра, победившая графиком

Первым человеком, который убедил правительство картинкой с данными, была медсестра. Флоренс Найтингейл вернулась с Крымской войны (1856 год) с страшной статистикой: большинство солдат погибало не от ран, а от болезней в грязных госпиталях. Столбцы цифр в отчётах никто из чиновников не читал. Тогда Найтингейл нарисовала свою знаменитую «розу» — круговую диаграмму, где каждый месяц войны был долькой, а размер дольки кричал о числе умерших. Синие зоны — болезни, красные — раны: было видно с одного взгляда, что госпитальная грязь убивает лучше вражеских пушек. Парламент увидел — и санитарная реформа случилась. Ваши пироги и столбики — прямые потомки той розы: график нужен не для красоты, а чтобы правду стало видно сразу.

Блок 5. Полигон

Задание 17. Пульт гильдии

Большая самостоятельная работа — дашборд, как у настоящего гильдейского казначея. Требования:

  1. Данные — источник правды: три динамических массива (dyn_array) — имена, классы, золото; стартовый состав — три героя.
  2. Три витрины в одном окне: таблица (имя, класс, золото), столбики золота (шкала зафиксирована), пирог по классам (сколько магов, воинов, жриц — посчитать циклом по массиву классов!).
  3. Функция-помощник rebuild(): очищает все три витрины (clear) и перезаполняет их из массивов циклом. Чтобы функция видела виджеты, объявите их глобально — как глобальную черепаху в Turtle; сама функция — на верхнем уровне: void function rebuild() { ... } (вложенных функций в языке нет).
  4. Кнопка «Принять новобранца»: случайное имя из заготовленного пула, случайный класс, случайное золото 50–500 — add во все три массива и один вызов rebuild().
  5. Табло «В гильдии N героев» — из length массива, не из row_count (правда — в данных!).

Приёмка кликом: пять новобранцев подряд — таблица растёт, столбики прибавляются, пирог перекраивает доли, табло считает. Устный экзамен: покажите в коде место, где данные меняются (одно!), и места, где витрины об этом узнают (одно — rebuild!). Кто хочет испытание сверху — добавьте кнопку «Проводить на пенсию»: уволить героя по selected_row таблицы (remove_at из всех трёх массивов + rebuild; не забудьте случай «никто не выбран»).

Задание 19 ⭐⭐. Центр управления полётом

Финал раздела витрин — телеметрия ракеты в прямом эфире. Таймер (тик — полсекунды) ведёт полёт, а три витрины показывают его с трёх сторон:

  1. Линия — высота: пока есть топливо, ракета набирает случайно от −5 до +12 за тик (турбулентность!), кончилось — падает на 5–15 за тик; высота не бывает меньше нуля; max_points = 40 — бегущая лента.
  2. Столбик — топливо: старт со 100, каждый тик минус 1–4; set_value обновляет, ниже нуля не бывает.
  3. Таблица-журнал — события с номером тика: «старт» при запуске, «топливо кончилось» (ровно один раз — вам понадобится флаг!), «посадка».
  4. Автофинал: когда высота 0 и топлива 0 — timer.stop(), в лейбле «Посадка! Полёт длился N тиков», в журнале — последняя запись.

Каждый запуск — новый полёт: сколько продержится ракета — решает случайность, но журнал обязан рассказывать правду. Сдача: два прогона при преподавателе + устный экзамен «покажите, где рождается событие журнала и почему „топливо кончилось" не пишется каждый тик». Кто дойдёт до конца — знайте: вы собрали настоящий телеметрический пульт, и после раздела SQLite он сможет писать журнал не в таблицу на экране, а в базу данных — урок прямо называет дашборд по базе законным финальным проектом всего курса виджетов.
