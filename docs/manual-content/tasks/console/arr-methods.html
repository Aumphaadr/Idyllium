Задание 20 ⭐. Встать в шеренгу

Класс выстроен по росту: [150, 160, 170, 180]. Приходит новичок — программа спрашивает его рост и вставляет его на правильное место, не пересортировывая всю шеренгу. Куда именно вставить — выясните перебором (первый, кто выше новичка, и укажет позицию), а само втискивание сделает insert. Подумайте и о крайнем случае: а если новичок — самый высокий?

Рост новичка: 165 Шеренга: [150, 160, 165, 170, 180]

Минутка из внешнего мира. Сортировка у соседей

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

  • В Python всё родное: список.sort(), список.reverse(), x in список (наш contains), список.count(x). Совпадение почти буквальное.
  • В JavaScript у arr.sort() есть легендарная ловушка: без специальной настройки он сортирует всё как строки — и массив [10, 9, 1] превращается в [1, 10, 9], потому что «10» по алфавиту раньше «9»! На этом сюрпризе подорвались поколения новичков.
  • В C++ сортировка — это std::sort(begin, end) с загадочными «итераторами» на края массива.

Idyllium сортирует честно: числа — как числа, строки — по алфавиту, и никаких настроек. А ещё держите в голове: за одну строчку sort() компьютер проделывает громадную работу по перестановке ячеек — как именно он это делает, целая наука, и до неё вы ещё доберётесь.
