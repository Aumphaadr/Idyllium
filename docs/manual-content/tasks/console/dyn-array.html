Задание 22 ⭐. Как это зовут у соседей

Растущие массивы есть почти везде, только имена разные:

  • в JavaScript это обычный массив с методом push() (добавить) и splice() (удалить); длину даёт .length — прямо как у нас;
  • в Python — список (list) с методами append() и pop(), а длину меряют функцией len(список);
  • в C++ это std::vector с push_back() и .size().

А статический массив из прошлой темы у них тоже есть: в C++ это std::array, в старом стиле — обычный int a[5]. Idyllium просто дал двум видам ясные имена: array — фиксированный, dyn_array — растущий. Кстати, наш dyn_array умеет пока не всё: вставлять ячейку в середину, чистить массив разом и доставать последнюю ячейку вы освоите в уроке про методы массивов.
