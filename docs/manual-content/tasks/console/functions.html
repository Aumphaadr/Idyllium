Это ремесло называется рефакторингом — переделка устройства без изменения поведения, — и им взрослые программисты заняты половину рабочего времени.

Минутка из внешнего мира. Функции — везде, main — почти везде

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

  • В Python функцию объявляют словом def, а тип не пишут вовсе: def digit_sum(number):. В JavaScript — словом function (знакомо!) или стрелочкой =>. В C++ — почти как у нас, только без слова function: int digit_sum(int number).
  • Точка входа main — тоже мировая традиция: C++, Java, C#, Go начинают программу именно с неё, и возвращает она тот же код завершения, что вы видели в задании 33. А вот Python живёт без обязательного main — код выполняется просто сверху вниз, как наши самые первые программы.
  • Именованные аргументы и умолчания — фирменная гордость Python (greet(name="Мира")); в C++ есть только умолчания, а JavaScript не умеет ни того, ни другого — там выкручиваются, передавая объект.

Так что выученное сегодня — не местный диалект, а общий язык ремесла: def, function или стрелка — механизм превращения данных везде один.
