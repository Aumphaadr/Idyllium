Раньше программа только болтала. Теперь она умеет слушать. Наберите:

Задание 8. Пять шоколадок

Программисты узнают правила, нарочно всё ломая. Запустите программу из задания 3 (про здоровье) и вместо честного числа введите по очереди:

Минутка из внешнего мира. Как это устроено в других языках

Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.

В Idyllium приятно: get_int сразу отдаёт число, get_float — дробь, get_string — слово. Каждый спрашивает своё.

А вот в Python функция ввода одна на всё — input(), и она всегда возвращает строку, даже если вы набрали 5. Для Python это текст "5", а не число. И если новичок наберёт два числа и попробует их «сложить», получит не 8, а склейку "53" — потому что складываются-то строки! Чтобы вышло число, в Python приходится явно просить: int(input()).

В C++ ближе к нам: cin >> n для числовой переменной сразу читает число.

Idyllium пошёл дружелюбным путём: сказал get_int — получил число, и никаких сюрпризов со случайной склейкой. Мелочь — а сколько нервов бережёт.
