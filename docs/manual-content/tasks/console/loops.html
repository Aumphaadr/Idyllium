Блок 1. while — пока условие держится

while проверяет условие перед каждым повторением. Держится — тело выполняется снова; перестало — цикл заканчивается. Хорош, когда заранее не знаешь, сколько будет повторений.

Блок 2. for — когда число повторений известно

for собирает всё управление счётчиком в одну строку: for (старт; условие; шаг). Старт — один раз в начале, условие — перед каждым кругом, шаг — после каждого круга. Идеален, когда повторить нужно ровно столько-то раз.

Задание 25 ⭐. Как крутят циклы у соседей

Ещё с урока про инкремент вы знаете: короткой записи i++ в Idyllium нет — шаг пишется i += 1, в том числе и в заголовке for (проверьте: for (int i = 1; i <= 5; i++) не соберётся). Но у соседей по цеху на этот счёт свои порядки.

  • В C++, Java и JavaScript есть короткая запись i++ (то же, что i += 1) — привычная, но новичков путает: чем i++ отличается от ++i? Idyllium убрал этот вопрос, оставив ясное i += 1.
  • Ещё коварнее — лишняя точка с запятой: в C++ строка while (i < 3); спокойно компилируется, но означает пустой цикл — программа зависает, а ошибки не видно. Напишите while (i < 3); с точкой с запятой в Idyllium — язык сразу откажется.

Idyllium специально проще и строже: одна очевидная форма шага и никаких «пустых» циклов исподтишка.
