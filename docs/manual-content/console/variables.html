Что такое переменная?

В прошлом уроке программа выводила только тот текст, который вы заранее написали в коде. Но настоящие программы постоянно что-то запоминают и меняют: счёт игрока, количество жизней, никнейм. Значит, данным нужно место, где они будут храниться, пока программа работает. Для этого и придуманы переменные.

Переменная — это ячейка в памяти компьютера, предназначенная для хранения данных.

У каждой переменной обязательно есть три атрибута:

  • Имя — как мы обращаемся к переменной в коде (например, score, name);
  • Тип — какого рода данные она может хранить (число, текст и т.д.);
  • Значение — то, что в ней сейчас лежит.

Создание переменных

Рассмотрим простейший пример — учёт жизней и очков в игре:

Результат выполнения:

3 1500

Запись int lives = 3; читается так: «создать ячейку типа int (целое число) с именем lives и положить в неё значение 3».

Если передать переменную в функцию console.write() — она выведет именно значение этой переменной, а не её имя.

Типы данных в Idyllium

Idyllium поддерживает пять базовых типов:

ТипЧто хранитПримеры значений
intцелые числа42, -7, 0
floatчисла с плавающей точкой (дробные)3.14, -0.5, 2.0
stringтекст в двойных кавычках"Привет"
charодиночный символ в одинарных кавычках'A', '#'
boolлогические значенияtrue, false

Ошибки несоответствия типов

В Idyllium нельзя присвоить переменной значение, не подходящее по типу. Сначала посмотрим на то, что компилятор разрешает:

Результат выполнения:

2 4.62 5 ЪЕЪ или ЪУЪ? дайте 64 алмаза

Заметьте единственную поблажку: во float разрешается положить целое число — оно спокойно превратится в 5.0. (А выводится weight просто как 5: дробная часть нулевая, и Idyllium её не показывает.)

А теперь попробуем провернуть обратный трюк — положить дробное число в int:

main.idyl:5:17: error: cannot assign 'float' value to 'int' variable

Компилятор непреклонен: 1.7 — это float, а float-значение в int-переменную не помещается. И правда: что такое 1.7 жизни? Число в string тоже не спрячешь:

main.idyl:5:23: error: cannot assign 'int' value to 'string' variable

Хотите, чтобы 56692 считался текстом, — возьмите его в кавычки: "56692". Это не ограничение — это защита. Компьютер не будет пытаться угадать, что вы имели в виду.

Объявление и присваивание

Есть два способа работать с переменной:

  • Инициализация — создание с одновременным присваиванием значения;
  • Присваивание — изменение значения уже созданной переменной.

Результат выполнения:

Монет: 20 Самоцветов: 30

Встраивание переменных в текст

Функция console.write() не ставит пробелы автоматически между аргументами. Сравните:

Результат:

Кот сожрал5кг корма!

Число «прилипло» к словам. Чтобы этого избежать — добавьте пробелы в строки:

Теперь всё читаемо:

Кот сожрал 5 кг корма!

Это даёт вам полный контроль над форматом вывода — без сюрпризов.

Изменение значения переменной

Переменная может менять своё значение в процессе работы программы:

Вывод:

У вас 20000 денег У вас 25000 денег

Обратите внимание: при изменении значения не нужно указывать тип повторно. Достаточно написать money = 25000;. Тип уже зафиксирован при объявлении.

Порядок строк имеет значение

В Idyllium переменную можно использовать только после её объявления. Попытка обратиться к переменной до того, как она создана, вызовет ошибку компиляции:

main.idyl:5:32: error: 'diam' was not declared in this scope

Компилятор жалуется: в строке 5 ему встретилось имя diam, о котором он пока ничего не знает — ведь объявление переменной стоит строкой ниже. Поменяем строки местами:

Алмазов: 64

Это правило помогает избежать путаницы и учит писать код в логической последовательности: сначала — что у вас есть (объявление), потом — что вы с этим делаете (использование).
