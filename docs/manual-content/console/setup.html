Самый быстрый способ: открыть IDE

Совсем скоро вы напишете свою первую программу. Но сначала ей нужен дом — место, где код удобно писать, запускать и разглядывать результат. Такое место называется средой разработки (по-английски — IDE). Хорошая новость: если вы только начинаете знакомиться с Idyllium, устанавливать ничего не нужно. Достаточно открыть Web IDE: там уже есть редактор, запуск программы, вывод, файловое дерево и подсветка синтаксиса.

Открыть IDE

Web IDE удобна для уроков и быстрых экспериментов. Всё просто: открыли страницу, набрали код в редакторе, нажали зелёную кнопку ▶ «Запустить» в правом верхнем углу окна (или сочетание клавиш Ctrl+Enter) — программа работает, а её результат появляется в панели «Вывод».

Учебник, документация и IDE живут рядом

Учебник, документация и Web IDE находятся на одном сайте. Поэтому из учебника можно открыть IDE, а из IDE — вернуться к урокам. Не нужно держать в голове два разных адреса: теория и практика всегда в одном щелчке друг от друга.

В шапке учебника есть кнопки «Открыть IDE» и «Документация». В шапке IDE есть отдельные кнопки «Учебник» и «Документация». Все три части проекта остаются рядом, но решают разные задачи.

Если хочется работать в VS Code

Для более серьёзной работы можно поставить расширение Idyllium для VS Code. Оно добавляет подсветку, запуск текущего файла и постепенно будет получать больше привычных возможностей редактора.

  1. Откройте страницу релизов: github.com/Aumphaadr/Idyllium/releases.
  2. Скачайте оттуда файл с окончанием .vsix. Это «коробка с расширением»: всё, что нужно VS Code для установки, упаковано в один файл.
  3. Откройте VS Code.
  4. Откройте панель Extensions («Расширения»): щёлкните по значку из квадратиков на левой панели или нажмите Ctrl+Shift+X.
  5. В правом верхнем углу этой панели найдите кнопку с тремя точками «···» и в её меню выберите Install from VSIX... («Установить из VSIX...»).
  6. Укажите скачанный файл .vsix — дальше VS Code всё сделает сам.

После установки VS Code начнёт понимать файлы .idyl. Это уже «локальный» способ работы: проекты лежат на вашем компьютере, а не только в браузере.

Что выбрать?

  • Web IDE — лучший старт для уроков, быстрых задач и работы без установки.
  • VS Code + расширение — хороший вариант для проектов побольше и привычной файловой структуры.

Для первых уроков выбирайте Web IDE. Когда появится желание хранить проект на компьютере и работать как в обычной среде разработки, переходите в VS Code.
