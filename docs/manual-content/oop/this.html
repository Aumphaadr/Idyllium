Проблема: одинаковый вывод

Создадим класс Cat с именем и методом meow(). В методе просто выведем «Кот мяукнул!»:

Кот мяукнул! Кот мяукнул!

В консоли не видно, какой именно кот мяукнул. Оба вывели одинаковое сообщение. Как это исправить?

Решение: идентификатор this

Внутри метода есть специальный идентификатор this, который ссылается на объект, вызвавший этот метод. Через this можно обращаться к свойствам и методам текущего объекта.

Барсик мяукнул! Мурзик мяукнул!

Теперь видно, какой кот мяукнул. Магия this позволяет методу понять, с каким объектом он работает.

Как это работает

Когда мы пишем cat1.meow(), внутри метода meow() идентификатор this становится ссылкой на cat1.

При вызове cat2.meow() — this указывает на cat2.

this — это как если бы методу невидимо передавался параметр «тот объект, от которого меня вызвали».

Объект — это ссылка

Мы сказали, что this — ссылка на объект. Переменные типа класса вообще хранят не сам объект, а ссылку на него. Поэтому запись Cat b = a; не создаёт второго кота: обе переменные указывают на один и тот же объект. Изменим кота через b — увидим изменение и через a:

5 5

Кот один, просто у него два «имени» — a и b. Запомните это: ссылки ещё не раз встретятся нам в уроках о массивах объектов и композиции.

Типичная ошибка: поле без this

Внутри метода к свойствам объекта нужно обращаться строго через this. Если написать просто name, компилятор будет искать обычную переменную с таким именем — и не найдёт её:

main.idyl:7:25: error: 'name' was not declared in this scope

Исправление: this.name вместо name.

Проблема: вывод объекта на консоль

Что будет, если попробовать вывести объект напрямую?

main.idyl:10:21: error: cannot print object of class 'Cat' directly

Компилятор не знает, как показать объект Cat в консоли, и отказывается это делать. Придётся объяснить ему самостоятельно.

Решение: метод info()

Добавим в класс метод info(), который печатает информацию об объекте в удобном виде:

Кот по кличке Барсик: 3 года, цвет рыжий Кот по кличке Мурзик: 4 года, цвет белый

Метод info() использует this, чтобы получить доступ к свойствам текущего объекта, и выводит удобочитаемую строку.

Итог

Главная опора урока: this — это тот объект, у которого вызвали метод.

  • Через this метод обращается к свойствам и методам своего объекта.
  • К свойствам внутри метода обращаемся строго через this: просто name — ошибка компиляции.
  • Переменная типа класса хранит ссылку на объект: после Cat b = a; обе переменные указывают на одного кота.
  • Вывести объект на консоль напрямую нельзя — это ошибка компиляции. Вместо этого пишем метод вроде info(), который печатает данные объекта.
