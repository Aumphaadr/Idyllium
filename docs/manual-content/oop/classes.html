Синтаксис класса

Класс объявляется с помощью ключевого слова class, затем идёт имя класса (с большой буквы — это общепринятое соглашение), а в фигурных скобках перечисляются свойства (поля) класса.

В этом примере мы создали класс Car (автомобиль) с тремя свойствами:

  • model — марка автомобиля (строка)
  • color — цвет автомобиля (строка)
  • year — год выпуска (целое число)

Обратите внимание: после закрывающей фигурной скобки класса точка с запятой не ставится.

Создание объектов

Когда класс объявлен, мы можем создавать его объекты (экземпляры). Синтаксис такой же, как у обычных переменных.

Соберём собственный автопарк из трёх машин с характером: вишнёвая «Лада» дедушки (заводится с пятого раза, но дедушка её ни на что не променяет), красная «Феррари» соседа и жёлтый «Запорожец», который старше вашей учительницы информатики:

Лада вишнёвый 1995 Феррари красный 2022 Запорожец жёлтый 1989

Обратите внимание: класс описан один раз, а объектов на его основе создано три. Каждый объект хранит свои собственные значения свойств: «Лада» не станет красной от того, что рядом припарковалась «Феррари».

Класс и объект

Разберём два ключевых термина:

  • Класс — это шаблон, по которому создаются объекты.
  • Объект — это экземпляр класса (конкретный представитель).

Чем объект отличается от обычной переменной?

Обычная переменная хранит одно значение определённого типа. Объект же может хранить много значений разных типов одновременно — это все его свойства (поля).

Объект — это как коробка с несколькими отделениями, каждое из которых хранит свой тип данных. А обычная переменная — это коробка с одним отделением. Чёрная «Победа» 1957 года — почти музейный экспонат, но для программы это обычный объект с тремя отделениями.

Типичная ошибка: печать объекта целиком

Раз объект — это переменная, возникает соблазн напечатать его одной командой, как число или строку:

main.idyl:15:21: error: cannot print object of class 'Car' directly
