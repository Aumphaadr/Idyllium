Текст на Canvas

Для текста используется drawable.Text. Ему можно задать позицию, размер шрифта, цвет и сам текст. Без дополнительных настроек используется встроенный Source Code Pro. Если нужен конкретный шрифт, его можно загрузить через общий ресурс fonts.Font — тот же объект подходит и для GUI-виджетов. Возьмём рукописный Lobster, знакомый по уроку о шрифтах в виджетах: его буквы совсем не похожи на встроенный шрифт, поэтому отличие видно с первого взгляда.

Эта маленькая программа ничего не рисует — она только загружает шрифт и настраивает текст. Зато её можно запустить и убедиться, что файл шрифта находится и читается без ошибок. Файл должен лежать в проекте рядом с программой: если его нет, Idyllium честно скажет, что не смог его найти:

main.idyl:8: runtime error: Font.load_from_file() cannot load 'Lobster-Regular.ttf': file does not exist

font выбирает рисунок букв, а font_size — их размер. Поэтому один объект main_font можно использовать у нескольких текстов разных размеров.

Если файл существует, но не является TTF, OTF, WOFF или WOFF2, ошибка тоже появится сразу.
