Когда кода становится много

Canvas-программа быстро разрастается: отдельно настройка объектов, отдельно клавиши, отдельно мышь, отдельно обновление кадра. Чтобы не заблудиться, часть кода можно вынести в другой файл.

main.idyl

Правило простое: строка use scene; подключает файл scene.idyl, лежащий рядом с программой, и его переменные и функции становятся доступны как scene.имя — например, scene.init.

scene.idyl

Новых возможностей здесь нет. Мы просто разложили код по файлам: главный файл собирает окно, а scene.idyl отвечает за поведение Canvas. Переменная ball объявлена на верхнем уровне scene.idyl — это состояние модуля: она создаётся один раз и живёт, пока работает программа, поэтому обе функции видят один и тот же шар.

Запустите программу — жёлтый шар бегает за курсором по тёмному полю, ровно как в уроке о движении мыши.
