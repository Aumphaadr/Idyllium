Вернёмся к нескольким игрокам

В первом уроке мы хранили имена и уровни в разных файлах и разных массивах. JSON позволяет хранить каждого игрока как отдельный объект, а всех игроков — как массив объектов.

Создаём массив игроков

Сначала создаём объекты игроков, затем добавляем их в общий JSON-массив.

[ { "name": "Liam", "level": 7 }, { "name": "Mira", "level": 5 } ]

Сохранить такой текст в JSON-файл вы уже умеете — точно так же, как мы записывали player.json в уроке о первом объекте, а прочитать его обратно — как в уроке о чтении JSON.

json.Value(объект) — это ссылка

Вызов json.Value(liam) не делает копию объекта, а упаковывает ссылку на него — вспомните врезку «Объект — это ссылка» из урока об идентификаторе this в разделе ООП. Если изменить объект после упаковки, изменение будет видно и внутри json.Value. Именно поэтому в примере выше у каждого игрока своя переменная: одна общая переменная положила бы в массив несколько ссылок на один и тот же объект.

{"level":6}

Читаем массив игроков

Каждый элемент массива — это json.Value. Мы превращаем его в json.Object и достаём нужные поля.

Liam: 7 Mira: 5
