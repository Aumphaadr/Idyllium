Данные не у вас

Весь третий курс данные жили рядом с программой: файлы в папке проекта, база данных на том же диске. Но самые интересные данные мира лежат не у вас. Прогноз погоды — на сервере метеослужбы. Курс валют — на сервере банка. Страница любимого сайта — на компьютере, который может стоять на другом континенте.

Люди ходят за такими данными через браузер. Программы ходят за ними напрямую — по сети, без браузера и без человека. Сегодня ваша программа впервые постучится на настоящий сервер в настоящем интернете.

Запрос и ответ

Разговор по сети устроен как разговор в справочном бюро. Программа-клиент задаёт вопрос: «дайте мне вот это» — это называется запрос. Сервер отвечает: «держите» или «такого нет» — это ответ. Один вопрос — один ответ; сервер не звонит первым.

Адрес, по которому стучится программа, вам давно знаком — это тот самый адрес из строки браузера. Подключаем библиотеку http и спрашиваем:

Статус: 200 Получилось: true

Присмотритесь к адресу: это же guild.json — файл гильдии из раздатки, который вы читали с диска в разделе JSON! Раздатка нашего учебника лежит на настоящем веб-сервере, и теперь ваша программа достаёт её по сети сама. Между запуском программы и словом «Статус» на экране запрос успел слетать до сервера и вернуться с ответом.

http.get(адрес) возвращает объект http.Response — конверт с ответом сервера. Внутри конверта:

Заголовок content-type — сервер честно предупреждает, что прислал: здесь — JSON в кодировке UTF-8. А в text лежит знакомая гильдия, символ в символ такая же, как в файле.

404 — это ответ, а не крах

Спросим у сервера файл, которого нет:

Статус: 404 Получилось: false Программа жива и работает дальше

Заметьте: программа не упала. Сервер снял трубку, выслушал вопрос и вежливо ответил: «такого файла нет, код 404». Это полноценный ответ — просто с плохой новостью. Поэтому после каждого запроса воспитанная программа смотрит на ok или status, прежде чем читать text.

Кодов у серверов много: 200 «хорошо», 404 «не найдено», 403 «не пущу», 500 «у меня самого всё сломалось». Запоминать таблицу не нужно — нужно запомнить правило: двухсотые — успех, остальные — повод разбираться. Ровно это и проверяет ok.

Два адреса беды: дозвонился или нет

А теперь сломаем по-настоящему — опечатаемся в имени сайта:

main.idyl:5: runtime error: http.get() cannot reach 'https://takogo-sajta-net.invalid/guild.json': host not found

Вот это уже ошибка времени выполнения: до сервера не дозвонились вовсе. Некому было отвечать — нет ни статуса, ни текста, программа падает с сообщением о причине.

Разница принципиальная, запишите её в тетрадь двумя строками:

Что случилосьКак выглядитЧто делать
Сервер ответил плохой новостьюstatus 404, 403, 500…; ok = falseчитать статус и решать
До сервера не дозвонилисьruntime error: cannot reach…ловить через try/catch

Короче: статус — читаем, недозвон — ловим. Причину недозвона сообщение называет прямо: host not found — имя сайта не существует (чаще всего опечатка), connection refused — компьютер есть, но на этой двери никто не слушает.

JSON приезжает по сети

В r.text лежит строка, а строку с JSON вы разбираете с закрытыми глазами — json.parse работает с текстом и ему всё равно, пришёл текст из файла или из-за океана:

В гильдии 5 героев: - Мира, уровень 12 - Кай, уровень 9 - Лея, уровень 14 - Борис, уровень 3 - Ника, уровень 21

Сравните с программой из раздела JSON, которая читала этот же файл с диска: разбор — тот же, данные — те же, поменялась только доставка. Полсотни настоящих сервисов — погода, расписания, словари — отдают данные ровно так: JSON по HTTP-адресу. Вы сейчас научились главному жанру современного интернета.

Сеть капризна: страховка через try/catch

Файл на диске никуда не денется, а сеть — живая: вайфай отвалился, сервер перегружен, кабель перекопали. Программа, которой данные нужны обязательно, держит запасной план — и это знакомый try/catch:

Web IDE и браузерная клетка

Запустите сегодняшние программы в Web IDE — гильдия придёт как ни в чём не бывало. А вот запрос к большинству чужих сайтов оттуда закончится так:

main.idyl:5: runtime error: http.get() was blocked by the browser for 'https://example.com/': the site does not allow browser requests (CORS) — this address works in console runs

Это не поломка и не каприз Idyllium. Web IDE живёт внутри браузера, а у браузеров железное правило безопасности: страница может запрашивать чужой сайт, только если тот сам разрешил (правило называется CORS). Наш сайт с раздаткой — разрешил, поэтому учебные адреса работают везде. Большинство сайтов — не разрешают чужим страницам себя читать.

В консольном запуске и VS Code никакого браузера нет — там программа ходит на любые адреса. Сообщение об ошибке само подсказывает выход: «this address works in console runs».

Таймаут: сколько ждать молчуна

Бывает третья беда: сервер не отвечает и не отказывает — просто молчит. Без защиты программа ждала бы вечно. Поэтому у каждого запроса есть таймаут — предел терпения. По умолчанию — 10 секунд: не дождались — запрос падает с ошибкой timed out after 10 seconds (и её тоже можно поймать через try/catch).

http.set_timeout(секунды) действует на все запросы после вызова; разрешено от 1 до 300 секунд.

POST: отдать, а не забрать

http.get — «дайте мне». Второй глагол сети — http.post(адрес, текст): «примите от меня». Так отправляют формы, сообщения, результаты игр. Наш сайт с раздаткой — витрина: он только выдаёт файлы, и на попытку что-то ему вручить честно отвечает кодом 405 — «так со мной нельзя»:

Статус: 405

Заметьте: это снова ответ, а не крах — правило «статус читаем» работает и здесь. Настоящее применение post начнётся, когда на другом конце появится сервер, готовый принимать, — в следующих разделах мы построим его сами.

Сетевая вежливость

Язык не ограничивает ваши запросы — как не ограничивают их Python, C# и другие взрослые языки. Значит, вежливость — на совести программиста. Правила простые: не стучаться к чужому серверу в цикле без пауз (сотня запросов в секунду для сервера — как сто звонков в дверь подряд), а если нужен опрос по расписанию — ставить time.sleep между запросами. К своей раздатке на уроке стучитесь сколько нужно — она для этого и выложена.
