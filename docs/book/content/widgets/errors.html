Зачем этот урок

Вы прошли весь раздел: окна и кнопки, поля и слайдеры, таймеры и модальные окна. Остался финальный урок — про грабли. Здесь собраны ошибки, на которые наступает каждый, кто пишет свои первые GUI-программы: для каждой — маленькая программа-пример, что происходит и как это исправить.

Ошибки бывают двух сортов. Одни ловит компилятор — для них мы приводим настоящий текст сообщения. Другие — «молчаливые»: программа компилируется и запускается, но ведёт себя не так, как вы хотели. Про них компилятор не скажет ни слова, поэтому их важно знать в лицо.

Забыли win.add_child()

Самый частый промах — создать виджет, но не добавить его в окно или контейнер. Виджет существует, но его не видно. Это «молчаливая» ошибка: компилятор не жалуется.

Код компилируется, окно появляется, но кнопки нет. Она создана и живёт в памяти — просто её никто не добавил в окно.

Исправление: всегда добавляйте виджеты в окно или контейнер через win.add_child(виджет) или frame.add_child(виджет).

Неправильный порядок добавления — перекрытие

Виджеты отрисовываются в порядке вызова add_child(). Первый добавленный — снизу, последний — сверху. Это тоже «молчаливая» ситуация: с точки зрения компилятора всё честно.

Кнопка перекрывает лейбл, потому что добавлена позже. Текст лейбла частично нечитаем.

Исправление: планируйте порядок добавления или используйте координаты, чтобы виджеты не пересекались.

Неверный тип в sender

При использовании параметра sender тип должен точно соответствовать типу виджета, который вызывает событие (об этом был урок «Отправители»).

main.idyl:9:20: compile error: callback property 'on_click' expects 'void function()' or 'void function(gui.Button)', got 'void function(gui.Label)'

Сообщение длинное, но полезное: компилятор перечисляет, какие сигнатуры он готов принять для on_click, и какую получил. Исправление: указывайте в параметре sender тип того виджета, чей это обработчик.

Присваивание числа свойству text у Label или Button

Свойство text у лейблов и кнопок — строковое (string). Число нужно преобразовывать через to_string().

main.idyl:7:18: compile error: cannot assign 'int' value to 'string' variable

Знакомое сообщение, правда? Оно то же самое, что и при работе с обычными переменными: text — строка, а 42 — число. Исправление: label.text = to_string(42);

Обращение к виджету до его создания

Переменная виджета должна быть объявлена до того, как вы пытаетесь её использовать в обработчике.

main.idyl:8:5: compile error: 'btn' was not declared in this scope

Компилятор не нашёл переменную btn — и сказал об этом ровно один раз, без эха о последствиях. Исправление: объявляйте виджет до его использования в обработчиках.

Timer: забыли вызвать start()

Таймер не запускается автоматически после создания. Нужно явно вызвать start(). Ещё одна «молчаливая» ошибка.

Код компилируется, таймер создан и настроен, но on_tick ни разу не вызывается. Текст на лейбле не меняется.

Исправление: не забывайте вызывать timer.start().

Modal: попытка добавить через add_child()

Модальные окна не являются виджетами в привычном смысле. Их не нужно добавлять в окно через add_child().

main.idyl:7:19: compile error: 'add_child' argument 1 expects gui widget, got 'gui.Modal'

Исправление: модальные окна создаются и показываются динамически, без add_child() — достаточно show_alert(), show_confirm() или show_input().

Выход за границы массива виджетов

При работе с массивами виджетов легко выйти за пределы, если индекс больше length - 1. Компилятор такое пропустит, а вот при выполнении программа упадёт — это ошибка выполнения (runtime error).

main.idyl:15: runtime error: array index 5 out of bounds (size 3, valid indices 0-2)

Исправление: всегда проверяйте, что индекс в пределах 0 .. length - 1.

Свойства, которых нет у виджета

У каждого виджета свой набор свойств. Например, placeholder нужен полю ввода, но не кнопке.

main.idyl:7:5: compile error: type 'gui.Button' has no property 'placeholder'

Исправление: сверяйтесь со справочником виджета. У кнопки есть text, font_size и on_click, а placeholder есть у LineEdit и TextEdit.

ComboBox: запись в selected_text

Классика раздела: захотелось выбрать пункт списка, записав его текст в selected_text. Но это свойство — только для чтения: ComboBox сам берёт его из выбранного пункта.

main.idyl:10:5: compile error: property 'selected_text' is read-only

Исправление: выбирайте пункт по номеру — combo.selected_index = 1; — а selected_text используйте только для чтения.

Горячая клавиша не работает, пока курсор в поле ввода

У окна есть событие on_key_pressed: «Escape закрывает программу», «пробел — пауза». Пишем обработчик, запускаем, щёлкаем в поле ввода, жмём Escape — ничего не происходит.

Это не поломка, а правило: пока фокус в поле ввода (LineEdit, TextEdit, счётчики, список), клавиши принадлежат полю — иначе Escape закрывал бы программу посреди слова. Щёлкните по фону окна или по кнопке — и горячие клавиши снова работают. С кнопки, флажка, ползунка, таблицы и холста клавиша доходит и до окна: сначала виджету, потом окну.

Как читать сообщения об ошибках

Сообщения для GUI-программ выглядят так же, как для консольных:

Вид ошибки Формат Пример из этого урока
Ошибка компиляции main.idyl:строка:колонка: compile error: ... main.idyl:6:18: compile error: cannot assign 'int' value to 'string' variable
Ошибка выполнения main.idyl:строка: runtime error: ... main.idyl:14: runtime error: array index 5 out of bounds (size 3, valid indices 0-2)
💡 Совет: Начинайте исправлять ошибки с первой — часто исправление одной ошибки убирает несколько последующих. А если ошибок нет, но виджет не отображается — проверьте, добавили ли вы его через add_child().

Что дальше?

Заметили, как мы весь раздел говорили: «у кнопки есть свойства и события», «у таймера есть методы»? Это неспроста: каждый виджет — это объект, готовая деталька со своими данными и умениями. В следующем разделе вы заглянете внутрь таких объектов — и научитесь создавать собственные.
