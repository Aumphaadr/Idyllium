Программа выходит в интернет

Пока что все ваши окна жили сами по себе. Но приложения умеют и большее — отправлять пользователя на сайт: в справку, в репозиторий проекта, на страницу с обновлениями. Сегодня вы научите этому и свои программы.

Инструментов будет два: надпись-ссылка (виджет gui.Label со свойством href) и библиотека url, которая умеет открывать адреса и разбирать их на части.

Надпись, на которую можно нажать

Отдельного виджета для ссылок в Idyllium нет — он и не нужен. У обычного gui.Label есть свойство href: как только вы запишете туда адрес, надпись превратится в настоящую ссылку. Она сама подчеркнётся, курсор станет «рукой», а по клику откроется новая вкладка:

Репозиторий Idyllium на GitHub
Слово href пришло из HTML — языка веб-страниц. Там ссылки описывают точно так же, и теперь вы узнаете их в чужом коде.

Ссылка остаётся обычной надписью, поэтому её можно приодеть уже знакомым style — в том числе задать вид при наведении:

Кнопка, которая открывает адрес

Ссылкой может быть не только надпись. Библиотека url умеет открывать адрес по команде — а значит, это можно поручить любому событию, например нажатию кнопки:

Кнопка с надписью «Не нажимать!» — древняя как мир шутка, и вы только что вооружились самым знаменитым её вариантом. Только не увлекайтесь: уводить человека на посторонний сайт без предупреждения — дурной тон. Хорошая программа честно пишет, куда именно ведёт кнопка.

Открывается адрес одинаково во всех трёх местах, где живёт Idyllium: в Web IDE появится новая вкладка, в расширении VS Code — окно системного браузера, а консольная программа попросит открыть браузер саму операционную систему. Разрешены только адреса http и https: открывать файлы на компьютере программа не может — и это не ограничение, а забота о безопасности.

main.idyl:4: runtime error: url.open() supports only http and https addresses, got 'file'

Адрес под микроскопом

Адрес только выглядит сплошной строкой — на самом деле он состоит из частей, у каждой своё имя и назначение. Библиотека url умеет доставать их поимённо:

Протокол: https Сайт: www.youtube.com Путь: /watch Запрос: v=dQw4w9WgXcQ&t=43 Порт: 443 Видео: dQw4w9WgXcQ Секунда: 43

Обратите внимание на порт: в адресе его нет, а программа ответила 443. Это стандартный порт для https — тот самый, куда браузер и пойдёт, даже если номер не написан. У http стандартный порт — 80.

Если строка вообще не похожа на адрес, программа честно об этом скажет. А заранее проверить строку поможет url.is_valid():

true false

Русские слова в адресе

Попробуйте поискать что-нибудь в интернете и посмотрите на адресную строку: русские слова в ней превращаются в череду процентов и цифр. Это не поломка, а процентное кодирование: в адресах разрешён узкий набор символов, и всё остальное записывается кодами байтов — теми самыми, о которых вы читали в уроке про кодировки.

Собирая адрес из кусочков, пропускайте текст через url.encode() — иначе адрес окажется испорченным:

https://www.google.com/search?q=%D0%B8%D0%B4%D0%B8%D0%BB%D0%BB%D0%B8%D1%8F%20%D1%8F%D0%B7%D1%8B%D0%BA идиллия язык

Заметьте: пробел превратился в %20, а каждая русская буква — в два кода, потому что в UTF-8 она занимает два байта. Обратно строку возвращает url.decode().

Что запомнить

  • Свойство href превращает обычный gui.Label в кликабельную ссылку; отдельного виджета для этого нет.
  • url.open() открывает адрес в браузере одинаково в Web IDE, VS Code и консоли.
  • Разрешены только http и https — файлы на компьютере программа открывать не может.
  • Адрес состоит из частей: протокол, сайт, путь, запрос, якорь — и каждую можно достать отдельно.
  • Русский текст попадает в адрес только через url.encode().
  • Уводить пользователя на посторонний сайт без предупреждения — дурной тон.
