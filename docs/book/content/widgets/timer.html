Что такое Timer?

gui.Timer — это объект, который позволяет вызывать функцию автоматически через равные промежутки времени, без участия пользователя.

Где он применяется:

  • ⏱️ Секундомеры и таймеры обратного отсчёта
  • 🎮 Анимация и движение объектов в игре
  • 📊 Автообновление данных (курсы валют, погода)
  • ⏰ Напоминания и отложенные действия

Свойства таймера

У таймера всего два свойства:

  • interval — интервал срабатывания в миллисекундах (1 секунда = 1000 мс)
  • on_tick — событие «тик», о нём в следующей секции

Интервал можно менять в любой момент, даже когда таймер уже запущен.

Кстати, у on_tick есть и расширенный вариант — void function(gui.Timer sender): таймер передаёт в обработчик сам себя, и через параметр sender можно, например, остановить его командой sender.stop();. Такие параметры-отправители есть и у событий виджетов — им посвящён отдельный урок чуть дальше.

Методы и состояние таймера

У таймера три метода управления и одно свойство-индикатор:

  • start() — запускает таймер; после остановки продолжает отсчёт с того места, где таймер замер
  • stop() — ставит таймер на паузу: накопленное время сохраняется
  • restart() — запускает таймер заново, отсчёт идёт с нуля (полезно при изменении интервала)
  • running — запущен ли таймер в данный момент (только для чтения; изменить его напрямую нельзя — используйте методы)

Разница между start() и restart() — как у секундомера: «продолжить» и «сбросить и начать заново». Пара stop() + start() — это пауза, а не перезапуск: недосчитанные миллисекунды никуда не денутся. Если вы поменяли интервал и хотите честный новый отсчёт — нужен именно restart():

Шпаргалка: всё, что умеет Timer

Имя Что это Описание
interval свойство (int) интервал между срабатываниями в миллисекундах; можно менять в любой момент
on_tick событие функция, вызываемая каждые interval мс: void function() или void function(gui.Timer sender)
start() метод запускает таймер
stop() метод ставит таймер на паузу: накопленное время сохраняется до следующего start()
restart() метод запускает отсчёт заново с нуля — например, после смены interval
running свойство (bool, только чтение) идёт ли отсчёт прямо сейчас; менять напрямую нельзя — только методами

Это весь Timer целиком — два свойства, событие и три метода. Помните разницу из секции про методы: пара stop() + start() — это пауза и продолжение, недосчитанные миллисекунды сохраняются. Честный перезапуск с нуля — только restart().

Типичные ошибки с таймером

«Молчаливая» ошибка: забыли start()

Самая коварная ошибка — та, о которой компилятор молчит. Таймер не запускается сам: если забыть start(), программа скомпилируется и окно откроется, но тиков не будет.

Ошибок нет, окно открылось, а «Тик!» так и не появился: таймер создан и настроен, но его никто не запустил. Надпись «Жду...» будет ждать вечно.

Если таймер «не работает» — первым делом проверьте, есть ли в программе вызов timer.start().

Ошибка компиляции: строка вместо числа

interval ждёт число миллисекунд (int). Если написать "1000" в кавычках, получится строка — и компилятор откажется:

main.idyl:5:22: compile error: cannot assign 'string' value to 'int' variable

Исправление: уберите кавычки — timer.interval = 1000;.
