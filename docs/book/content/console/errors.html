Два вида ошибок

Ошибки — не признак плохого программиста. Ошибки — это нормальная часть работы: они случаются и у новичков, и у профессионалов, причём у профессионалов, пожалуй, даже чаще — просто они быстрее их находят. Весь секрет в умении читать сообщения об ошибках, а не пугаться их.

В Idyllium существует два вида ошибок:

  • Ошибки компиляции — обнаруживаются до запуска. Программа вообще не начнёт работать, пока вы их не исправите.
  • Ошибки выполнения (runtime errors) — возникают во время работы программы. Компиляция проходит успешно, программа запускается, но на какой-то строке что-то идёт не так — и программа останавливается прямо там.

Этот урок — справочник самых частых ошибок. Все сообщения в нём настоящие: можете скопировать любой пример, запустить его и получить точно такой же текст.

Как читать сообщения об ошибках

Прежде чем разбирать ошибки по одной, научимся читать сами сообщения. Возьмём настоящую ошибку компиляции:

main.idyl:2:13: compile error: cannot assign 'string' value to 'int' variable

Сообщение состоит из частей, разделённых двоеточиями:

Часть Что означает
main.idyl файл, в котором найдена проблема
2 номер строки
13 номер символа в строке — компилятор показывает место с точностью до буквы
compile error: вид сообщения — ошибка компиляции
cannot assign... описание: что именно пошло не так

Ошибка выполнения выглядит чуть иначе: у неё указан только номер строки (без номера символа), а вместо compile error: написано runtime error:

main.idyl:3: runtime error: array index 5 out of bounds (size 3, valid indices 0-2)

Если вы работаете в Web IDE, перед именем файла будет видна ещё и папка проекта: /workspace/main.idyl:2:13: compile error: ... Смысл сообщения от этого не меняется.

💡 Совет: если сообщений несколько — начинайте исправлять с первого. Одна опечатка часто порождает целую гроздь сообщений, и после исправления первого остальные исчезают сами.

Ошибки компиляции: типы данных

Несовместимый тип при объявлении переменной

main.idyl:2:13: compile error: cannot assign 'string' value to 'int' variable

Переменной типа int нельзя присвоить строку. Используйте to_int() для преобразования.

Несовместимый тип при присваивании

main.idyl:3:9: compile error: cannot assign 'float' value to 'int' variable

Переменная уже объявлена как int — в неё нельзя записать дробное число. Округлите его или объявите переменную как float.

Переменная типа void

main.idyl:2:5: compile error: cannot declare variable of type 'void'

Тип void означает «ничего» и используется только как тип возврата функций.

Деление всегда возвращает float

main.idyl:4:13: compile error: cannot assign 'float' value to 'int' variable

Оператор / всегда возвращает float, даже если делится нацело. Для целочисленного деления используйте div(a, b).

Ошибки компиляции: необъявленные имена

Использование необъявленной переменной

main.idyl:4:19: compile error: 'x' was not declared in this scope

Переменная x не была создана. Объявите её перед использованием — и проверьте, нет ли опечатки в имени.

Использование библиотеки без импорта

main.idyl:2:13: compile error: 'math' is not imported (use 'use math;')

Библиотеку нужно подключить. Заботливый компилятор прямо в сообщении подсказывает как: добавьте use math; в начало файла.

Ошибки компиляции: условия и циклы

Условие должно быть типа bool

main.idyl:2:9: compile error: if condition must be 'bool', got 'int'

Условие в if, while, for должно быть логическим выражением. Используйте операторы сравнения: 5 > 0, x == 10 и т.д. У циклов сообщение то же, только вместо if в нём будет while или for.

break и continue вне цикла

main.idyl:2:5: compile error: 'break' is only valid inside a loop

Операторы break и continue работают только внутри while, do-while и for.

Ошибки компиляции: функции

Функция не возвращает значение

main.idyl:1:1: compile error: function with return type 'int' must return a value

Функция объявлена как int, но не содержит return. Это ошибка компиляции — программа не запустится, пока вы не добавите return result; в конец функции. Заметьте: компилятор указывает на строку 1 — на объявление самой функции.

void-функция возвращает значение

main.idyl:2:12: compile error: void function cannot return a value

Функция объявлена как void — она не может возвращать значение. Уберите return или смените тип на string.

Неправильное количество аргументов

main.idyl:6:13: compile error: 'add' expects 2 arguments, got 3

Функция add принимает 2 аргумента, а передано 3. Лишний придётся забрать обратно.

Ошибки компиляции: массивы

Неправильный размер массива

main.idyl:2:26: compile error: array initializer has 3 elements, but 'array<int, 5>' requires 5 main.idyl:2:26: compile error: cannot assign 'array<int, 3>' value to 'array<int, 5>' variable

Количество элементов в инициализаторе должно совпадать с размером массива. Обратите внимание: одна опечатка породила сразу два сообщения. Помните совет из начала урока? Исправьте первое — второе исчезнет вместе с ним.

Метод динамического массива на статическом

main.idyl:3:5: compile error: method 'add' is only available on 'dyn_array'

Статический массив имеет фиксированный размер — добавить в него элемент нельзя. Используйте dyn_array<int>, если размер должен меняться.

Сравнение массива с числом

main.idyl:3:9: compile error: comparison '>' requires numeric operands, got 'array<int, 3>' and 'int'

Знак > умеет сравнивать только числа — и компилятор называет обоих участников по именам: слева целый массив, справа число. Сравнивайте отдельные элементы: arr[0] > 5.

Ошибки компиляции: строки

Замена символа в строке

main.idyl:3:5: compile error: string characters are read-only

Прочитать символ строки через word[0] можно, а вот записать — нет: символы строки предназначены только для чтения. Хотите «мот» вместо «кот» — соберите новую строку целиком, например через конкатенацию.

Ошибки выполнения

Все ошибки ниже компилятор пропускает: с точки зрения типов программы безупречны. Проблема выясняется уже на ходу — поэтому и сообщение начинается с runtime error, а программа останавливается на указанной строке.

Деление на ноль

main.idyl:2: runtime error: division by zero

Деление на ноль невозможно. Проверяйте делитель перед операцией.

Выход за границы массива

main.idyl:3: runtime error: array index 5 out of bounds (size 3, valid indices 0-2)

Индекс 5 выходит за пределы массива из 3 элементов. Допустимые индексы: 0, 1, 2 — сообщение услужливо их перечисляет.

Выход за границы строки

main.idyl:3: runtime error: string index 10 out of bounds (length 3, valid indices 0-2)

Со строками правило то же, что с массивами: индекс 10 выходит за пределы строки длиной 3.

Некорректное преобразование

main.idyl:2: runtime error: 'to_int' cannot convert 'abc' to int

Строка «abc» не содержит число. Перед преобразованием проверяйте строку методом .is_int() — особенно если её ввёл пользователь.

Корень из отрицательного числа

main.idyl:4: runtime error: math.sqrt() expects a non-negative number, got -4

Квадратный корень из отрицательного числа не определён в вещественных числах.

Файл не найден

main.idyl:4: runtime error: file.open() cannot open 'data.txt' for reading: file does not exist

Путь в сообщении — тот же, что вы написали в программе: он всегда считается от папки проекта. Смысл один: файла data.txt рядом с программой нет. Создайте его перед чтением.

Pop из пустого массива

main.idyl:3: runtime error: cannot pop from empty array

Массив пуст — нечего извлекать. Проверяйте arr.length > 0 перед вызовом pop().

Неизвестная кодировка

main.idyl:4: runtime error: unknown encoding 'cp1337'

Кодировка cp1337 не поддерживается. Вызовите encoding.list_encodings(), чтобы увидеть список доступных кодировок.

Заключение

Не пытайтесь выучить этот каталог наизусть — просто возвращайтесь к нему, когда встретите незнакомое сообщение. Со временем вы будете читать ошибки так же спокойно, как подсказки навигатора: «через 200 метров поверните к строке 4».

А в следующем уроке мы научимся перехватывать ошибки выполнения прямо из программы — чтобы она не останавливалась, а действовала по запасному плану.
