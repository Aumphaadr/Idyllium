Оператор присваивания: напоминание

Оператор = работает просто и честно:

«Беру значение справа от себя и кладу его в переменную слева от себя».

Пример:

A = 5 D = 6

Здесь всё предсказуемо: сначала вычисляется правая часть, потом результат присваивается левой.

Переменная изменяет саму себя

Теперь представим, что слева и справа — одна и та же переменная:

Это не ошибка и не парадокс. Это — саморедактирование.

Переменная N участвует в выражении в двух ролях:

  • справа — как источник текущего значения («я сейчас 10»);
  • слева — как получатель нового значения («теперь я стану 11»).

Увеличение переменной на единицу называется инкрементом, а уменьшение на единицу — декрементом. Посмотрим на оба в деле:

Было: 10 После инкремента: 11 После декремента: 10

Другие формы изменения переменной

Разумеется, переменную можно изменять не только на единицу — любым способом:

Очки после штрафа: 90 Цена со скидкой: 100 Счётчик: 6

Заметьте: уменьшение на 10 — это уже не декремент. Инкремент и декремент — строго на единицу, всё остальное — просто изменение переменной.

Во всех случаях правило одно: сначала вычисляется правая часть, затем результат присваивается переменной слева — даже если это та же самая переменная.

Изменение через функции

Переменную можно «редактировать» и с помощью функций:

Модуль: 25 Громкость: 100

Здесь тоже действует то же правило: сначала функция вычисляет результат, потом он присваивается переменной. Переменная «переписывает» саму себя на основе своего же предыдущего значения.

Короткая форма: +=, -=, *=, /=

Запись N = N + 1 честная и понятная, но иногда она слишком длинная. Теперь, когда вы понимаете, что при этом происходит, можно писать короче — в Idyllium есть короткие формы присваивания:

11 8 16

Важно: это всё ещё присваивание. Просто правая часть записана короче. Компьютер читает N += 1 примерно так: «возьми старое значение N, прибавь 1, положи результат обратно в N».

ЗаписьЧто означает
N += 5N = N + 5
N -= 3N = N - 3
N *= 2N = N * 2
F /= 4F = F / 4 (только для float-переменных)

А почему /= — только для float? Вспомните урок об арифметике: деление / в Idyllium всегда даёт float. Поэтому для переменной типа int короткое деление не сработает:

main.idyl:5:10: compile error: cannot assign 'float' value to 'int' variable

Компилятор честен: 10 / 4 = 2.5, а дробное число в int не помещается. Для float-переменных /= работает отлично, а для int остаётся знакомое целочисленное деление div():

Цена: 50 Монеты: 50

Почему в Idyllium нет ++ и --?

В некоторых языках для инкремента и декремента есть специальные операторы-сокращения — отдельные значки, которые меняют переменную ровно на единицу. Idyllium сознательно обходится без них: такие значки маскируют суть операции — присваивание — и заводят отдельную грамматику ради одной-единственной единицы. Читаемость важнее.

При этом никакой силы мы не теряем: N = N + 1 говорит всё как есть, а N += 1 и N -= 1 делают то же самое для любителей краткости.

Практическое применение

Саморедактирование переменной — основа счётчиков, накопителей и ограничителей:

Попытка 1: введите пароль Попытка 2: введите пароль Попытка 3: введите пароль

Такие паттерны встречаются везде — от игр до баз данных.
