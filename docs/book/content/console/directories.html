Файлу понадобился дом

Пока файлов мало, их можно складывать рядом с main.idyl. Но у игры быстро появляются сохранения, картинки, настройки и таблицы уровней. Если свалить всё в одну кучу, найти нужный файл станет труднее, чем нужный носок в ящике после очень бодрой стирки.

Попытка сразу записать файл в несуществующую папку закончится ошибкой:

main.idyl:4: runtime error: file.open() cannot open 'saves/player.txt' for writing: directory does not exist

Вместо /home/user/my_game компилятор подставит полный путь к папке вашего проекта. Файл player.txt создать можно, но сначала программе нужна папка saves.

Создаём папку

Строка "Liam;12" — это имя игрока и его уровень, склеенные через разделитель ';': знакомый вам метод split() потом легко разберёт такую запись обратно на части.

Функция create_directory() создаёт одну папку. Её родитель уже должен существовать. Поэтому создать game/saves/players одним обычным вызовом не получится: сначала нет даже папки game.

Что находится по этому пути?

Функция exists() отвечает только на вопрос «что-нибудь здесь есть?». Иногда этого недостаточно: файл нельзя открыть как папку, а в папку нельзя записывать строки как в файл. Поэтому рядом живут проверки is_directory() и is_file(). Спросим про папку saves из прошлой секции:

true true false

Заодно exists() чинит неприятность с повторным запуском: создавайте папку, только если её ещё нет.

А list_directory() возвращает динамический массив с именами файлов и папок, лежащих непосредственно внутри указанной папки. Имена отсортированы, чтобы один и тот же проект не выдавал случайный порядок на разных компьютерах.

Соберём всё вместе: программа готовит папку, кладёт в неё два сейва и показывает содержимое. Запускать можно сколько угодно раз:

["player.txt", "world.txt"]

Копирование и переименование

copy() создаёт копию файла или целой папки вместе с её содержимым. rename() меняет путь существующего объекта: этой функцией можно и переименовать его, и перенести в другую папку. А list_directory() покажет, что получилось:

["liam_backup.txt", "player.txt", "world.txt"]

Обе функции откажутся работать, если путь назначения уже занят. Это защита от опечатки: программа не должна молча уничтожать старый файл только потому, что вы случайно указали его имя.

Удаление без неприятных сюрпризов

remove() удаляет файл или пустую папку. Если папка не пустая, обычный вызов остановится с runtime error. Так язык даёт возможность ещё раз проверить путь перед удалением целого дерева.

Поток ещё открыт?

Напоследок вернёмся ненадолго к потокам из прошлого урока. У входных и выходных потоков есть свойство is_open. Как и свойства меток времени, оно пишется без скобок: мы просто читаем состояние. Оно равно true до вызова close() и false после него, а записать в него ничего нельзя — переключает его только сам close().
