Задача: сколько всего очков?

У вас есть массив очков за семь уровней, и вы хотите узнать их сумму. После прошлых уроков вы уже умеете решать такое циклом:

Сумма очков: 284

Работает! Но пять строк кода ради одной суммы — многовато. А теперь то же самое в одну строку:

Сумма очков: 284

Никаких циклов, индексов и промежуточных переменных. Такой код короче, чище, и в нём просто негде ошибиться. Познакомимся с этим семейством функций поближе.

Четыре готовые функции

В Idyllium есть готовые функции для быстрого анализа числовых массивов:

  • max(arr) — возвращает наибольшее значение в массиве;
  • min(arr) — возвращает наименьшее значение;
  • sum(arr) — возвращает сумму всех ячеек;
  • avg(arr) — возвращает среднее арифметическое.

Эти функции работают и со статическими (array), и с динамическими (dyn_array) массивами.

Общий синтаксис

Функции принимают массив в качестве аргумента и возвращают результат:

Максимум: 84 Сумма: 284

Всё, что нужно, — передать функции имя массива.

Типы данных и совместимость

Функции работают только с числовыми массивами — int или float:

12

А вот выяснять, кто «больше» — кот или собака, — функция отказывается. Попытка передать ей строковый массив приводит к ошибке компиляции:

main.idyl:5:20: compile error: 'max' expects a numeric array, got 'array<string, 2>'

Компилятор сообщает прямо: max ожидает числовой массив, а получил массив строк.

Тип возвращаемого значения

Функции max(), min() и sum() возвращают значение того же типа, что и ячейки массива:

Сумма: 6, максимум: 3 Сумма: 7.25, максимум: 3.5

Целочисленный массив — целые результаты, дробный массив — дробные.

Особенность функции avg()

Среднее арифметическое вычисляется как sum(arr) / arr.length. А вы помните: в Idyllium деление всегда даёт float. Поэтому avg() всегда возвращает float, даже если массив состоит из целых чисел:

Среднее: 26.25 Вручную: 26.25

Это сделано для точности: среднее может быть дробным, даже если все исходные числа — целые. Причём float вернётся в любом случае — даже когда среднее получилось ровным. Компилятор не даст записать его в int:

main.idyl:5:13: compile error: cannot assign 'float' value to 'int' variable

Все четыре функции в деле

Максимум: 96 Минимум: 78 Сумма: 439 Среднее: 87.8
