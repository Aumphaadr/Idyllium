Типы char и string

Строки вы храните и выводите уже давно. Но как заглянуть внутрь строки — вытащить из слова первую букву, проверить последнюю или разобрать его по буквам, как конструктор? Для одного символа в Idyllium есть отдельный тип — char (от английского character — «символ»).

Строка — это массив символов

Это очень похоже на отношение «переменная ↔ массив» для чисел:

Точно так же:

  • char — один символ,
  • string — набор символов, то есть массив типа char.

Это означает: к отдельным символам строки можно обращаться по индексу, как к ячейкам массива.

Доступ к символам строки

Как и у массива, у строки можно получить любой символ по его индексу. Разберём гуся на буквы — и соберём обратно задом наперёд:

ьсуГ

В слове «Гусь» четыре символа — значит, допустимые индексы: от 0 до 3. А если запросить символ, которого нет, — например, десятый?

main.idyl:6: runtime error: string index 10 out of bounds (length 4, valid indices 0-3)

Строка ведёт себя как массив: индексация с нуля, выход за границы — ошибка выполнения. Гусь не резиновый.

Посимвольный перебор

Можно вывести каждый символ строки по отдельности:

П и н г в и н

Длина строки: свойство length

Если длина строки заранее неизвестна, прочитайте свойство length:

Птица: Страус, длина: 6 символов Птица: Фламинго, длина: 8 символов

Цикл с неизвестной длиной строки

Свойство length содержит число — значит, его можно подставить в цикл:

Ж у р а в л ь

Такой цикл работает с любой строкой — независимо от её длины.

Конкатенация строк и символов

Строки и символы можно соединять с помощью оператора +:

пиццавкусная пицца вкусная пицца вкусная!

В отличие от чисел, от перемены мест слагаемых — сумма меняется:

пицца вкусная вкусная пицца

Экранированные символы

Знакомый по прошлым урокам перенос строки \n — тоже символ. А раз символ, его можно положить в char:

Первая строка Вторая строка

Стоп. Почему символ '\n' записан в одинарных кавычках, хотя выглядит как два символа?

Потому что \ здесь не является отдельным символом — он экранирует букву n, превращая её в управляющий символ «новая строка». Вдвоём они обозначают один символ.

То же касается:

  • '\t' — символ табуляции;
  • '\'' — одинарная кавычка внутри char;
  • '\"' — двойная кавычка внутри string.

Экранирование позволяет вставлять в строку или символ управляющие последовательности и знаки пунктуации без путаницы.

Кто ты такой: функция type_name()

В большой программе легко забыть, кто такой vals и что мы добываем из него квадратными скобками: vals[i] — это ячейка массива или символ строки? Спросить можно у самого языка: глобальная функция type_name() называет тип любого значения строкой.

array<int, 3> int string char

Четыре ответа — вся сегодняшняя арифметика на месте: массив и его ячейка, строка и её символ. Имена типов пишутся ровно так, как их пишет компилятор в сообщениях об ошибках, — удобно сверять.
