Зачем программе сюрпризы?

Бросить кубик, подкинуть монетку, вытянуть карту из колоды — половина игр держится на честном «кто знает, что выпадет?». Но компьютер сам по себе сюрпризов не любит: он всегда делает ровно то, что написано в программе. Чтобы добавить в программу непредсказуемости, в Idyllium есть библиотека random:

После этого все функции из этой библиотеки вызываются по схеме: random.название(аргументы).

Случайное целое число: random.create_int()

Функция random.create_int(min, max) возвращает случайное целое число в диапазоне от min до max включительно:

Пример использования:

Каждый запуск программы будет давать новую тройку чисел. У нас, например, выпало так:

80 60 40

У вас числа будут свои — на то они и случайные. А бросок игрального кубика — это просто random.create_int(1, 6).

Случайное дробное число: random.create_float()

Функция random.create_float(min, max) генерирует случайное число типа float. Границы у неё такие же дружелюбные, как у create_int(): результат не меньше min и не больше max — выпасть могут обе границы. Правда, поймать ровно max — большая удача: дробных чисел между границами невообразимо много, и шанс попасть точно в край исчезающе мал.

Пример:

У нас, например, получилось:

Внутри числа хранятся с высокой точностью — до 15–16 значащих цифр. А вот при выводе Idyllium по умолчанию показывает не больше 8 знаков после точки, чтобы результат было удобно читать. Если нужно больше знаков, вызовите console.set_precision().

Псевдослучайность и сиды

Компьютер не умеет генерировать по-настоящему случайные числа — только псевдослучайные. Это такие числа, которые выглядят случайными, но на самом деле полностью определяются начальным значением, называемым сидом (англ. seed).

Если задать один и тот же сид, последовательность будет повторяться:

26 0 22 26 0 22 26 0 22

Как видите, при сиде 0 всегда генерируется одна и та же последовательность. Это полезно для отладки и воспроизводимых экспериментов.

Например, в Minecraft есть известный эксплойт RANDAR, основанный на предсказуемости генератора мира — и он работает именно потому, что мир строится на основе сида.

Смена сида — смена последовательности

В Idyllium сид генератора псевдослучайных чисел задаётся функцией random.set_seed():

26 0 22 61 49 7

Сид 0 → последовательность 26, 0, 22...

Сид 400 → новая последовательность: 61, 49, 7...

Бонус для любопытных: random.mulberry32()

Напоследок — экспонат из музея программистского быта. В некоторых языках нет удобных функций для генерации случайных чисел, и разработчикам приходится городить математические огороды — писать генератор самостоятельно. Один из самых знаменитых таких огородов — алгоритм mulberry32: несколько строк хитрых битовых операций, которые выдают следующее «случайное» число из предыдущего.

В Idyllium он встроен как random.mulberry32() — без аргументов, возвращает целое от 0 до 4294967295 (это максимум 32-битной ячейки — вспомните его, когда дойдёте до урока о библиотеке types):

50271532 266108690 4195786334

Он подчиняется тому же сиду, что и остальные функции библиотеки. Для повседневных задач create_int() удобнее — но теперь вы знаете, как выглядит «сырой» генератор, из которого такие удобства собирают.

Важное предупреждение

Библиотека random в Idyllium предназначена для игр, симуляций и учебных проектов. Для защиты секретов — например, паролей — она не годится: вы только что своими глазами видели, насколько предсказуемы её числа. А вот для броска кубика, случайного выбора карты или генерации лабиринта — в самый раз.
