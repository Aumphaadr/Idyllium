Зачем нужны файлы?

До сих пор всё, что делала ваша программа, исчезало после её завершения. Чтобы сохранить данные надолго — их нужно записать в файл.

Файлы позволяют:

  • Сохранять результаты работы (например, таблицу рекордов);
  • Загружать настройки или уровень игры;
  • Обмениваться данными между программами.

Библиотека file

Для работы с файлами в Idyllium используется встроенная библиотека file:

Она предоставляет два типа потоков:

  • file.ostream — для записи в файл (output stream);
  • file.istream — для чтения из файла (input stream).

Открытие файла для записи

Чтобы записывать данные в файл, нужно сначала открыть его функцией file.open():

Разберём:

  • file.ostream — тип объекта «поток вывода в файл»;
  • fout — имя этого объекта (можно любое);
  • file.open() — функция для открытия файла;
  • "output.txt" — имя файла (создастся, если не существует);
  • "write" — режим открытия: запись.

Запись данных: выполнение

После открытия файла можно записывать в него строки с помощью методов write_line() и write():

Оба метода принимают любое количество аргументов и собирают из них текст.

write_line() после текста сам добавляет '\n', как console.writeln(). Метод write() ничего не добавляет, как console.write(). Пустой вызов write_line() просто начинает новую строку.

Есть важное отличие от записи: файл для чтения должен уже существовать. Читать из пустоты не умеет даже Idyllium. Попробуем открыть файл, которого нет:

main.idyl:4: runtime error: file.open() cannot open 'treasure.txt' for reading: file does not exist

Вместо /home/user/my_game в сообщении будет полный путь к папке вашего проекта — так сразу видно, где именно программа искала пропавший файл.

Чтение файла построчно

Возьмём файл с тремя строками:

Кирка Топор Меч

Прочитаем его вручную:

["Кирка\n", "Топор\n", "Меч"]

Здесь возникают две проблемы:

  1. Строки содержат символ '\n' (кроме последней);
  2. Нельзя так читать файл, если количество строк заранее неизвестно.

Очистка строки: метод .trim()

Метод .trim() удаляет пробелы и управляющие символы (вроде '\n', '\t') только по краям строки — в начале и в конце. Всё, что внутри, остаётся нетронутым. Проверим:

[кот] [кот] [ко т]

Первые два кота избавились от «шубы» из пробелов, табуляций и переводов строк, а третий сохранил пробелы внутри себя — .trim() в середину строки не заглядывает.

Именно то, что нужно, чтобы очистить прочитанные из файла строки от хвостика '\n':

["Кирка", "Топор", "Меч"]

Теперь строки «чистые» и готовы к использованию.

Прочитать весь файл сразу: метод read_all()

Построчное чтение удобно, когда файл похож на список: одна строка — один предмет, одна команда или одна запись.

Но иногда файл хочется забрать целиком. Например, если внутри лежит большой текст, HTML-страница или JSON-данные. Для этого у file.istream есть метод read_all(). Возьмём файл story.txt:

Дневник шахтёра День 1. Нашёл уголь. День 2. Нашёл алмазы!
Дневник шахтёра День 1. Нашёл уголь. День 2. Нашёл алмазы!

Метод read_all() читает всё, что осталось в файле от текущего места до конца. Если до него уже вызывали read_line(), то первые прочитанные строки повторно не вернутся:

Заголовок: Дневник шахтёра Остальной текст: День 1. Нашёл уголь. День 2. Нашёл алмазы!

Это поведение удобно: можно сначала отдельно прочитать заголовок, а потом забрать весь оставшийся текст одним действием.

Прочитать ровно несколько символов: read(n)

А если нужно точное количество символов, передайте его в метод read(). Вызов read() без аргумента работает как read_all() — забирает всё оставшееся. Для файла word.txt со словом:

котики
Первые три символа: кот Остаток: ики

Считаются символы, а не байты, поэтому кириллица и эмодзи не ломают такое чтение. Если до конца файла осталось меньше символов, чем вы попросили, метод просто вернёт оставшийся текст.

Итог: инструменты одной таблицей

Режимов открытия в Idyllium ровно два — "write" для записи и "read" для чтения. А вот и все методы урока:

ИнструментЧто делает
file.open("out.txt", "write")Открывает файл для записи, возвращает file.ostream. Создаёт файл, если его нет
fout.write(...)Записывает аргументы в файл, ничего не добавляя
fout.write_line(...)Записывает аргументы и добавляет '\n'
file.open("in.txt", "read")Открывает существующий файл для чтения, возвращает file.istream
fin.read_line()Читает одну строку (вместе с '\n', если он есть)
fin.has_next_line()Возвращает true, если в файле остались непрочитанные строки
fin.read_all()Читает всё от текущего места до конца файла
fin.read(n)Читает n символов; без аргумента — как read_all()
fout.close() / fin.close()Закрывает файл — обязательный финал любой работы с потоком
строка.trim()Убирает пробелы и управляющие символы по краям строки
