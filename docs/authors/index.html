Юниты Idyllium для вашего сайта

Юнит — маленькое окно с редактором кода, консолью и кнопками «Запустить» и «Проверить», которое встраивается в страницу любого сайта. Ученик пишет программу прямо в уроке, а юнит сам проверяет решение на ваших тестах и говорит, сошлось ли. Ничего не нужно устанавливать ни вам, ни ученику.

Соберите юнит в конструкторе ниже — справа он сразу живой, в нём можно запускать программы и пробовать проверку. Когда всё готово, скопируйте HTML и вставьте на свой сайт. Незаконченную работу можно сохранить в файл и открыть завтра — или передать администратору сайта, чтобы он дописал свою часть.

Как вставить юнит на сайт — три рецепта
  1. Свой HTML (сайт на своих страницах, GitHub Pages, Tilda с блоком «HTML-код» и т. п.): вкладка «Полная вставка». Это строка со скриптом и блок <idyllium-unit>. Скрипт достаточно подключить один раз на странице, блоков может быть сколько угодно.
  2. Платформа пускает только iframe (многие LMS и конструкторы вырезают скрипты): вкладка «Только iframe». Весь юнит упакован в адрес — больше ничего не нужно. В этой форме сайт не получает событий проверки, а код ученика не сохраняется между визитами.
  3. Реакция сайта на проверку (для администратора): в блоке «Реакция сайта» впишите имена функций вашей страницы. Юнит вызовет их с одним аргументом — объектом { unit, verdict, passed, total, attempt, firstFailure }. Программистам удобнее события на элементе: idyllium-check, idyllium-solved, idyllium-failed, idyllium-run.

5. Ввод и тесты

Кнопка «Проверить» запускает программу ученика на каждом тесте. Один тест ничего не доказывает: программа «w * 4» вместо периметра проходит ввод «1 1». Дайте хотя бы два-три разных, а для ветвлений — по тесту на каждую ветку.

6. Проверка

Условия пишутся как в Idyllium: and, or, not, ==, abs(), mod(). Значения теста — в фигурных скобках. Приглашения вроде «Введите радиус: » в ответ не попадают.

Вывод программы сравнивается с этим текстом по строкам; пробелы в конце строк и пустые строки в конце прощаются.

Программа ученика и ваше решение (блок 8) запускаются на одних и тех же тестах, ответы сравниваются по значениям. Важно: в этом режиме решение уезжает в HTML страницы — любопытный ученик сможет его найти.

Юнит будет просто песочницей: кнопки «Проверить» в нём не будет.
