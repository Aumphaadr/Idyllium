Дата: 2026-07-24. Оценены все уроки `docs/book/content/widgets/` (собранный учебник — то, что видит ученик) по критериям Т1–Т12/АТ1–АТ10 из [conspect-criteria.md](conspect-criteria.md). ## 2. Сквозные паттерны

### Хорошие новости

1. **Компилируемость образцовая**: ~99 проверок `cli check`, все полные примеры всех 21 урока компилируются; падают только намеренные примеры-ошибки. Флаги `program-compile-failure` в lessons.json для этого раздела устарели в лучшую сторону (кроме errors, где «падения» — задумка).
2. **Устаревший GUI-синтаксис вычищен полностью**: ни строковых цветов, ни `.color`, ни `fill_color`, ни `gui.Image` нет нигде — миграция на `colors.Color`/`text_color` доведена до конца (включая inline-правки в сборке для label/slider/lineedit/frame).
3. **Интерактивные HTML-демо — суперсила раздела**: почти все повторяют логику кода попиксельно; демо no_echo, двух групп RadioButton, модальных окон — образцовые.
4. Прогрессия зависимостей честная: visibility→Frame, arrays→консольные массивы, sender используется дальше как норма; Canvas нигде не опережается.

### Системные слабости (по убыванию важности)

1. **Фантомный API в timer.html**: `running` (ro-свойство) и `restart()` описаны в опорных списках урока, но их нет ни в компиляторе (`error: type 'gui.Timer' has no member 'running'` / `no method 'restart'`), ни в api.json. Урок — единственный источник. Ребёнок, попробовавший restart() из шпаргалки, получит ошибку компиляции. (Это разрешает вопрос B1 из inconsistencies.md: **registry прав, урок врёт** — либо API задумывался и не реализован → вопрос команде компиляции.)
2. **errors.html — половина цитат ошибок неточна**: `parameter type 'gui.Label' does not match event type 'gui.Button'` → реально `callback property 'on_click' expects function(): void or function(gui.Button): void, got function(gui.Label): void`; `cannot assign 'int' to 'string' property 'text'` → `cannot assign 'int' value to 'string' variable`; `cannot add 'gui.Modal' to window (Modal is not a widget)` → `'add_child' argument 1 expects gui widget, got 'gui.Modal'`. Формат без колонки. То же, что было в консоли до редактуры.
3. **Т9 почти отсутствует**: секции типичных ошибок есть только в label (текст-парафраз) и image (точный). У остальных 19 уроков — ноль, при очевидных кандидатах (запись в read-only `selected_text`, координаты относительно рамки, value вне min/max, volume=4).
4. **Т7 системно проседает**: опорные таблицы свойств/событий виджета — только в progressbar, colors, spinbox (+шпаргалка sender); в остальных свойства рассыпаны по прозе.
5. **Два авторских слоя со швом**: мигрированные уроки (widgets/0NN) — интерактивные демо + эмодзи, но пустые мотивации; manual-уроки (colors, fonts, image, audio) — живой голос и мотивации, но демо мало (fonts — ноль). Ни один слой не собирает оба достоинства.
6. **Т1-каталожность**: больше половины уроков открываются «Что такое X?» + эмодзи-список «Где встречается» вместо проблемы из пройденного. Мотивация colors вообще ссылается на «старые примеры», которых в учебнике уже нет (след миграции).
7. **Демо-рассинхроны точечные**: button (тройная путаница «Нет, мой!»/«Нет, мой лейбл!»), frame (рамка вылезает за окно — демо маскирует), image (сдвиг всех позиций на 10px), colors (смягчённые цвета, лишний border), sender/modal (мелочи).
8. Гигиена: мёртвые `use console;` (lineedit ×3, modal), однострочные if без скобок (radiobutton), «полная программа» без show (combobox), audio не упоминает loop/position/on_finished (самый детский сценарий — зацикленная музыка — не показан).

## 3. Приоритеты будущих правок (когда решим править)

1. timer — убрать `running`/`restart()` (или дождаться реализации в языке — вопрос команде компиляции).
2. errors — реальные тексты по образцу консольной редактуры (все репро прогнать; починить E5).
3. fonts — демо, источник файла шрифта, перенести аналогию с ImageBox.
4. frame — геометрия примера 2 + секция типичной ошибки координат.
5. Точечные демо-рассинхроны (button, image, colors, sender).
6. Т9-секции и Т7-таблицы по всем урокам; мотивации-связки; гигиена.

Механика правок готова: рецепт миграции в manual-content описан в [lessons-format-and-migration.md](lessons-format-and-migration.md) и отработан на консоли.
