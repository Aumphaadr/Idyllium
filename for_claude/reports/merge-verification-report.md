# Сверка слияния с веткой команды компиляции

Дата: 2026-07-24 (вечер). Проверено: технические исправления рантайма/компилятора и соответствие «документация ↔ фактическое поведение» после подтягивания актуальной версии проекта.

## 1. Пробы исправлений — всё подтверждено

| Исправление | Проба | Результат |
| --- | --- | --- |
| stdin-буфер CLI | `printf "40\n2\n"` одним куском | ✅ оба значения читаются (42) |
| Пути в file-ошибках | открытие несуществующего файла | ✅ относительный путь: `cannot open 'treasure.txt' ...` |
| Бесконечная рекурсия | timeout-прогон | ✅ читаемое `main.idyl: runtime error: maximum call depth exceeded (check the recursion in function 'bad_sum' — it needs a stop condition)`; ⚠️ перед ним по-прежнему дважды печатается сырой `Exception in PromiseRejectCallback / RangeError` — единственный оставшийся шум |
| gui.Timer.running / restart() | check | ✅ компилируются — API реализован |
| time.stamp.millisecond | run | ✅ работает (0 для from_unix(0)) |
| Печать объекта класса | run | ✅ теперь ошибка компиляции: `cannot print object of class 'Cat' directly` |
| Диагностика деструкторов | check | ✅ вернулось `destructors are not supported yet` |
| math.abs | run | ✅ сохраняет тип аргумента (int→int, float→float) |

Новое поведение: **печать float по умолчанию — до 8 дробных цифр с обрезкой хвостовых нулей** (`0.1 + 0.2` → `0.3`, `math.sqrt(2)` → `1.41421356`); `console.set_precision(25)` раскрывает полное значение. ai-reference обновлён командой и закрыл пробелы из [inconsistencies.md](inconsistencies.md): дефолтные значения (B13), порядковые сравнения (B14), модель памяти значений/ссылок (E1), формат печати float, семантика bare-объявления объектов.

## 2. Тесты команды

`spec:extract` + `lesson-spec` + `lesson-runtime`: 373/373 валидных standalone-программ учебника компилируются; 28 json/sqlite-программ выполняются. Команда добавила собственный контур прогона уроков (`tests/lesson-runtime.test.ts`) — покрывает выполнение sqlite/json без сверки выводов.

## 3. Дословная сверка уроков с новым рантаймом

Собственный сверщик: все пары «код-блок → output/error-блок» разделов console и widgets, детерминированные примеры — `run` с побайтовым сравнением, GUI-ошибки — `check`. **239 блоков проверено, 225 дословных совпадений, 14 «расхождений» — все разобраны как артефакты методики** (примеры с состоянием-цепочкой, входными файлами из урока, ANSI-кодами в сыром потоке, runtime-ошибки GUI, недоступные check-у) и добиты адресными пробами (audio volume, image scale/rotate — тексты в уроках актуальны).

Слияние оказалось взаимно-аккуратным: команда сохранила мои правки (constants, if, errors и др. — целы), сама обновила уроки под новые поведения (increment под abs→int, math-basics/math-advanced под новую печать float, timer под реализованный API — с сохранением моих шпаргалки и секций ошибок, часть путей в directories).

## 4. Мои добивочные правки (6 файлов)

1. `console/math-basics.html` — «abs всегда возвращает float» → «возвращает тип аргумента» (утверждение стало ложным после фикса).
2. `console/recursion.html` — error-блок и разбор заменены на новое читаемое сообщение (с именем функции и подсказкой); упоминание остаточного RangeError-шума смягчено и оставлено, пока шум жив.
3. `console/files.html` — абзац про «полный путь в сообщении» переписан под относительные пути.
4. `console/directories.html` — то же + error-блок `path already exists: saves` (был абсолютный путь).
5. `widgets/timer.html` — шпаргалка дополнена `restart()` и `running`, финальная фраза приведена в согласие с новым текстом команды («stop+start — пауза, restart — честный перезапуск»).
6. `console/time.html` — строка `.millisecond` (0–999) добавлена в таблицу свойств stamp (в ai-reference и api.json уже было, в уроке — нет).

Повторный свип после правок: стабильные 225/239, сайт пересобран (110 уроков).

## 5. Оставшееся для команды

1. **Шум перед сообщением рекурсии**: два сырых блока `Exception in PromiseRejectCallback ... RangeError: Maximum call stack size exceeded` до читаемой строки.
2. Из старого списка остаются нерешёнными (не блокеры): «parent() первым» — по-прежнему не проверяется компилятором (уроки подают как правило); каскадные `type '<error>'`-ошибки после первичной; вопрос `PRAGMA foreign_keys=ON` для sqlite.
3. Для будущей редактуры ООП: урок this.html снова верен по сути (печать объекта — ошибка), но цитирует старый формат без колонки.
