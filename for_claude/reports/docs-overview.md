# Карта документации `docs/` проекта Idyllium

Дата: 2026-07-24. Всего 338 файлов, ~27 МБ. `docs/` — это одновременно **исходники знаний** о языке и **собранный статический сайт** для GitHub Pages (Web IDE + учебник + справочник).

## Что где лежит

| Путь | Что это | Статус |
| --- | --- | --- |
| `ai/idyllium-ai-reference.md` | Компактный нормативный справочник для ИИ-ассистентов (EN, 59 КБ, 32 раздела). Самый полный текст о языке; версия 1.1.3. Правило: «не выдумывать синтаксис» | ✅ актуален |
| `reference/` | SPA «взрослого» справочника + `api.json` (312 КБ): русские разделы о языке (10 тем) + машинные сигнатуры 15 модулей, генерируется из standard library registry (`npm run docs:site`); сгенерирован 2026-07-19 | ✅ актуален,但 `extends` не выражен |
| `book/` | SPA детского учебника: `lessons.json` (оглавление: 7 разделов, 110 уроков) + `content/<раздел>/<slug>.html` — фрагменты уроков. URL вида `/book/#/console/hello`. Нумерация — по порядку в lessons.json, файлы названы смысловыми slug'ами | ⚠️ жив, но несёт реликты старого языка (см. inconsistencies.md) |

## Учебная линия (`book/lessons.json`)

1. **Консоль** — 32 урока: установка, hello, переменные/типы, const, ввод, арифметика, ANSI-вывод, преобразования, math, if/bool, «инкремент» (через `+= 1`), random, логика, циклы, массивы (стат./дин./функции/методы), char, строки, time, types, encoding, функции, свои библиотеки, файлы, папки, продвинутый math, 2D-массивы, рекурсия, типичные ошибки, try/catch.
2. **Виджеты** — 21: окно, кнопки, Label, ProgressBar, цвета, шрифты, SpinBox/FloatSpinBox, Slider, LineEdit, картинки, CheckBox, RadioButton, Frame, ComboBox, видимость, звуки, массивы виджетов, отправители (sender), Timer, Modal, ошибки.
3. **ООП** — 13: введение, класс, поля/методы, this, модули/файлы, массивы объектов, конструктор, композиция, наследование, полиморфизм, инкапсуляция, static, ошибки.
4. **Canvas** — 19: первый canvas, drawable, once/loop, клавиатура, плавное движение (pressed keys), кнопки мыши, движение/колесо, модули, шрифт/текст, картинки/спрайты, массивы объектов, origin/вращение, временные объекты, звук, hit-test точка-в-прямоугольнике/круге, коллизии кругов/прямоугольников, встроенные contains/collides_with.
5. **JSON** — 10: файлы-повторение, первый объект, чтение, массивы, вложенные объекты, массивы объектов, методы массивов/объектов, JSON+ООП, ошибки.
6. **SQLite** — 14: первая БД, таблицы/записи, чтение строк, параметры, поиск/фильтры, null, много записей, транзакции, SQL-скрипты, агрегаты, повторный запуск/DEFAULT, ключи/UNIQUE, связи/JOIN, ошибки.
7. **Примеры задач** — 1: «Калькулятор» — **заглушка**, урок не написан.

Порядок «Canvas после ООП» — осознанный: игровые Canvas-проекты используют классы, коллбэки и разбиение на модули.

## Конвейер сборки

`packages/docs-book/`, `packages/docs-reference/` (исходники оболочек) + `docs/manual-content/` (ручной педагогический контент: 58 файлов в 7 папках — новые уроки и `patches/` к мигрированным, например `console-increment-extra.html`) → `npm run docs:site` → `docs/` (готовый сайт: `book/`, `reference/`). Основная масса `book/content/**` пришла из мигратора (исторический слепок — `packages/docs`); ручные правки внутри сгенерированных `docs/book/` и `docs/reference/` затираются при пересборке — править нужно manual-content/патчи.

| Документ | Аудитория | Язык | Стиль |

Тройное дублирование — сознательное; цена — рассинхронизация (см. inconsistencies.md, разделы B и C).
