## Находки за пределами уроков (техдолг проекта)

1. **Баг CLI**: при подаче нескольких строк stdin одним куском (`printf "a\nb\n" | cli run`) readline теряет строки после первой — программа молча завершается до чтения второго значения. Два редактора обошли это «капельной» подачей с задержками. Стоит завести issue на `src/cli.ts`.
2. **Пути в file-ошибках**: рантайм печатает абсолютный путь (`/home/user/.../saves/player.txt`), Web IDE — `/workspace/...`. В уроках использованы плейсхолдер и пояснение; возможно, стоит печатать проектно-относительные пути.
3. Формат диагностик компиляции теперь с колонкой (`file:line:col:`) — ai-reference цитирует без колонки; при следующей правке референса стоит синхронизировать.
4. Бесконечная рекурсия падает с «сырым» `RangeError: Maximum call stack size exceeded` без `main.idyl:строка` — читаемая ошибка рантайма здесь бы соответствовала философии языка.
