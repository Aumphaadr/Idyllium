# Ревью 32 уроков раздела «Консоль» по критериям конспектов

> **Статус: правки по этому ревью выполнены 2026-07-24** — см. [console-lessons-edit-report.md](console-lessons-edit-report.md). Таблица ниже описывает состояние ДО редактуры.

Дата: 2026-07-24. Каждый урок `docs/book/content/console/*.html` оценён как конспект по критериям Т1–Т12 / АТ1–АТ10 из [conspect-criteria.md](conspect-criteria.md). Оценивали 4 параллельных ревьюера (по 8 уроков), урок if.html дополнительно проверен вручную (оценки совпали). Ревьюеры также перепроверяли арифметику примеров, битовые представления и unix-метки.

Шкала: **хороший** → скорее хороший → смешанный → скорее плохой → плохой.

## 2. Сквозные паттерны (по всем 32 урокам)

### Сильные стороны раздела

1. **«Строгость = забота»** — фирменный голос курса: рефрен «это не ограничение — это защита» проходит через variables, input, arithmetics, transforms, directories, if. Это лучшее, что есть в разделе, и оно уникально для детских учебников.
2. **Сюжетные уроки умеют всё**: там, где есть паттерн «проблема → потребность → конструкция» (if, input, dyn-array, files, functions, constants), он реализован образцово — команда умеет писать «хорошие конспекты» по всем Т-критериям.
3. **Сшивка соседних уроков местами эталонная**: array→char (эхо-определения), colors→transforms (трюк с покраской через to_string), files→directories (старт от ошибки прошлой темы), errors→try-catch (дословная опора). 
4. **Юмор дозирован и работает** (ЪУЪ, 64 алмаза, «Рома здоров. Свободен. Следующий!», носок после «очень бодрой стирки», RANDAR из Minecraft).
5. Т10 (только язык курса) соблюдён в 27 из 32 уроков; Т4 (без опережений) — почти везде.

### Системные слабости (по частоте)

1. **«Каталожные» уроки без мотивации (Т1)** — 8+ уроков начинаются с «Подключение библиотеки X» или списка методов: math-basics, random, arr-methods, string-methods, time, math-advanced, arithmetics, bool. Паттерн лечится одним абзацем-затравкой.
2. **«Немые листинги» (Т5/Т12)**: ключевые новинки урока не печатают ничего — результат живёт в комментариях. Апофеоз: bool и libs — ноль output-блоков на урок; arithmetics (div/mod), transforms (to_*), types (переполнение — гвоздь урока!) — немые.
3. **Ошибки без лица (Т9)**: точные тексты ошибок есть лишь в 6 уроках (constants, encoding, functions, directories, errors, try-catch). Остальные 26 обходятся `// Ошибка: ...` или словами. Формат idyl-error-block с `main.idyl:N: error: ...` надо растиражировать.
4. **Нет опорных таблиц (Т7/АТ7)**: ни один «методный» урок (files ~9 методов, directories ~8, math-advanced ~10, arr-methods 8, string-methods, time, colors-коды) не сводит ядро в таблицу «метод — что делает — что возвращает». Будущий словарь формулировок заданий не формируется.
5. **Чужие языки (Т10/АТ9) в 5 уроках**, причём кодом: hello (print Python), increment (`N++` + C++/Java/JS), random («как в Python или JavaScript»), bool (code-блок Python), types (C++/Java/Rust как мотивация).
6. **Битые примеры и фактические ошибки**: matrix — «Сумма: 1424» при реальной 1231 (единственное проверяемое число урока!) и заполнитель `[ /* ... */ ]` в «полном» примере; increment — `N /= 4` для int (противоречит правилу «/ всегда float»); if/array — скобка `}` проглочена комментарием в примерах-ошибках; arithmetics — листинг с ошибкой компиляции показан с выводом.
7. **Следы несведённых итераций**: секции, дописанные ПОСЛЕ якоря `<!-- Lesson navigation -->` (increment, colors, files, types), `<section>` вместо `div.docs-section`, двойные `<!-- Section 3 -->`, потерянная секция 8 в errors.
8. **Межурочные рассинхроны**: печать массива строк с кавычками (string-methods) и без (dyn-array); float — 13 знаков в math-basics vs 16 в random; `+=` введён в №11, но loops/array/dyn-array/functions пишут `i = i + 1` (закрепление упущено; encoding использует); два формата file-ошибок (directories vs errors); в errors устаревшая формулировка `cannot assign 'float' to 'int'` рядом с полной парной.
9. **Голос адресата плавает**: обращения к учителю/автору внутри детского текста (setup, input, colors: «объяснять ученику…», «ученик обязан понимать…», «вы пишете программу для начинающих»).
10. **Опережения точечные, но грубые**: constants использует `writeln` (№7) и `void function` (№24); random — тип `char` (№16); внутри time секция зон использует `from_unix`/`.unix` до их введения.

### Отдельные решения

- **errors.html (жанр-каталог)** — жанр работает: формула «репро → дословный текст → совет» выдержана в ~20 записях, каталог играет роль Т7-опоры целого раздела. Починить: потерянную секцию, заголовок «строки» с примером про массив, перенести «Как читать сообщения» в начало, объяснить warning (единственное сообщение без номера строки при заявленных «двух типах»).
- **types.html** — кандидат №1 на разбиение (целые+переполнение / bin+hex / float+IEEE+сдвиги) или перенос в факультатив; вычистить чужие языки из мотивации; ввести set_precision.
- **try-catch** содержит 3 задания «Попробуйте сами» — единственный урок с заданиями; решить: легализовать формат для всех уроков или убрать.
- **Шутка «нар»/`clear()`/«котики»** (colors) собирает слово «наркотики» — заменить (пример пришёл из documentation-migration.md, поэтому заодно поправить и там).
- Раздел не имеет финала: try-catch обрывается без итога всей «Консоли» (напрашивается страница-капстоун «что вы теперь умеете»).

## 3. Приоритеты правок (сводно)

1. **Фактические ошибки**: сумма в matrix (1424→1231), `N /= 4` в increment, битые скобки-в-комментариях (if, array), листинг-с-ошибкой-и-выводом в arithmetics.
2. **Дать выводы немым листингам** (bool и libs — целиком; div/mod, to_*, переполнение в types) и **привести тексты ошибок к актуальному компилятору** через idyl-error-block (связка с C-разделом inconsistencies.md).
3. **Дописать мотивации каталожным урокам** (по одному абзацу «проблема → зачем»).
4. **Вычистить чужие языки** из 5 уроков (философия языка это прямо запрещает — «Do not replace Idyllium syntax with…» относится и к учебнику).
5. **Добавить опорные таблицы** методным урокам.
6. Починить опережения (constants — переписать на write без функций; random — убрать char; time — переставить секции).
7. Разбить types; унифицировать печать массивов строк, формат float, `+=`, компоненты ошибок; убрать «нар/котики»; единый голос «к ребёнку».
