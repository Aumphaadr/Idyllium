### 21. errors — «Типичные ошибки» — скорее плохой
**Жанр:** формула «репро → текст → совет» выдержана в 9 записях; отличное разделение «ошибка компиляции» vs «компилируется, но не работает» (E1 забыли add_child, E2 перекрытие, E6 забыли start — компилируются, проверено); покрытие широкое.
**Слабое — точность текстов провалена наполовину (3 из 6 цитат не совпадают с компилятором):**
- E3: «parameter type 'gui.Label' does not match event type 'gui.Button'» → реально `main.idyl:8:20: error: callback property 'on_click' expects function(): void or function(gui.Button): void, got function(gui.Label): void`;
- E4: «cannot assign 'int' to 'string' property 'text'» → `main.idyl:6:18: error: cannot assign 'int' value to 'string' variable`;
- E7: «cannot add 'gui.Modal' to window (Modal is not a widget)» → `main.idyl:6:19: error: 'add_child' argument 1 expects gui widget, got 'gui.Modal'`;
- E9: почти — потерян префикс «type» в `type 'gui.Button' has no property 'placeholder'`.
Репро E5 грязный: без `use console;` даёт 3 ошибки вместо 1 заявленной. §10 описывает формат «file:строка:» — реально с колонкой. Нет ни одной audio-ошибки (volume — готовый кандидат).
**CLI:** 9/9 репро прогнаны; E8 (границы массива) — текст корректен.
**Особое:** lessons.json сам помечает урок `program-compile-failure`, `teaching-errors` — проблема известна, не исправлена.
