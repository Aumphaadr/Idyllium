		Задание 1
Напишите следующий код:
main.cpp
#include <iostream>

using namespace std;

int main()
{
	int NUM;
	cout << "Введите число от 1 до 100: ";
	cin >> NUM;

	if (NUM > 50)
	{
		cout << "Вы ввели число больше 50" << endl;
	}
}
Запустите эту программу два раза:
    • При первом запуске введите число больше 50 (например, 67)
    • При втором запуске введите число меньше 50 (например, 32)
Также можете запустить программу третий раз и ввести число 50.
Сравните полученные результаты.
