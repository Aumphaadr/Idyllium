# Аудит порядка уроков «Консоли»: забегания вперёд

Проверка каждого урока на использование конструкций из будущих тем. Состояние — 2026-07-24, после переноса time (№14), констант (№15) и разделения types (№22+№23). Важно: с введением доктрины «ходов конём» (см. [README.md](README.md)) не всякий забег — нарушение; сознательные забеги легитимны, если не плодятся без необходимости.

## Исправлено переносами уроков

1. **constants использовал `*` до урока арифметики** (старая позиция 4 < арифметика 5): `const int TOTAL_CELLS = ROWS * CELLS_IN_ROW;`. Решено переносом урока на позицию после циклов. Заодно реализовано пожелание владельца: константы после «шишек» с переменными, перед массивами. (2026-07-25; после переноса time константы — №15.)

## Признанные «ходы конём» (НЕ нарушения)

2. **input (№4) использует `+` до урока арифметики (№5)**: пример периметра `int P = A + B + C;`. Ранее аудит рекомендовал упростить пример до эхо-программы — **рекомендация ОТОЗВАНА** решением владельца (2026-07-24): базовая арифметика `+ - *` — школьный фоновый багаж, доступный с урока «Переменные». Урок арифметики при этом не пустеет: его настоящее содержание — правила типов результата (см. карточку №5 лестницы).
3. **«Птичье» использование функций до урока №25**: `console.write()` со №2, `math.abs()` с №8 — практический паттерн «вызов → аргументы → присвоить результат» без понимания устройства. Легитимно; полное раскрытие — №25.

## Проверено и признано нормой

- **`use math;`/`use random;`/`use time;` и т.д. до урока libs (№26)**: не нарушение — «подключение библиотеки» фактически введено в hello (`use console;`) и math-basics; урок libs учит СОЗДАНИЮ собственных библиотек, а не использованию готовых.
- **random (№11) упоминает char и массивы** — только анонсы («о них позже»), кода нет. Анонс прав не даёт, нарушения нет.
- **time (№14) вводит точечные свойства (`t.year`) и первый метод (`in_timezone`)** — вводит явно, с объяснением «скобки не нужны: читаем состояние». После переноса time именно этот урок, а не char, первым знакомит с точечным доступом. Норма.
- **char (№17) вводит `.length`** — теперь второе точечное свойство после свойств time.stamp; по-прежнему вводится явно. Норма.
- **files (№27) использует `dyn_array.add`** — dyn-array пройден в №18. Норма.
- **errors (№32) показывает ошибки из всех пройденных тем** — по построению урок-каталог, всё из прошлого. Норма.

## Инструменты языка, которые существуют, но НЕ введены ни одним уроком раздела

Генератору заданий их требовать нельзя нигде в «Консоли» (сверяться при обновлениях уроков):

- Отрицательные значения/переполнения `to_int` больших строк.
- Дробные секунды в `time.from_unix(…)` — язык умеет, урок не рассказывает (`.millisecond` метки с 2026-07-24 введён в №14).
- `array.length` у СТАТИЧЕСКОГО массива в уроке array (№16) не упоминается (появляется в контексте строк №17 и dyn_array №18); формально до №17 «длина» известна только из объявления.

Закрыто обновлениями 2026-07-24 (больше не в списке):

- ~~`types.*.bit_and/bit_or/bit_xor/bit_not`~~ — теперь введены уроком №23 «Битовые операции».
- ~~`string.trim()` до №26~~ — с 2026-07-25 ВВЕДЁН полноценной секцией в №21 (по указанию владельца); в files (№27) — повторение в боевых условиях.
- ~~`time.stamp.millisecond`~~ — введён в уроке time (№14).
