# Задачник: Улучшенный вывод текста

Урок №6 раздела «Консоль». Составлен 2026-07-31 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод». Цвет на бумаге не показать — цветные строки помечены словами.

**Для преподавателя.**
- *Доступно:* всё из уроков 1–5 — переменные (int/float/string), ввод (`get_int/get_float/get_string`), арифметика (`+ - * /`, `div`, `mod`); из новой темы — `console.writeln()` (авто-перенос), экранирование кавычек `\"`, табуляция `'\t'`, ANSI-цвета `"\e[31m"`(тёмные 30–37, светлые 90–97), сброс `"\e[0m"`, «цвет действует, пока не сменишь», `console.clear()`.
- *Нельзя (рано):* `to_string` (№7 — код цвета из числа собрать нельзя, только готовые строки!), `math.*` (№8), `if` (№9), `random` (№11), циклов (№13). Палитру не перебрать циклом — красим строки руками, и это нормально.
- *Словарь:* экранирование, табуляция, ANSI-последовательность, сброс эффектов, очистка консоли.

Тема — про красоту и заботу о читателе: перенос без возни, кавычки в тексте, ровные колонки, цвет по делу. Ученик четыре урока таскал `'\n'` вручную — `writeln` придёт как долгожданное избавление. **Важно:** поломки (пропущенный слеш, утёкший цвет, битая последовательность) ученик открывает сам — не показывайте заранее, что получится.

# Блок 1. `writeln`: перенос больше не ваша забота

## Практика с преподавателем

### Задание 1. Прощай, `'\n'`

Четыре урока подряд вы прилежно дописывали `'\n'` к каждой строке. Хватит. Наберите:

```idyllium
use console;

main() {
    console.writeln("Первая строка");
    console.writeln("Вторая строка");
    console.writeln("Третья строка");
}
```

```
Первая строка
Вторая строка
Третья строка
```

`writeln` — это тот же `write`, но перенос строки он добавляет **сам**, в самом конце. Ни одного `'\n'` в коде — а строки не слиплись. Меньше писанины, меньше шансов забыть перенос.

## Самостоятельная практика

### Задание 2. Меню кафе

Выведите меню кафе — заголовок и три блюда, каждое с новой строки. Всё через `writeln`, ни единого `'\n'`.

```
--- Меню кафе «Уют» ---
Блинчики с мёдом
Какао с зефиром
Сырники со сметаной
```

### Задание 3. Пересадка на новый двигатель

Перед вами код в старом стиле. Спишите его и **переделайте на `writeln`** — уберите все `'\n'`:

```idyllium
    console.write("Утро доброе!", '\n');
    console.write("Сегодня отличный день.", '\n');
    console.write("Пора программировать.", '\n');
```

Запустите обе версии и убедитесь: вывод одинаковый, а нового кода — заметно меньше. Почувствуйте разницу руками: это и есть причина, по которой `writeln` придумали.

### Задание 4. Каждому своё

А когда `write` всё ещё нужен? Когда курсор должен **остаться в той же строке** — например, в приглашении к вводу. Напишите программу: приглашение «Как тебя зовут:» через `write` (курсор ждёт рядом), а ответ — через `writeln`.

```
Как тебя зовут: Мира
Привет, Мира! Отличное имя.
```

Запомните пару: `write` — для строк из кусочков и приглашений, `writeln` — для законченных строк.

# Блок 2. Кавычки и ровные колонки

## Практика с преподавателем

### Задание 5. Кавычки внутри кавычек

Как вывести кавычки, если ими же обозначаются границы строки? Поставить перед ними обратный слеш `\` — «экранировать». Наберите:

```idyllium
use console;

main() {
    console.writeln("Игра \"Minecraft\" вышла в 2009 году");
}
```

```
Игра "Minecraft" вышла в 2009 году
```

Слеш шепчет компилятору: «эта кавычка — часть текста, а не конец строки». В выводе слеша не видно — только кавычки.

### Задание 6. Колонки через Tab

Символ `'\t'` — табуляция, широкий отступ, как клавиша Tab. Наберите:

```idyllium
use console;

main() {
    console.writeln("Товар\tЦена");
    console.writeln("Зелье\t150");
}
```

```
Товар	Цена
Зелье	150
```

Числа встали друг под другом — получилась таблица без единого лишнего пробела.

## Самостоятельная практика

### Задание 7. Любимая книга

Выведите строку о любимой книге или игре: название — в кавычках, рядом автор или год. Кавычки, конечно, экранированные.

```
Моя любимая книга — "Хоббит" Толкина.
```

### Задание 8. Разговор у пещеры

Выведите диалог из двух реплик — прямая речь в кавычках:

```
Рыцарь сказал: "Дракон, выходи!"
Дракон ответил: "Дай поспать..."
```

Сочините свои реплики — пусть герои будут с характером.

### Задание 9. Пропавший слеш

Поломка. Возьмите строку из задания 5 и **сотрите оба слеша** перед кавычками. Запустите.

Ошибок вывалится целая пачка — не пугайтесь. Когда компилятор запутался, читайте **первую** ошибку: остальные — лишь её испуганное эхо. Разберитесь по первой, что его смутило, верните слеши — и тишина.

### Задание 10. Прайс зельеварни

Выведите прайс-лист лавки зельевара: заголовок и три товара, название и цена разделены табуляцией.

```
Товар	Цена
Зелье	150
Меч	900
Хлеб	40
```

### Задание 11. Мини-чек

Программа спрашивает цену стакана сока и число стаканов, а затем печатает строку чека: слово «Итого:», табуляция, стоимость (цена × количество).

```
Цена стакана: 60
Сколько стаканов: 3
Итого:	180
```

### Задание 12. Колонки разъехались

Эксперимент. Выведите «таблицу» из трёх строк с табуляцией:

```idyllium
    console.writeln("Имя\tРоль");
    console.writeln("Аня\tхудожник");
    console.writeln("Александра\tкапитан");
```

Запустите и присмотритесь ко второй колонке. Ровно ли она стоит? Разгадка: таб прыгает не «на сколько-то пробелов», а к ближайшей невидимой линейке, расчерченной через каждые 8 символов. Короткое имя до линейки не дотянулось, длинное — перевалило за неё. Запомните это коварство: на длинных словах таб-колонки едут.

# Блок 3. Цвет

## Практика с преподавателем

### Задание 13. Первая краска

Цветом управляет специальная строка-последовательность `"\e[31m"` (31 — код красного). Наберите:

```idyllium
use console;

main() {
    console.writeln("\e[31m", "Тревога!");
    console.writeln("\e[0m", "Обычный текст");
}
```

```
Тревога!        (красными буквами)
Обычный текст   (обычными)
```

`"\e[31m"` включает красный, `"\e[0m"` — сбрасывает все эффекты. Держите под рукой палитру из урока: 31 красный, 32 зелёный, 33 жёлтый, 34 синий, 35 малиновый, 36 циановый.

## Самостоятельная практика

### Задание 14. Победа и поражение

Выведите два сообщения из конца игры: «ПОБЕДА! Босс повержен.» — зелёным, «Поражение... попробуй ещё.» — красным. В конце не забудьте сброс.

```
ПОБЕДА! Босс повержен.      (зелёным)
Поражение... попробуй ещё.  (красным)
```

### Задание 15. Цвет утёк

История с модификацией. Напишите программу из трёх строк: первая покрашена в зелёный, вторая и третья — «обычные», без всяких команд цвета:

```idyllium
    console.writeln("\e[32m", "Уровень пройден!");
    console.writeln("Собрано монет: 120");
    console.writeln("До встречи!");
```

Запустите и посмотрите внимательно на вторую и третью строки. Что с ними произошло? А теперь взгляните на приглашение терминала **после** завершения программы — и на него посмотрите. Почините программу: добавьте в нужное место сброс `"\e[0m"`. Мораль: включил цвет — выключи за собой, как свет в ванной.

### Задание 16. Светофор

Выведите три строки светофора, каждая своим цветом: «СТОЙ» красным, «ПРИГОТОВЬСЯ» жёлтым, «ИДИ» зелёным. Сброс в конце.

```
СТОЙ           (красным)
ПРИГОТОВЬСЯ    (жёлтым)
ИДИ            (зелёным)
```

### Задание 17. Тёмный и светлый

У каждого цвета есть яркий брат: прибавьте к коду 60 (31 → 91). Выведите пару «Тёмно-синий» (34) и «Ярко-синий» (94) и сравните на экране. А потом попробуйте код 90 — «светлый чёрный». Какого цвета он на самом деле? Забавный курьёз палитры.

```
Тёмно-синий     (тёмным синим)
Ярко-синий      (ярким синим)
А это — серый!  (кодом 90)
```

### Задание 18. Золотое приветствие

Программа спрашивает имя героя и приветствует его **жёлтым** (золотым!) цветом. Приглашение — обычное, цветное только приветствие, после — сброс.

```
Как зовут героя: Мира
Добро пожаловать, Мира!    (жёлтым)
```

# Блок 4. Чистый экран

## Практика с преподавателем

### Задание 19. Черновик и чистовик

`console.clear()` стирает всё, что успело появиться на экране. Наберите:

```idyllium
use console;

main() {
    console.writeln("Это черновик. Тут много лишнего...");
    console.clear();
    console.writeln("Чистовик!");
}
```

```
Чистовик!
```

Черновик исчез, будто его и не было. Заметьте: `clear` не отменяет выполненные строки — они честно отработали. Он лишь очищает экран.

## Самостоятельная практика

### Задание 20. Фокусник

Программа-фокусник: сначала выводит подготовку («Кладу кролика в шляпу...», «Накрываю платком...», «Абракадабра!»), потом очищает экран и объявляет: «Та-дам! Кролик исчез!». Зритель видит только финал — в этом и фокус.

```
Та-дам! Кролик исчез!
```

# Блок 5. Со звёздочкой

### Задание 21 ⭐. Сломанная магия

Два опыта над последовательностями. Первый: «забудьте» букву `m` — выведите `"\e[31"` перед текстом. Запустите: что за крокозябра появилась в выводе? Второй: возьмите несуществующий код — `"\e[99m"`. Покрасился ли текст хоть как-то?

Сделайте вывод: управляющая последовательность работает только **целиком и точно** — `\e[`, код из палитры, буква `m`. Шаг в сторону — и терминал либо покажет мусор, либо молча пожмёт плечами.

### Задание 22 ⭐. Ёлка в красках

Помните ёлку из самой первой темы? Пора нарядить. Нарисуйте её снова — теперь звезда на макушке жёлтая, хвоя зелёная, а ствол обычного цвета. Цвет «течёт» вниз сам (задание 15 научило) — пользуйтесь этим: одна команда цвета красит несколько строк подряд.

```
  *      (жёлтым)
 ***     (зелёным)
*****    (зелёным)
  |      (обычным)
```

Придумайте свой рисунок в цвете: костёр, светящееся окно, флаг.

### Задание 23 ⭐. Чек как в магазине

Соберите всё вместе. Программа спрашивает цены двух товаров (с копейками — `float`!), а потом печатает аккуратный чек: заголовок, две строки «товар-таб-цена» и итоговую сумму — **зелёным**, с табуляцией, со сбросом в конце.

```
Цена сока: 75.5
Цена пиццы: 120.9
--- Чек ---
Сок	75.5
Пицца	120.9
Итого:	196.4    (зелёным)
```

Здесь работает вся тема разом: `write` для приглашений, `writeln` для строк, `'\t'` для колонок, цвет для акцента — и ввод с арифметикой из прошлых уроков.

### Минутка из внешнего мира. Язык терминала, а не Idyllium

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Раскрою секрет: коды цветов — вовсе не изобретение Idyllium. Это язык **терминала**, и понимает он его от любого языка программирования:
- **C++**: `std::cout << "\033[31m" << "Красный";`
- **Python**: `print("\x1b[31m" + "Красный")`
- **JavaScript**: `console.log("\x1b[31m" + "Красный")`

Приглядитесь: код `31` везде один и тот же! Различается лишь запись невидимого символа перед ним: наш `\e`, сишный `\033`, питоновский `\x1b` — это три имени **одного** символа под номером 27 (Escape). Так что палитру вы выучили не для одного языка, а на всю программистскую жизнь: смените язык — а цвета останутся с вами.
