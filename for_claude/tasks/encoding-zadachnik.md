# Задачник: Библиотека encoding

Урок №24 раздела «Консоль». Составлен 2026-08-03 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод», со случайностью — помечены «например».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–23; из новой темы — `use encoding;`: `char_to_codepoint(c)` (постоянный номер Unicode) и `codepoint_to_char(n)`, `encode(строка, кодировка)` → `dyn_array<int>` байтов и `decode(байты, кодировка)`, восемь кодировок (`ascii`, `utf-8`, `windows-1251`, `koi8-r`, `cp866`, `cp437`, `windows-1252`, `windows-1254`), `list_encodings()`, параметр `safe=false` (ромбики � и вопросики вместо аварии), «кракозябры» как лабораторный опыт. Границы букв в таблице кодовых точек: латиница `A–Z` = 65–90, `a–z` = 97–122; кириллица `А–Я` = 1040–1071, `а–я` = 1072–1103 (буква «ё» живёт отдельно — в диапазон не входит!).
- *Нельзя (рано):* **функций** (№25 — шифры пишем прямым кодом в `main`!), файлов (№27 — там кодировки развернутся по-настоящему).
- *Градиент сложности.* **Минимальная обвязка** — символ/строка и вывод. Строение: **блок 1 — атомарные**, **блок 2 — полукомплексные** (+ один инструмент), **блок 3 — комплексные** (шифры), **блок 4 — звёздочки**. Карта — в заметке.
- *Словарь:* кодировка, кодовая точка, байт, кодирование/декодирование, шифр.

Тема — про два разных вопроса: «какой у символа **номер**» (кодовая точка, одна на весь мир) и «какими **байтами** его записать» (а вот это решает кодировка). Из первого вырастают шифры, из второго — знаменитые кракозябры, которые мы вырастим сами. **Важно:** поломки и сюрпризы ученик открывает сам.

# Блок 1. Номера и байты

## Практика с преподавателем

### Задание 1. У каждой буквы есть номер

Наберите:

```idyllium
use console;
use encoding;

main() {
    console.writeln(encoding.char_to_codepoint('A'));
    console.writeln(encoding.char_to_codepoint('Я'));
    console.writeln(encoding.codepoint_to_char(1071));
}
```

```
65
1071
Я
```

У каждого символа в таблице Unicode есть постоянный номер — **кодовая точка**: у `'A'` — 65, у `'Я'` — 1071, и это не меняется никогда и нигде. `codepoint_to_char` работает в обратную сторону: номер → символ.

### Задание 2. Одна буква — разные байты

А вот **в байты** один и тот же символ записывается по-разному — это решает кодировка. Наберите:

```idyllium
use console;
use encoding;

main() {
    string text = "Я";
    console.writeln("UTF-8: ", encoding.encode(text, "utf-8"));
    console.writeln("Windows-1251: ", encoding.encode(text, "windows-1251"));
    console.writeln("KOI8-R: ", encoding.encode(text, "koi8-r"));
}
```

```
UTF-8: [208, 175]
Windows-1251: [223]
KOI8-R: [241]
```

Кодовая точка у «Я» одна — 1071, а байты в трёх кодировках разные, и в UTF-8 их вообще два. Запомните разницу: **номер описывает символ, кодировка — его запись**.

# Блок 3. Шифры

## Практика с преподавателем

### Задание 13. Шифр Цезаря

Легендарный шифр двухтысячелетней давности: каждая буква сдвигается по алфавиту на три позиции, а с конца алфавита — заворачивает в начало (вот зачем `mod`!). Числа 65–90 и 97–122 — границы заглавной и строчной латиницы. Наберите:

```idyllium
use console;
use encoding;

main() {
    string message = "Hello World";
    int shift = 3;
    string result = "";

    for (int i = 0; i < message.length; i += 1) {
        int code = encoding.char_to_codepoint(message[i]);
        if (code >= 65 and code <= 90) {
            code = mod(code - 65 + shift, 26) + 65;
        }
        if (code >= 97 and code <= 122) {
            code = mod(code - 97 + shift, 26) + 97;
        }
        result = result + encoding.codepoint_to_char(code);
    }

    console.writeln("Исходное: ", message);
    console.writeln("Зашифрованное: ", result);
}
```

```
Исходное: Hello World
Зашифрованное: Khoor Zruog
```

Разберите цепочку: буква → номер → сдвиг с заворотом → номер → буква. Пробел ни в один диапазон не попал — и прошёл нетронутым. Так Цезарь писал генералам — и так же вы сейчас будете писать соседу.

### Задание 16. Загадочное письмо

### Минутка из внешнего мира. Кодировки, изменившие быт

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- Кракозябры из задания 6 — не учебная страшилка: в 90-е и 2000-е «Íîðìàëüíûé òåêñò» приходил в настоящих письмах, потому что почтовые программы спорили, какой кодировкой читать русский. Теперь вы умеете и диагностировать это, и воспроизводить.

- А победитель войны кодировок известен: **UTF-8** сегодня хранит больше 95% всех страниц интернета. Придумали его, кстати, за один вечер на салфетке в закусочной — Кен Томпсон и Роб Пайк, создатели Unix. Иногда один хороший вечер решает проблему на десятилетия вперёд.

И да: эмодзи — это тоже кодовые точки Unicode, соседи вашей буквы «Я» по одной большой таблице.
