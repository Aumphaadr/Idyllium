# Задачник: Ввод данных

Урок №4 раздела «Консоль». Составлен 2026-07-30 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания управляются вводом, поэтому каждый образец «ввод → вывод» точен (что после двоеточия — ввод пользователя).

**Для преподавателя.**
- *Доступно:* переменные и типы (int/float/string), вывод только через `console.write` (авто-переноса `writeln` ещё нет — переносы ставим сами через `"\n"`); из новой темы — `console.get_int()`, `console.get_float()`, `console.get_string()`, диалог «приглашение → ввод → ответ», несколько вводов подряд, дефолтные значения; из школьного багажа — `+ - *` и (с разрешения владельца) деление `/` с дробным результатом.
- *Нельзя (рано):* `if`/условия (№9 — «проверить ввод» пока нельзя, поэтому поломки просто **наблюдаем**), `is_int()`-проверки (№21), `writeln` и ANSI-цвета (№6), `to_string` (№7), `random`, циклы, `math.*`, `div`/`mod` (№5).
- *Словарь:* ввод, функция ввода, ошибка выполнения (runtime error), дефолтное значение.

Практикум разбит на три блока по типам данных (целые → дробные → строки) плюс блок «собери программу» и звёздочки. Тема базовая, поэтому есть короткие **конвейеры однотипных заданий** — они приучают отделять данные от их роли (число — это и здоровье, и деньги, и урон). **Важно:** ошибки ученик открывает сам, запуская код, — не подсказывайте заранее.

# Блок 1. Целые числа: `get_int`

## Практика с преподавателем

### Задание 1. Первый вопрос программы

Раньше программа только болтала. Теперь она умеет слушать. Наберите:

```idyllium
use console;

main() {
    console.write("Сколько тебе лет: ");
    int age = console.get_int();
    console.write("Ого, целых ", age, "! Солидный возраст.\n");
}
```

Запустите и введите свой возраст:

```
Сколько тебе лет: 12
Ого, целых 12! Солидный возраст.
```

`console.get_int()` останавливает программу, ждёт, пока вы наберёте число и нажмёте Enter, и кладёт введённое в переменную. Обратите внимание: переноса строки после приглашения нет — курсор ждёт ответа прямо за двоеточием.

### Задание 2. Программа-калькулятор в зачатке

Введённые числа можно не только показывать, но и считать. Наберите:

```idyllium
use console;

main() {
    console.write("Первое слагаемое: ");
    int a = console.get_int();
    console.write("Второе слагаемое: ");
    int b = console.get_int();
    console.write("Сумма равна ", a + b, "\n");
}
```

```
Первое слагаемое: 40
Второе слагаемое: 2
Сумма равна 42
```

Два вопроса подряд, два ответа — и программа сама складывает. Запустите с разными числами.

### Задание 6. Сумма покупок

### Задание 7. На сколько старше

### Задание 8. Пять шоколадок

Вы гуляете впятером и разом захотели по шоколадке. Программа спрашивает цену одной шоколадки и считает, сколько всего денег нужно на пятерых, — умножает цену на 5.


### Задание 9. Сломаем ввод числа

Программисты узнают правила, нарочно всё ломая. Запустите **программу из задания 3** (про здоровье) и вместо честного числа введите по очереди:

# Блок 2. Дробные числа: `get_float`

## Практика с преподавателем

### Задание 10. Цена с копейками

Не всё измеряется целыми. Для чисел с точкой есть `get_float`. Наберите:

```idyllium
use console;

main() {
    console.write("Цена товара: ");
    float price = console.get_float();
    console.write("Товар стоит ", price, " монет.\n");
}
```

```
Цена товара: 9.99
Товар стоит 9.99 монет.
```

Всё как с `get_int`, только теперь программа ждёт число с точкой и хранит его в переменной типа `float`.

## Самостоятельная практика

### Задание 11. Рост в метрах

### Задание 12. Чек в магазине

Программа спрашивает цену двух товаров с копейками и складывает их в общий чек (обычное `+`, только числа теперь дробные).


### Задание 13. Средний балл

Программа спрашивает две оценки (целые) и выводит средний балл — сумму, делённую на 2. Учтите: средний балл легко может оказаться дробным, поэтому храните его в `float`.

### Задание 14. Ведёрко мороженого

Деление умеет не только считать средние, но и переводить одни единицы в другие. Программа спрашивает массу ведёрка пломбира в граммах и переводит её в килограммы (делим на 1000).


Заметьте: ввели-то целые граммы, а на выходе — дробные килограммы. Деление на 1000 родило дробь, поэтому результат храните в `float`. Придумайте свой перевод: миллилитры сока в литры? метры дистанции в километры?

### Задание 15. А если ввести целое?

Запустите цену из задания 10 и поставьте эксперимент:

Сравните с прошлым блоком: `get_float` строже или добрее к «неправильному» вводу, чем `get_int`? На что он всё-таки не согласен ни в какую?

### Минутка из внешнего мира. Как это устроено в других языках

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

В Idyllium приятно: `get_int` сразу отдаёт число, `get_float` — дробь, `get_string` — слово. Каждый спрашивает своё.

А вот в **Python** функция ввода одна на всё — `input()`, и она **всегда возвращает строку**, даже если вы набрали `5`. Для Python это текст `"5"`, а не число. И если новичок наберёт два числа и попробует их «сложить», получит не `8`, а склейку `"53"` — потому что складываются-то строки! Чтобы вышло число, в Python приходится явно просить: `int(input())`.

В **C++** ближе к нам: `cin >> n` для числовой переменной сразу читает число.

Idyllium пошёл дружелюбным путём: сказал `get_int` — получил число, и никаких сюрпризов со случайной склейкой. Мелочь — а сколько нервов бережёт.
