**Для преподавателя.**
- *Доступно:* всё из уроков 1–7 — переменные, ввод, арифметика (`+ - * /`, `div`, `mod`), `console.writeln` и цвета, `to_string/to_int/to_float`; из новой темы — библиотека `math` (`use math;`, схема `math.имя(...)`): `math.abs(n)` (сохраняет тип: int→int, float→float), `math.round/floor/ceil(n[, z])` (без `z` → `int`, с `z` → `float`), `math.pow(a, b)` (**всегда `float`**, в т.ч. отрицательная степень), `math.sqrt(n)` (**всегда `float`**, только неотрицательное), `math.clamp(min, val, max)`.
- *Нельзя (рано):* `if`/условия (№9) — и это ключевой момент темы: **ограничить значение можно только через `clamp`, а «убрать минус» — только через `abs`, потому что условий мы ещё не знаем**; `random` (№11), циклов (№13), тригонометрии/логарифмов (№29). Негодные данные (корень из отрицательного) просто **наблюдаем** — проверить заранее нечем.
- *Словарь:* библиотека, модуль числа, округление вниз/вверх/математическое, степень, корень, диапазон, зажать значение.

Тема — «коробка готовых инструментов» для того, чего четырьмя действиями не сделать. Практикум: три округления → степень и корень → **математика вместо условий** (`abs` и `clamp` заменяют `if`, которого пока нет) → звёздочки. Числа одеваем в живые истории: банки краски, бактерии, громкость, здоровье героя. **Важно:** поломки ученик открывает сам; тип `float` у `pow`/`sqrt` — не придирка, а повод не забывать про правильную коробку.

# Блок 1. Три округления: `round`, `floor`, `ceil`

Деление часто даёт дробь, а в жизни нужно целое: банок краски, коробок, автобусов. Округлять можно тремя способами: `round` — к ближайшему, `floor` — вниз, `ceil` — вверх. Выбор зависит от вопроса.

## Практика с преподавателем

### Задание 1. Три округления одного числа

Наберите и сравните:

```idyllium
use console;
use math;

main() {
    float x = 3.6789;
    console.writeln("Число: ", x);
    console.writeln("round: ", math.round(x));
    console.writeln("floor: ", math.floor(x));
    console.writeln("ceil:  ", math.ceil(x));
    console.writeln("round до 2 знаков: ", math.round(x, 2));
}
```

```
Число: 3.6789
round: 4
floor: 3
ceil:  4
round до 2 знаков: 3.68
```

Без второго аргумента результат — целое (`int`). А со вторым (сколько знаков оставить) — снова дробь (`float`): «3.68 знака» — это ведь тоже дробное число.

### Задание 2. Когда недобор недопустим

Красим стену 23 кв. метра, одной банки хватает на 5. Наберите:

```idyllium
use console;
use math;

main() {
    console.writeln("Банок нужно точно: ", 23.0 / 5.0);
    console.writeln("Придётся купить: ", math.ceil(23.0 / 5.0));
}
```

```
Банок нужно точно: 4.6
Придётся купить: 5
```

`floor` дал бы 4 — и краски бы не хватило! Когда «чуть-чуть не хватить» нельзя, честно округляем **вверх** через `ceil`.


У тебя есть деньги, пицца стоит фиксированно. Программа спрашивает сумму в кошельке и цену пиццы и считает, сколько **целых** пицц можно купить. Полпиццы не продают — округляем **вниз** (`floor`).

```

```

Программа спрашивает три оценки, считает средний балл и выводит его, округлив до **двух знаков** после запятой (`round` со вторым аргументом). Тут нужна дробь, поэтому результат — `float`.

# Блок 2. Степень и корень: `pow` и `sqrt`

`math.pow(a, b)` возводит `a` в степень `b`, `math.sqrt(n)` извлекает квадратный корень. Обе всегда возвращают дробь (`float`) — даже когда ответ ровный, храните его в `float`.

## Практика с преподавателем

### Задание 7. Всё, что удваивается

Бактерия делится каждый час: была одна, стало две, четыре, восемь… Степень считает это мгновенно. Наберите:

```idyllium
use console;
use math;

main() {
    console.writeln("Через 3 часа: ", math.pow(2, 3));
    console.writeln("Через 10 часов: ", math.pow(2, 10));
    console.writeln("Через сутки: ", math.pow(2, 24));
}
```

```
Через 3 часа: 8
Через 10 часов: 1024
Через сутки: 16777216
```

Почти семнадцать миллионов из одной за сутки. Вот зачем мыть руки. (А `math.pow(4, -1)` даст `0.25` — отрицательная степень это деление: одна четвёртая.)

### Задание 8. От площади к стороне

Корень выручает, когда известна площадь квадрата, а нужна сторона. Наберите:

```idyllium
use console;
use math;

main() {
    console.writeln("Корень из 49: ", math.sqrt(49));
    console.writeln("Корень из 2: ", math.sqrt(2));

    float field = 144.0; // площадь квадратного участка, кв. м
    console.writeln("Сторона участка: ", math.sqrt(field), " м");
}
```

```
Корень из 49: 7
Корень из 2: 1.41421356
Сторона участка: 12 м
```

У точных квадратов корень ровный (`49 → 7`), у остальных — с длинным дробным хвостом. Потому `sqrt` и отдаёт всегда `float`.

Лист бумаги складывают пополам снова и снова: после каждого сгиба слоёв вдвое больше. Программа спрашивает число сгибов и считает, сколько получится слоёв, — это `2` в степени числа сгибов.

```
Сколько раз сложили: 7

```

### Задание 11. Длина лестницы

Лестницу приставили к стене: её нижний конец в 3 метрах от стены, а верхний достаёт до высоты 4 метра. Какой длины лестница? По теореме Пифагора — корень из суммы квадратов. Программа спрашивает оба числа и считает `sqrt(pow(осн, 2) + pow(высота, 2))`.

Опыт на строгость. Корень из отрицательного числа не существует (в школьной математике) — посмотрим, как поведёт себя `sqrt`:


# Блок 3. Математика вместо условий: `abs` и `clamp`

Вот где начинается волшебство. Условного оператора `if` мы ещё не проходили — а значит, «если число отрицательное, убери минус» или «если больше 100, поставь 100» словами пока не выразить. Зато это делают две функции: `abs` берёт модуль (расстояние от нуля, всегда без знака), а `clamp` зажимает значение в границы. Целых две человеческих проверки — одной функцией каждая.

## Практика с преподавателем

### Задание 13. На сколько промахнулся

Программа загадала 37, игрок назвал своё число. Насколько промах? Вычитание может дать минус, но «промахнуться на −13» звучит странно — промах это расстояние. Наберите:

```idyllium
use console;
use math;

main() {
    int secret = 37;
    console.write("Угадайте число от 1 до 100: ");
    int guess = console.get_int();
    console.writeln("Промах: ", math.abs(secret - guess));
    console.writeln("А без abs было бы: ", secret - guess);
}
```

```
Угадайте число от 1 до 100: 50
Промах: 13
А без abs было бы: -13
```

`abs` превратил `−13` в честное расстояние `13`. Без условий, без хлопот.

### Задание 14. Громкость под контролем

Громкость должна жить в диапазоне 0–100, что бы ни ввёл пользователь. `clamp` держит её в узде. Наберите:

```idyllium
use console;
use math;

main() {
    console.write("Выкрутить громкость до: ");
    int wanted = console.get_int();
    int volume = math.clamp(0, wanted, 100);
    console.writeln("Громкость установлена на: ", volume);
}
```

```
Выкрутить громкость до: 115
Громкость установлена на: 100
```

Попросили 115 — получили 100: выше потолка не прыгнешь. Введите −20 — выйдет 0. `clamp(min, val, max)`: значение всегда посередине, между границами.

И ещё раз — теперь с ненулевым нижним краем. Термостат в доме умеет держать от 16 до 30 градусов. Программа спрашивает, сколько выставил хозяин, и зажимает в эти рамки.

# Блок 4. Со звёздочкой

### Задание 19 ⭐. Диагональ телевизора

Программа спрашивает ширину и высоту экрана в сантиметрах и считает диагональ — корень из суммы квадратов сторон (снова Пифагор). Ответ выведите дважды: точно и округлённым до одного знака после запятой (`round(d, 1)`).

```
Ширина экрана (см): 100
Высота экрана (см): 70
Диагональ точно: 122.06555616
Диагональ округлённо: 122.1 см
```

Тут в одной задаче встретились сразу три инструмента урока: `pow`, `sqrt` и `round`. Разберите, где какой и почему именно в таком порядке.

### Задание 20 ⭐. Почему корень не влезает в `int`

Загадка на внимательность. Как думаете, скомпилируется ли это?

```idyllium
    int side = math.sqrt(49);
```

Запустите и прочитайте отказ. Хотя `sqrt(49)` — это ровно `7`, функция всё равно отдаёт **дробное** число (`float`), а в целую коробку дробь не помещается. То же с `pow`. Мораль: результат `sqrt` и `pow` всегда кладите в `float`, даже если ответ на вид целый. Почините, заменив `int` на `float`.

### Минутка из внешнего мира. Как это зовут у соседей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Набор математических функций есть в каждом языке — только имена и правила чуть разные:
- в **JavaScript** это `Math` с большой буквы: `Math.abs(-5)`, `Math.pow(2, 8)`, `Math.sqrt(49)`, `Math.round(3.7)`;
- в **Python** модуль числа — встроенный `abs(-5)`, а корень — `math.sqrt(49)` (почти как у нас!); степень же там свой особый значок `2 ** 8`;
- в **C++** нужно подключить `<cmath>` и звать `abs`, `pow`, `sqrt` без приставки.

А вот `clamp` — редкость: в C++ он появился лишь недавно (`std::clamp`), а в JavaScript его нет вовсе — там «зажимать» приходится вручную через условия. У нас же `clamp` есть с самого начала, и, что важно, работает **без всяких `if`** — как раз то, что нам сейчас на руку. Идея одна на все языки: не изобретай корень и степень заново, возьми готовое из коробки `math`.

«Битый код / эксперименты» здесь — задания 6, 12, 20: ученик сам предсказывает округление, ловит корень из отрицательного и упирается в тип `float`.
