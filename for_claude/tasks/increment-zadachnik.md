Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–9 — переменные, ввод, арифметика (`+ - * /`, `div`, `mod`), `writeln` и цвета, `to_string/to_int/to_float`, `math.*` (`abs`, `round`, `clamp`…), `if`/`if…else` с одиночными сравнениями, `bool`; из новой темы — **саморедактирование** `N = N + 1` (справа вычисляется со **старым** значением, результат ложится в ту же переменную), термины инкремент/декремент, изменение через функции (`K = math.abs(K)`), короткие формы `+= -= *= /=`, правило «`/=` только для `float`» (для целых — `div`), и разговор «почему в Idyllium нет `++`/`--`».
- *Нельзя (рано):* циклов (№13 — счётчик наращиваем **руками, несколько строк подряд**, и это осознанная боль: она — мотивация будущих циклов); `random` (№11); логических операций `and`/`or` (№12 — только одиночные сравнения в `if`); массивов. Вложенный `if` уроком не показан — только в звёздочке с пометкой «для смелых».
- *Словарь:* саморедактирование, инкремент, декремент, короткая форма, счётчик, накопитель.

Сердце темы — строка `N = N + 1`, о которую спотыкаются почти все: «как это N равно N плюс один?!» Ключ — вспомнить урок про переменные: `=` это не «равно», а **приказ**: сначала вычисли правую часть (с тем значением, что лежит в N *сейчас*), потом положи результат в N. Вся тема — вариации этого приказа. **Важно:** поломки и предсказания ученик проживает сам — не раскрывайте развязку заранее.

# Блок 1. Переменная редактирует сама себя

## Практика с преподавателем

### Задание 1. Тот самый трюк

Наберите и запустите:

```idyllium
use console;

main() {
    int N = 5;
    N = N + 1;
    console.writeln(N);
}
```

```
6
```

Строка `N = N + 1` — не уравнение из математики (там бы она была враньём!). Это приказ: возьми **текущее** N (пятёрку), прибавь 1, результат положи обратно в N. Было 5 — стало 6. Увеличение на единицу зовут **инкрементом**, уменьшение — **декрементом**. Так переменная редактирует сама себя.

## Самостоятельная практика

### Задание 2. Ещё один лайк

Программа спрашивает, сколько лайков под видео. И тут кто-то ставит ещё один — увеличьте счётчик на единицу тем самым трюком и выведите.

```
Сколько лайков под видео: 41
Кто-то лайкнул! Теперь: 42
```

### Задание 3. Минус жизнь

Программа спрашивает, сколько жизней у героя. Герой наступает на шипы — жизней на одну меньше (`lives = lives - 1`, это декремент). Вывели остаток — а он снова на шипы! Ещё один декремент, ещё вывод.

```
Сколько жизней у героя: 5
Ой, шипы! Осталось: 4
Снова шипы! Осталось: 3
```

### Задание 4. Предскажи удвоение

Опыт-предсказание. **Сначала запишите на бумажке**, что выведет программа, — и лишь потом запускайте:

```idyllium
    int N = 5;
    N = N + N;
    N = N + N;
    console.writeln(N);
```

Совпало? Разберите по шагам: во второй строке справа стоит уже **новое** N. А теперь замените оба плюса на умножение (`N = N * N`) и снова предскажите до запуска. Тут сюрприз посильнее.

### Задание 5. Лифт без кнопок

Программа спрашивает, с какого этажа стартует лифт, а дальше он поднимается на пять этажей вверх, объявляя каждый: **пять раз подряд** напишите пару строк «увеличь — выведи».

```
С какого этажа стартует лифт: 3
Этаж 4
Этаж 5
Этаж 6
Этаж 7
Этаж 8
```

Стартовый этаж знает только пользователь, так что без переменной-счётчика не выкрутиться. Пять одинаковых кусков кода… рука не устала? Запомните это чувство: скоро появится инструмент, который повторяет действия сам, — а сегодняшний счётчик станет его сердцем.

# Блок 2. Короткие формы

Приказ «измени себя» пишут так часто, что для него завели сокращения: `N += 5` значит `N = N + 5`. Есть все четыре: `+=`, `-=`, `*=`, `/=`.

## Практика с преподавателем

### Задание 6. Короче!

Наберите:

```idyllium
use console;

main() {
    int score = 100;
    score += 10;
    console.writeln("Счёт: ", score);
}
```

```
Счёт: 110
```

`score += 10` — ровно то же, что `score = score + 10`, только без повторения имени. Меньше букв — меньше опечаток.

## Самостоятельная практика

### Задание 7. Копилка за день

В копилке уже есть деньги (спросите сколько). За день в неё положили трижды — утром, днём и вечером (три ввода). После каждого ввода прибавляйте к копилке через `+=`. Выведите итог.

```
Сколько в копилке сейчас: 2000
Утренний вклад: 120
Дневной вклад: 80
Вечерний вклад: 50
В копилке стало: 2250
```

Переменная-копилка, в которую всё стекается, называется **накопителем** — запомните слово, оно будет всюду.

### Задание 8. Бой с боссом

У героя 100 здоровья. Босс бьёт дважды, и силу каждого удара программа спрашивает. После каждого удара уменьшайте здоровье через `-=` и выводите остаток. А если после боя осталось не больше 30 — выведите **красным** «Здоровье на исходе!».

Урон второго удара: 45
Осталось здоровья: 20
Здоровье на исходе!    (красным)

Проверьте и щадящего босса (10 и 10) — предупреждение должно промолчать.

### Задание 9. Вирусный ролик

Программа спрашивает, сколько у ролика просмотров сейчас, а дальше три дня подряд их число **удваивается**: три раза `*= 2` с выводом после каждого.

```

День 2: 4000

```

### Задание 10. Делёж торта

Программа спрашивает массу торта в граммах (дробную — `get_float`). Каждый из трёх гостей честно забирает половину того, что осталось: три раза `/= 2`. Сколько граммов уцелело?

```
Масса торта (г): 1200
После трёх гостей осталось: 150 г
```

### Задание 11. Дробь в целую коробку

Поломка. Попробуйте применить `/=` к **целой** переменной:

```idyllium
    int N = 10;
    N /= 4;
```

Запустите и прочитайте отказ. Сообщение окажется старым знакомым — вспомните урок про арифметику: деление **всегда** даёт дробь, и короткая форма не исключение. Для целого деления берите `N = div(N, 4)`, а `/=` оставьте дробным переменным.

### Задание 12. Порядок имеет значение

Опыт-предсказание. Две программы отличаются только **порядком** строк. Предскажите ответ каждой до запуска:

```idyllium
    int x = 10;      |    int x = 10;
    x += 5;          |    x *= 2;
    x *= 2;          |    x += 5;
    console.writeln(x);   console.writeln(x);
```

Запустите обе. Почему ответы разные, хотя команды одинаковые? Каждое саморедактирование работает с тем, что оставило предыдущее, — поэтому перестановка строк меняет судьбу переменной.

# Блок 3. Функция как редактор

Переменную можно редактировать не только арифметикой. Функция берёт старое значение, выдаёт новое — а вы кладёте его обратно в ту же переменную.

## Практика с преподавателем

### Задание 13. Сам себе модуль

Наберите:

```idyllium
use console;
use math;

main() {
    int K = -7;
    K = math.abs(K);
    console.writeln(K);
}
```

```
7
```

Схема та же, что у `N = N + 1`: справа функция вычислила модуль **старого** K, результат лёг в K. Минус исчез безвозвратно.

## Самостоятельная практика

### Задание 14. Зелье с перебором

У героя 80 здоровья, а максимум — 100. Программа спрашивает, сколько лечит зелье. Прибавьте через `+=`, а затем **той же переменной** назначьте `math.clamp(0, hp, 100)` — пусть лишнее срежется. Запустите с сильным зельем и со слабым:

```
Сколько лечит зелье: 50
Здоровье: 100
```

```
Сколько лечит зелье: 15
Здоровье: 95
```

Две правки одной переменной подряд: сначала арифметика, потом функция-ограничитель.

Программа спрашивает три оценки и считает средний балл — он выходит лохматым. Для дневника такой не годится: отредактируйте переменную округлением до одного знака (`avg = math.round(avg, 1)`) и выведите до и после.

# Блок 4. Со звёздочкой

### Задание 17 ⭐. Где мой `++`

Те, кто подглядывал в чужой код в интернете, могли видеть загадочное `N++`. Попробуйте:

```idyllium
    int N = 5;
    N++;
```

Запустите и прочитайте отказ. В **C++** и **JavaScript** запись `N++` (и парная `--`) существует и означает `N += 1` — но тянет за собой путаницу: чем `++N` отличается от `N++`? (Даже взрослые спорят.) **Python** рассудил как Idyllium: никакого `++`, только честное `N += 1`. Одна форма — ноль путаницы. Кстати, имя языка C++ — это шутка его создателя: «C, увеличенный на единичку».

### Задание 18 ⭐. Перевёртыши

Внимание, самая коварная звёздочка. Разберите два «перевёртыша», где символы поменяны местами:

```idyllium
    int score = 100;
    score =+ 10;
```

```idyllium
    int lives = 3;
    lives =- 5;
```

Одна из этих строк — ошибка компиляции. А вторая… кое-что похуже: она **молча делает не то**. Запустите обе, выведите переменные и разберитесь: как компилятор прочёл строку, которая «сработала»? (Подсказка: вспомните, что минус бывает частью числа.)

Полвека назад в языке C запись `=-` была законной формой вычитания — потом от неё отказались именно из-за этой путаницы. Мораль: `+=` и `=+` — не одно и то же; за порядком символов следите, как за порядком строк.

### Задание 19 ⭐. Комбо

В файтинге серия ударов копится в комбо-счётчик, и программа спрашивает, сколько комбо у бойца уже накоплено. Дальше — серия из трёх ударов: три раза `combo += 1`, после каждого выводите счёт. Если после серии комбо дотянуло до 10 — объявите **жёлтым** «СУПЕРУДАР!».

### Задание 20 ⭐. Новый уровень (для смелых)

У героя 95 опыта и 9-й уровень. Программа спрашивает, сколько опыта он получил, и прибавляет к счётчику. Если опыта набралось 100 или больше — уровень растёт на 1, а из опыта вычитается сотня. А если новый уровень оказался десятым — **внутри первой проверки** сделайте вторую и объявите золотым «МАКСИМАЛЬНЫЙ УРОВЕНЬ!».

```
Получено опыта: 20
Новый уровень: 10! Опыта осталось: 15
МАКСИМАЛЬНЫЙ УРОВЕНЬ!    (жёлтым)
```

Проверка внутри проверки — приём, который урок вам ещё не показывал. Получилось — отлично, вы забежали вперёд; не получилось — не страшно, вернётесь к нему позже во всеоружии.
