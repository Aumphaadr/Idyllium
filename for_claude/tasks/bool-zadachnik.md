# Блок 1. `and` — нужны оба

`and` даёт `true`, только когда **обе** стороны `true`. Идеален, когда одно действие разрешено лишь при выполнении сразу двух условий.

## Практика с преподавателем

### Задание 1. Детский билет в зоопарк

Детский билет положен тем, кому от 3 до 7 лет включительно. Это сразу два условия — «не меньше 3» **и** «не больше 7». Наберите:

```idyllium
use console;

main() {
    console.write("Возраст: ");
    int age = console.get_int();
    if (age >= 3 and age <= 7) {
        console.writeln("Детский билет.");
    } else {
        console.writeln("Обычный билет.");
    }
}
```

```
Возраст: 5
Детский билет.
```

```
Возраст: 9
Обычный билет.
```

Двумя отдельными `if` тут не обойтись: нужно одно решение по обоим краям сразу. `and` склеивает два сравнения в одно условие.

# Блок 2. `or` — хватит одного

`or` даёт `true`, если `true` **хотя бы одна** сторона (можно и обе). Годится, когда сработать должно от любой из нескольких причин.

# Блок 3. `xor` — ровно одно

`xor` («исключающее ИЛИ») даёт `true`, когда истинна **ровно одна** сторона. Обе сразу — уже `false`. Это про «либо-либо, но не всё вместе».

## Практика с преподавателем

### Задание 10. Створки ворот

У ворот две створки с датчиками. Тревога звучит, если открыта **ровно одна** створка (кто-то пролез в щель). Обе открыты — это штатный проезд, обе закрыты — тоже покой. Наберите:

```idyllium
use console;

main() {
    console.write("Левая створка открыта? (1/0) ");
    int left = console.get_int();
    console.write("Правая створка открыта? (1/0) ");
    int right = console.get_int();
    if (left == 1 xor right == 1) {
        console.writeln("Тревога: приоткрыта одна створка!");
    } else {
        console.writeln("Всё в порядке.");
    }
}
```


# Блок 4. `not()` и всё вместе

`not(x)` переворачивает логическое значение: `true` становится `false`, и наоборот. Это **функция** — то, что переворачивается, всегда в скобках. Заодно в этом блоке соберём операции вместе.

## Практика с преподавателем

### Задание 14. Гулять или дома

Соберём «шторм» из двух примет, а потом одним `not()` перевернём: гулять идём, когда шторма **нет**. Наберите:

```idyllium
use console;

main() {
    console.write("Скорость ветра (м/с): ");
    int wind = console.get_int();
    console.write("Дождь? (1/0) ");
    int rain = console.get_int();

    bool storm = wind > 15 or rain == 1;
    if (not(storm)) {
        console.writeln("Погода тихая — идём гулять!");
    } else {
        console.writeln("Шторм: сидим дома.");
    }
}
```

```
Скорость ветра (м/с): 5
Дождь? (1/0) 0
Погода тихая — идём гулять!
```

```
Скорость ветра (м/с): 20
Дождь? (1/0) 0
Шторм: сидим дома.
```

`storm` собран из `or`, а `not(storm)` перевернул готовое значение целиком — вот зачем скобки: они обнимают ровно то, что инвертируется.

### Задание 19 ⭐. Кто вперёд

Когда операции стоят рядом без скобок, порядок такой: сначала `and`, потом `xor`, потом `or`. Возьмите три значения и предскажите ответ **до** запуска:

```idyllium
    console.writeln(A or B and C);
```

Что посчитается первым — `A or B` или `B and C`? Запишите свою догадку, потом запустите. А теперь поставьте скобки вокруг `A or B` (`(A or B) and C`) и запустите снова — ответ изменился? (Должен: без скобок выходит `true`, со скобками — `false`.) Мораль: **сомневаешься — ставь скобки**, и никто (даже ты через неделю) не прочитает условие иначе.

### Задание 20 ⭐. Почему `not` со скобками и как у соседей

Попробуйте написать «не» без скобок, как слово:

```idyllium
    int coins = 50;
    if (not coins > 100) {
        console.writeln("мало");
    }
```

Запустите — язык откажется и объяснит почему. `not` — функция, ей нужны скобки вокруг **всего**, что переворачиваешь: `not(coins > 100)` — «неправда, что монет больше ста».

А у соседей по цеху иначе:
- в **Python** «не» пишут словом-приставкой без скобок: `not coins > 100`; «и»/«или» — тоже слова `and`/`or`; а вот `xor`-слова нет — берут `!=` или значок `^`;
- в **C++, Java и JavaScript** «и»/«или»/«не» — это значки `&&`, `||`, `!` (например, `!(coins > 100)`); отдельного `xor` для условий тоже нет.

Idyllium выбрал слова (`and`, `or`, `xor`, `not`) — их легко читать вслух, — а «не» сделал функцией со скобками, чтобы никто не гадал, что именно отрицается.
