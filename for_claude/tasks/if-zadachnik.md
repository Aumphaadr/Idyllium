### Задание 1. Хватит ли на меч

С этого урока программа умеет принимать решения. Наберите:

```idyllium
use console;

main() {
    console.write("Сколько у вас монет: ");
    int coins = console.get_int();
    if (coins >= 100) {
        console.writeln("Меч ваш! За ним и ходили.");
    }
}
```

Меч стоит 100 монет. Запустите **три раза**, вводя 450, 60 и ровно 100:

```
Сколько у вас монет: 450
Меч ваш! За ним и ходили.
```

```
Сколько у вас монет: 60
```

```
Сколько у вас монет: 100
Меч ваш! За ним и ходили.
```

Обсудите: почему при вводе 100 меч достался? Потому что `>=` — «больше **или равно**», ровно сотни хватает. И заметьте: при 60 программа не пишет ничего — `if` без пары `else` в этом случае просто молчит, и это нормально.

### Задание 2. Секретный код

Иногда важно не «больше-меньше», а точное совпадение. Для этого есть `==`.

```idyllium
use console;

main() {
    console.write("Введите код от сейфа: ");
    int code = console.get_int();
    if (code == 7766) {
        console.writeln("Щёлк. Сейф открыт.");
    }
}
```

Запустите дважды: сначала `7766`, потом любое другое число. Сейф поддаётся ровно на одном значении.

### Задание 3. Сломаем сравнение

Программисты часто узнают правила, нарочно всё ломая. В условии легко перепутать `==` (сравнить) и `=` (присвоить). Специально ошибёмся — в коде из задания 2 замените `==` на одиночное `=`:

```idyllium

```

Запустите и гляньте, что выйдет. Наткнётесь на что-то непонятное — не пугайтесь: Idyllium ругается по-английски, но по-человечески. Скормите сообщение онлайн-переводчику и узнайте, что ему не понравилось. Разобрались — верните `==` на место.

# Блок 3. Математическое выражение в сравнении

До сих пор слева от знака сравнения стояла переменная. Но там может стоять и целое **вычисление** — программа сначала посчитает, потом сравнит.

### Задание 15. Одолею ли босса

У босса 5000 здоровья. Меч героя бьёт на введённую силу, а всего у героя 10 ударов. Успеет ли он свалить босса? Это правда, если `урон * 10` наберёт не меньше 5000.

```idyllium

    int dmg = console.get_int();
    if (dmg * 10 >= 5000) {
        console.writeln("Босс повержен за 10 ударов! Слава герою.");
    }
    else {
        console.writeln("Не хватит силёнок. Точи меч.");
    }
}
```

Запустите с 600, 400 и ровно 500:

```
Урон за удар: 600

```

```
Урон за удар: 400
Не хватит силёнок. Точи меч.
```

При 500 герой всё же побеждает: `500 * 10` — это ровно 5000, а нам хватает «не меньше».

### Задание 16. Чёт или нечёт

Помните `mod` — остаток от деления? У чётного числа остаток от деления на 2 равен нулю. Значит, само условие — это вычисление: `mod(число, 2) == 0`.

```idyllium

main() {
    console.write("Число: ");
    int n = console.get_int();
    if (mod(n, 2) == 0) {
        console.writeln(n, " — чётное.");
    }
    else {
        console.writeln(n, " — нечётное.");
    }
}
```

```
Число: 8
8 — чётное.
```

```
Число: 7
7 — нечётное.
```

Проверьте на своём годе рождения, номере квартиры, любимом числе.

### Задание 21 ⭐. Раскрась ответ

Помните цветной вывод через `\e[..m`? Соедините его с условием. Программа спрашивает «Сколько будет 6 × 7?», принимает ответ и красит реакцию: верно — **зелёным**, неверно — **красным**.

```

Верно!      (зелёными буквами)
```

```
Сколько будет 6 x 7? 40
Мимо. Правильно — 42.   (красными буквами)
```

Напоминание: `"\e[32m"` включает зелёный, `"\e[31m"` — красный, `"\e[0m"` возвращает обычный. Не забудьте сбросить цвет в конце, иначе он «потечёт» на следующие строки.

### Задание 22 ⭐. Тайна одной чёрточки

Вы уже ловили ошибку из задания 3: Idyllium не даёт написать `if (code = 7766)`. Разберёмся, почему он так строг.

`==` — вопрос «равны?», а `=` — приказ «стань равным». Перепутать их — классическая ловушка. И вот как с ней обходятся разные языки, если написать `if (x = 5)`:
- **Idyllium** — отказывается компилировать: «так нельзя». Ошибку видно сразу.
- **Python** — тоже запрещает, ругается похоже.
- **C++ и JavaScript** — **молча соглашаются!** Присваивают `x` пятёрку, считают её «истиной» и всегда заходят в `if`. Программа работает не так, как задумано, а ошибки не видно — её потом ищут часами.

Idyllium сознательно встал на сторону Python: лучше честно отказать сейчас, чем подсунуть коварный баг потом. Проверьте — верните `=` в любую программу с условием и полюбуйтесь, как язык вас останавливает.

### Задание 23 ⭐. Почему `if (5)` не работает

Попробуйте написать совсем коротко:

```idyllium
if (5) {
    console.writeln("привет");
}
```

Запустите — и получите отказ. Прочитайте его (при желании — через переводчик): условие обязано быть **истиной или ложью** (`bool`), а `5` — просто число.

А в C++, Python и JavaScript такое пишут сплошь и рядом: там любое **ненулевое** число считается «истиной», а `0` — «ложью». Программисты этим пользуются, но новички спотыкаются: `if (счёт)` там значит «если счёт не ноль» — попробуй догадайся с первого взгляда. Idyllium решил не хитрить: хочешь проверить — сравни явно, `if (счёт != 0)`. Одна лишняя чёрточка — зато сразу ясно, о чём речь.
