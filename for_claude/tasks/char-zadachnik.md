**Для преподавателя.**
- *Доступно:* всё из уроков 1–16 — переменные, ввод, арифметика, `writeln`/цвета, преобразования, `math.*`, `if`/`bool`, инкремент, `random`, логические операции, циклы, `time`, `const`, статические массивы; из новой темы — тип `char` (один символ в **одинарных** кавычках), строка = массив символов, чтение `s[i]` (запись запрещена — символы строки только для чтения!), свойство `.length`, посимвольный перебор `for i < s.length`, конкатенация `+` строк и символов (порядок важен; **`char + char` нельзя** — начинайте склейку со строки, хотя бы пустой `""`), экранированные символы как один `char` (`'\n'`, `'\t'`, `'\''`).
- *Нельзя (рано):* **методов строк** (№21! никаких `to_upper`, `contains`, `find` — только индексация и `.length`; счёт и поиск букв — руками, циклом), динамических массивов (№18), кодов символов (encoding — №24), `choose_from` от массива.
- *Словарь:* символ, одинарные/двойные кавычки, длина строки, посимвольный перебор.

Тема открывает дверь **внутрь** строки: до сих пор строка была цельным кирпичом, а теперь она — массив символов, и к каждому есть доступ по индексу. Всё, что дети умеют с массивами (перебор, счётчики, накопители), внезапно работает и с текстом. **Важно:** поломки (перепутанные кавычки, буква за границей, попытка переписать символ) ученик открывает сам.

# Блок 1. Два текстовых типа

## Практика с преподавателем

### Задание 1. Символ и строка

Для одного символа в Idyllium есть отдельный тип — `char`. Наберите:

```idyllium
use console;

main() {
    char mark = '!';
    string word = "Ура";
    console.writeln(word, mark);
}
```

```
Ура!
```

Правило кавычек железное: одиночный символ — в **одинарных** `'!'`, строка — в **двойных** `"Ура"`. Символ ровно один, строка — сколько угодно.

## Самостоятельная практика

### Задание 2. Смайлик по частям

Соберите смайлик из трёх переменных типа `char`: глаза `':'`, нос `'-'`, рот `')'`. Выведите все три подряд одним `writeln` — через запятые, как обычные аргументы.

```
:-)
```

Придумайте второй смайлик из своих символов — грустный? удивлённый?

### Задание 3. Кавычки наоборот

Поломка. Поставьте два опыта — «перепутайте» кавычки в обе стороны:

```idyllium
    char c = "а";
```

```idyllium
    string s = 'Привет';
```

Запустите каждый и прочитайте отказы — они разные! Разберите оба: в первом случае в `char`-коробку суют строку, во втором — в одинарные кавычки пытаются втиснуть целых шесть символов. Кавычки — не украшение, а метка типа.

### Задание 4. Два в одном

Ещё поломка. Попробуйте положить в `char` два символа сразу:

```idyllium
    char c = 'ab';
```

Запустите и прочитайте замечание. `char` — коробка строго на один символ: «ровно один» здесь не пожелание, а закон. (А как же `'\n'` — там ведь два знака? Помните из урока: слеш экранирует букву, и вдвоём они обозначают **один** символ.)

# Блок 2. Строка — это массив символов

Строка устроена как массив типа `char`: у каждого символа есть индекс, счёт — с нуля. А длину знает свойство `.length`.

## Практика с преподавателем

### Задание 5. Разобрать и собрать

Разберём слово на буквы и соберём задом наперёд. Наберите:

```idyllium
use console;

main() {
    string p = "Лось";
    char a = p[0];
    char b = p[1];
    char c = p[2];
    char d = p[3];
    console.writeln(d, c, b, a);
}
```

```
ьсоЛ
```

`p[0]` — первая буква (счёт с нуля!), `p[3]` — последняя из четырёх. Вытащили все четыре и выложили в обратном порядке. Пока — вручную; скоро цикл сделает это с любым словом.

## Самостоятельная практика

### Задание 6. Первая и последняя

Программа спрашивает слово и называет его первую и последнюю буквы. Первая — это `w[0]`, а последняя? Подумайте, как выразить её индекс через `.length` — слово-то каждый раз разной длины.

```
Слово: крокодил
Первая: к, последняя: л
```

### Задание 7. Инициалы

Программа спрашивает имя и фамилию и печатает инициалы: первая буква имени, точка, первая буква фамилии, точка. Символ приклеивается к строке обычным плюсом.

```
Имя: Мира
Фамилия: Соколова
Инициалы: М.С.
```

### Задание 8. Чьё слово длиннее

Программа спрашивает два слова и объявляет, какое длиннее (и на ничью тоже отвечает — тремя независимыми `if`, как в теме про условия). Сравниваются, конечно, `.length`.

```
Первое слово: бегемот
Второе слово: кот
Длиннее первое: 7 букв против 3
```

### Задание 9. Буква за забором

Поломка-предсказание. Кажется логичным взять «последнюю букву» так:

```idyllium
    string s = "Пингвин";
    console.writeln(s[s.length]);
```

**Сначала предскажите**, что произойдёт, — потом запустите. В «Пингвине» 7 букв, а какие индексы допустимы? Та самая ошибка «на единицу больше», знакомая по массивам, — теперь в строках. Почините на верный индекс.

### Задание 10. Только для чтения

Ещё поломка. Раз строка — массив, попробуем «исправить» букву, как ячейку массива:

```idyllium
    string s = "кот";
    s[0] = 'К';
```

Запустите и прочитайте отказ. Символы строки — **только для чтения**: подглядывать можно, переписывать нельзя. Хотите строку с большой буквы — соберите **новую** (например, `"К" + …` — а как достать хвост слова без первой буквы, узнаете в уроке про методы строк; интрига!).

# Блок 3. Посимвольный перебор

Раз у строки есть индексы и длина — по ней можно пройтись циклом, как по массиву. Здесь начинается настоящая магия: всё, что вы умеете с массивами, работает и с текстом.

## Практика с преподавателем

### Задание 11. По буквам

Наберите:

```idyllium
use console;

main() {
    string t = "Журавль";
    for (int i = 0; i < t.length; i += 1) {
        console.writeln(t[i]);
    }
}
```

```
Ж
у
р
а
в
л
ь
```

Цикл идёт по индексам от 0 до `length - 1`, и `t[i]` на каждом шаге — очередная буква. Смените слово — цикл подстроится сам.

## Самостоятельная практика

### Задание 12. Печатная машинка

Программа спрашивает фразу и печатает её **по одному символу** с паузой `time.sleep(0.15)` после каждого — как старая печатная машинка. Печатайте через `console.write` (без переносов), а перенос строки — один, в самом конце. Эффект гипнотический.

```
Фраза: Добро пожаловать в игру
Добро пожаловать в игру    (появляется по буковке)
```

### Задание 13. Счёт буквы

Программа спрашивает фразу и считает, сколько в ней букв «о»: перебор + `if s[i] == 'о'` + счётчик. Методов-помощников у нас ещё нет — честная ручная работа, как с массивами.

```
Фраза: молоко и колобок
Букв о: 6
```

### Задание 14. Шифр-заборчик

Секретное агентство передаёт слова шифром: читается **каждая вторая** буква, начиная с первой. Программа спрашивает слово и выводит шифровку — просто пустите цикл с шагом `i += 2`.

```
Слово: программа
Шифр: порма
```

### Задание 15. Перевёртыш

Программа спрашивает слово и выводит его задом наперёд — теперь циклом, а не вручную, как в задании 5. Приём с накопителем: заведите пустую строку и **приставляйте каждую букву спереди** (`rev = s[i] + rev`). Порядок слагаемых тут решает всё — в этом и фокус.

```
Слово: кот
Задом наперёд: ток
```

### Задание 16. Кричалка болельщиков

Трибуны скандируют имя героя по буквам. Программа спрашивает имя и выводит кричалку: по строчке «Дай нам «Х»!» на каждую букву, а в конце — имя целиком.

```
Имя героя: Мира
Дай нам «М»!
Дай нам «и»!
Дай нам «р»!
Дай нам «а»!
Все вместе: Мира!
```

### Минутка из внешнего мира. Буква — это число?

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

В **C++** тип `char` — на самом деле маленькое **число**: там можно написать `'A' + 1` и получить `'B'`, потому что за каждым символом прячется числовой код. Звучит мощно, но есть подвох: в сишный `char` влезает только один байт, и русская буква туда **не помещается** — из-за этого длина слова «привет» в C++ окажется 12, а не 6! Idyllium считает буквы честно: буква — это буква, хоть латинская, хоть русская.

В **Python** другая крайность: типа `char` там нет вовсе — одиночный символ хранят как строку длины 1.

А числовые коды символов — штука и правда полезная (сортировки, шифры, таблица Unicode) — в Idyllium тоже есть, но живут в отдельной библиотеке `encoding`. Доберёмся и до неё.
