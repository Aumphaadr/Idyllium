# Задачник: Именованные константы

Урок №15 раздела «Консоль». Составлен 2026-07-31 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–14 — переменные, ввод, арифметика, `writeln` и цвета, `to_string/to_int/to_float`, `math.*`, `if`/`bool`, `random`, логические операции, циклы, `time`; из новой темы — `const` перед типом, **обязательный инициализатор**, **запрет переприсваивания**, соглашение `ЗАГЛАВНЫЕ_ИМЕНА` (не требование — компилятор примет и строчные), вычисление константы из констант (`ROWS * COLS`), **константы уровня файла** (объявлены вне `main`, видны внутри).
- *Нельзя (рано):* массивов (№16 — там const-размер сразу пригодится), функций (№25), модульных констант (`config.NAME` — вне раздела).
- *Словарь:* именованная константа, неизменяемое значение, инициализатор, магическое число, константа уровня файла.

Тема — узкая по механике (объяви, используй, попробуй изменить — не выйдет), поэтому вся её ценность в **ответе на вопрос «зачем нельзя менять?»**: читаемость (имя вместо загадочного числа), единый источник правды (поменял в одном месте — обновилось везде) и защита от случайной правки. На этих трёх китах и строим практику, опираясь на поломки и истории-модификации. **Важно:** запрет на изменение ученик нащупывает сам, ломая код.

# Блок 1. Первая константа

## Практика с преподавателем

### Задание 1. Неизменное число

В неделе всегда семь дней — это значение не должно меняться никогда. Такие числа объявляют через `const`. Наберите:

```idyllium
use console;

main() {
    const int DAYS_IN_WEEK = 7;
    console.write("В неделе дней: ", DAYS_IN_WEEK, "\n");
}
```

```
В неделе дней: 7
```

Слово `const` перед типом означает «объявляю раз и навсегда». В остальном это обычное целое: его можно складывать, умножать, выводить — нельзя лишь одно: **менять**. Имена констант принято писать БОЛЬШИМИ_БУКВАМИ — чтобы сразу было видно: это значение трогать нельзя.

### Задание 2. Константа из констант

Справа от `=` может стоять и вычисление — оно посчитается один раз при объявлении. Наберите:

```idyllium
use console;

main() {
    const int ROWS = 6;
    const int COLS = 8;
    const int TOTAL = ROWS * COLS;
    console.write("Всего клеток: ", TOTAL, "\n");
}
```

```
Всего клеток: 48
```

`TOTAL` вычислилась из двух других констант — и сама стала неизменяемой.

## Самостоятельная практика

### Задание 3. Паспорт программы

Заведите три константы разных типов: название программы (строка), максимальный уровень (целое) и число пи (дробное) — и выведите их. Значения выберите сами.

```
Программа: Космо-раннер
Максимальный уровень: 50
Число пи: 3.14
```

### Задание 4. Константа умеет считать

Заведите константу-цену одного билета в кино и посчитайте, сколько стоят три билета (`ЦЕНА * 3`). Константа участвует в арифметике как обычное число — просто её саму никто не сможет случайно переписать.

```
Три билета в кино: 750 монет.
```

### Задание 5. Восьмой день недели

Поставьте опыт. Заведите `const int DAYS_IN_WEEK = 7;` и на следующей строке попробуйте «исправить» неделю на восемь дней:

```idyllium
    DAYS_IN_WEEK = 8;
```

Запустите — программа откажется ещё до старта. Прочитайте замечание: константу переписать нельзя, в том и весь смысл. (Попробуйте заодно `DAYS_IN_WEEK += 1;` — язык не проведёшь и так.)

### Задание 6. Пустая константа

Ещё опыт. Заведите константу, но **не давайте** ей значения:

```idyllium
    const int ANSWER;
```

Запустите и прочитайте отказ. Обычную переменную можно объявить пустой и заполнить позже — а константу нельзя: раз менять её потом запрещено, значение обязано появиться сразу. Иначе она навсегда осталась бы пустой и бесполезной.

# Блок 2. Долой магические числа

«Магическое число» — это голое число прямо в коде, о смысле которого приходится гадать: почему `60`? откуда `1000`? Хуже того, если оно встречается в нескольких местах и однажды меняется — правь все места и не забудь ни одного. Именованные константы лечат обе беды разом.

## Практика с преподавателем

### Задание 7. Один источник правды

Игра выдаёт базовую награду за разные дела. Наберите:

```idyllium
use console;

main() {
    const int REWARD = 50;
    console.write("За монстра: ", REWARD, "\n");
    console.write("За сундук: ", REWARD, "\n");
    console.write("За квест: ", REWARD, "\n");
}
```

```
За монстра: 50
За сундук: 50
За квест: 50
```

Награда записана **одним** числом `REWARD`. Захочет разработчик поднять её до 70 — поменяет одну строку, и обновится сразу везде. А если бы `50` было вписано трижды вручную, легко исправить два места и забыть третье. Попробуйте: смените `50` на `70` и убедитесь, что все три строки изменились разом.

## Самостоятельная практика

### Задание 8. Что это за числа

Перед вами расчёт площади футбольного поля, но числа в нём — загадка. Перепишите его, вынеся длину (105) и ширину (68) в понятные константы `FIELD_LENGTH` и `FIELD_WIDTH`, а площадь посчитайте их произведением.

```
Площадь поля: 7140 кв. м.
```

Сравните с исходным `105 * 68`: теперь по коду сразу ясно, что за числа и что они значат.

### Задание 9. Кафе подняло цены

Кофе стоит 120 монет. Программа считает стоимость одной, двух и трёх чашек. Вынесите цену в константу `PRICE`, а суммы получите умножением. Потом кафе подняло цену до 150 — поменяйте **одну** строку и убедитесь, что все три суммы обновились сами.

```
1 чашка: 120
2 чашки: 240
3 чашки: 360
```

### Задание 10. Упорный взломщик

Сейф в игре даёт ровно 25 попыток подбора кода. Заведите `const int MAX_TRIES = 25;` и прокрутите цикл `for` от 1 до `MAX_TRIES`, печатая номер попытки, а после цикла — «Попытки кончились!». Порог вынесен в константу: захотите смягчить сейф до 50 попыток — поменяете одну строку наверху.

```
Попытка 1
Попытка 2
Попытка 3
...
Попытка 24
Попытка 25
Попытки кончились!
```

(В образце — многоточие; программа, конечно, печатает все 25 строк.)

### Задание 11. Заперто на весь матч

Иногда значение приходит извне, но потом меняться не должно. Программа спрашивает число раундов в начале матча и фиксирует его в **константе** через `const int ROUNDS = console.get_int();`. Дальше это число можно выводить и считать, но случайно переписать посреди матча — уже нет.

```
Сколько раундов сыграем: 5
Матч зафиксирован: 5 раундов. Изменить нельзя!
```

# Блок 3. Константы для всей программы

Константу можно объявить не только внутри `main`, но и снаружи — в начале файла, сразу после `use console;`. Такая константа принадлежит всей программе, и `main` свободно ею пользуется. Общие правила — максимум здоровья, размер поля — держат на самом видном месте.

## Практика с преподавателем

### Задание 12. Правило на видном месте

Наберите — обратите внимание, что `MAX_LEVEL` объявлена **до** `main`, но внутри прекрасно видна:

```idyllium
use console;

const int MAX_LEVEL = 100;

main() {
    console.write("Максимальный уровень: ", MAX_LEVEL, "\n");
}
```

```
Максимальный уровень: 100
```

Чем больше программа, тем ценнее такие «общие» константы: все главные настройки собраны наверху, а не спрятаны в глубине кода.

## Самостоятельная практика

### Задание 13. Настройки игры

Вынесите в начало файла (до `main`) две файловые константы: стартовое здоровье героя `START_HEALTH` (100) и размер игрового поля `FIELD_SIZE` (10). Внутри `main` выведите приветствие новой игры, используя обе.

```
Новая игра!
Здоровье героя: 100
Поле: 10 на 10 клеток.
```

### Задание 14. Секунд в сутках

Объявите файловые константы `MINUTES_IN_HOUR` (60), `HOURS_IN_DAY` (24), а из них вычислите третью — `SECONDS_IN_DAY` (`60 * 60 * HOURS_IN_DAY`). Внутри `main` выведите, сколько секунд в сутках.

```

```

# Блок 4. Со звёздочкой

### Задание 15 ⭐. Константа или переменная?

Не для всякого значения нужна константа. Для каждого из списка решите, что подойдёт — `const` или обычная переменная, — и коротко объясните почему:
- число дней в неделе;
- счёт игрока в матче;
- температура воздуха за окном;
- скорость света;
- максимальное число игроков в лобби.

Подсказка-вопрос из урока: «если эта строка случайно изменит значение позже — это будет нормальной частью алгоритма или ошибкой?». Если ошибкой — просится `const`. Соберите крошечную программу с двумя-тремя своими примерами каждого вида.

### Задание 16 ⭐. Пульт настроек

Соберите «пульт настроек» маленькой игры: в начале файла объявите четыре-пять файловых констант (максимум здоровья, урон меча, число врагов, цена зелья, стартовое золото), а в `main` разыграйте короткую сценку, где все они участвуют в выводе и расчётах. Смысл упражнения: чтобы перебалансировать всю игру, достаточно поправить несколько строк наверху — тело программы трогать не нужно. Это и есть главная сила констант в больших проектах.

### Минутка из внешнего мира. Как с этим у соседей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Слово `const` есть во многих языках, но строгость разная:
- в **C++** и **JavaScript** `const` работает как у нас: объявил — переписать нельзя, компилятор не пустит;
- а в **Python** настоящих констант… нет вовсе! Там пишут `MAX_LEVEL = 100` большими буквами — но это лишь **вежливая просьба** «не меняй меня». Технически ничто не мешает написать ниже `MAX_LEVEL = 200`, и Python молча согласится.

Idyllium пошёл строгим путём C++ и JavaScript: большие буквы — это подсказка для людей (её мы тоже переняли), но саму неизменность стережёт компилятор, а не только договорённость. Обещание, за которым следит машина, надёжнее обещания на честном слове.

**Заметка для преподавателя (запас времени).** Прорешали всё — не открывайте новую тему, а развивайте сделанное:
- «пульт настроек» (з.16) перебалансировать вживую: поменять пару констант наверху и вслух проследить, как изменился весь вывод, ни строчки не тронув в теле;
- лимит попыток (з.10) свести с темой циклов: пусть `const int MAX_TRIES` управляет `for`, а внутри — обратный отсчёт оставшихся попыток (`MAX_TRIES - i`);
- секунды в сутках (з.14) продолжить до недели и года через ещё одну константу-произведение — заодно повод удивиться, как быстро растут числа.

«Битый код / эксперименты» здесь — задания 5 и 6: в обоих ученик сам упирается в неизменность (переписать нельзя, пустой оставить нельзя). Красная нить темы — **не механика, а мотив**: `const` не про «ещё один способ объявить число», а про три обещания — читаемость, единый источник и защиту от случайной правки. Проговаривайте «зачем», а не только «как»: на фоне будущих массивов (const-размер) и больших программ ценность констант станет очевидной сама собой.
