# Блок 1. Методы-стражи: `is_int`, `is_float`, `contains`

Пользователь вводит что попало. Попросишь возраст — прилетит «двенадцать», «12 лет» или вообще «ЪУЪ». Раньше программа падала. Теперь у строки есть методы-проверки, отвечающие «да или нет», — и падать больше не обязательно.

## Практика с преподавателем

### Задание 1. Спроси у строки

У строки можно спрашивать про неё саму — через точку, как у объектов `time`. Наберите:

```idyllium
use console;

main() {
    console.writeln("123".is_int());
    console.writeln("двенадцать".is_int());
    console.writeln("12.5".is_float());
}
```

```
true
false
true
```

Метод `is_int()` отвечает, можно ли безопасно превратить строку в целое число, `is_float()` — в дробное. Пока просто ответы `true`/`false` — а сейчас пристегнём к ним настоящую защиту.

### Задание 2. Реванш за старые падения

Помните программу из урока про ввод, которая рушилась от слова «двенадцать»? Пора взять реванш. Наберите:

```idyllium
use console;

main() {
    console.write("Сколько вам лет: ");
    string answer = console.get_string();
    if (answer.is_int()) {
        int age = to_int(answer);
        console.writeln("Через год вам будет ", age + 1);
    } else {
        console.writeln("Хм, «", answer, "» — не похоже на число.");
    }
}
```

```
Сколько вам лет: 12
Через год вам будет 13
```

```
Сколько вам лет: двенадцать
Хм, «двенадцать» — не похоже на число.
```

Вот он, паттерн надёжных программ: **бери строкой — проверяй — конвертируй**. Никаких аварий: на ерунду программа вежливо отвечает, а не падает.

### Задание 5. Экзамен для стража

Опыт-предсказание. Что ответит `is_int()` на каждую из этих строк? **Сначала запишите догадки**, потом проверьте программой:

# Блок 2. Методы-сыщики: `find` и `count`

Эти двое отвечают числами: `find` — **где** первое вхождение (или −1, если нет), `count` — **сколько** вхождений.

## Практика с преподавателем

### Задание 6. Где и сколько

Наберите:

```idyllium
use console;

main() {
    string t = "Кот и собака";
    console.writeln(t.find('о'));
    console.writeln(t.find("собака"));
    console.writeln(t.find("рыба"));
    console.writeln("абракадабра".count('а'));
}
```

```
1
6
-1
5
```

Буква `'о'` впервые встречается в ячейке 1 (символы, как и массивы, нумеруются с нуля!), «собака» начинается с ячейки 6, а рыбы нет — и `find` честно возвращает −1. Ну а `count` насчитал в абракадабре пять букв «а».


# Блок 3. Методы-переделщики: новая строка из старой

Эти методы **не меняют** исходную строку — они изготавливают новую. Хотите сохранить результат — присвойте его переменной (привет, урок про инкремент!).

## Практика с преподавателем

### Задание 9. Кричалка и шёпот

Наберите:

```idyllium
use console;

main() {
    string a = "Тише едешь";
    console.writeln(a.to_upper());
    console.writeln(a.to_lower());
}
```

```
ТИШЕ ЕДЕШЬ
тише едешь
```

`to_upper` кричит, `to_lower` шепчет. Оба изготавливают новую строку — сама `a` осталась какой была. Проверим это в следующем задании.

## Самостоятельная практика

### Задание 10. Метод, который «не сработал»

Опыт. Наберите и запустите:

```idyllium
    string s = "тихо";
    s.to_upper();
    console.writeln(s);
```

Строка не закричала! Почему? `to_upper` изготовил новую строку — а её никто не забрал, и она пропала. Почините так же, как чинили счётчики в теме про инкремент: результат — обратно в ту же переменную (`s = s.to_upper();`). Запомните правило: **методы-переделщики возвращают, а не переделывают**.

# Блок 4. Разрезать строку: `split`

Иногда в одной строке едет сразу несколько значений — через запятую, точку или двоеточие. `split(разделитель)` режет строку и возвращает **динамический массив строк** — а с массивами вы уже на «ты».

## Практика с преподавателем

### Задание 17. Строка на части

Наберите:

```idyllium
use console;

main() {
    string data = "яблоко,банан,апельсин";
    dyn_array<string> fruits = data.split(",");
    console.writeln(fruits);
    console.writeln("Частей: ", fruits.length);
}
```

```
["яблоко", "банан", "апельсин"]
Частей: 3
```

Одна команда — и строка превратилась в массив: хочешь — перебирай, хочешь — считай длину.

## Самостоятельная практика

### Задание 20. Баскетбольный пересчёт

Задача посерьёзнее — шагов много, но каждый прост. Судьи пересмотрели запись матча и выяснили: первой команде **недосчитали 3 очка**, а второй **начислили 5 лишних**. Программа:
1. спрашивает счёт с табло в виде строки `84:86`;
2. режет её по двоеточию — получает две строки-числа;
3. переводит обе в числа (`to_int`);
4. прибавляет первой 3, вычитает у второй 5;
5. печатает исправленный счёт;
6. и выясняет главное: **сменился ли победитель?** (Сохраните в `bool`, кто вёл до пересчёта, и сравните с тем, кто ведёт после, — здесь красиво работает `xor`.)

```
Счёт с табло: 84:86
Исправленный счёт: 87:81
Сенсация: победитель сменился!    (жёлтым)
```

```
Счёт с табло: 97:83
Исправленный счёт: 100:78
Победитель остался прежним.
```

Разберите цепочку по звеньям: строка → массив строк → числа → арифметика → сравнение. Полконспекта в одной программе — и ни одного сложного звена.

### Минутка из внешнего мира. Почти как в Python

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Методы строк — место, где Idyllium и другие языки похожи до смешного:
- **Python**: `s.upper()`, `s.lower()`, `s.replace(a, b)`, `s.strip()` (наш `trim`), `s.split(",")`, `s.count("а")`, `s.find("б")` — почти один в один, вплоть до имён!
- **JavaScript**: `s.toUpperCase()`, `s.replace(...)`, `s.split(",")`, `s.indexOf(...)` (наш `find`, тоже −1 при неудаче);
- а вот в **C++** готового `split` нет вовсе — программисты пишут его сами или таскают из библиотек, и это вечный предмет жалоб.

Мигрируете когда-нибудь на Python — методы строк узнаете в лицо. А заодно оцените, как вам повезло со `split` из коробки.
