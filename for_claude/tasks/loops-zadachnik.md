Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод» (число после двоеточия — ввод пользователя), а задания со случайностью помечены «например».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–12 — переменные, ввод, арифметика (`+ - * /`, `div`, `mod`), `console.writeln` и цвета, `to_string`, `math.*` (в т.ч. `math.sqrt`), `if`/`if…else`, `bool` и сравнения, инкремент (`+= -=`, `N = N + 1`), `random`, логические операции (`and`/`or`/`xor`/`not`); из новой темы — `while`, `do…while`, `for (старт; условие; шаг)`, `break`, `continue`. Шаг счётчика пишем `i += 1` (короткого `i++` в языке нет).
- *Нельзя (рано):* массивов (№16 — циклы пока «по числам»: суммы, отсчёты, таблицы, разбор цифр, накопление строки), `const` (№15), собственных функций (№25). Вложенные циклы урок не показывает — приберегли для звёздочек и пометили как «для смелых».
- *Словарь:* цикл, итерация, счётчик, условие продолжения, досрочный выход (`break`), пропуск итерации (`continue`).

Практикум идёт по типам циклов: `while` (пока условие держится) → `for` (известное число повторений) → `do…while` (хотя бы один раз, потому и третий — задач по нему меньше) → звёздочки. Числа стараемся одевать в живые истории: гринд золота, слухи, средний рост команды, уровни в игре. **Важно:** поломки ученик открывает сам, запуская код. Особая поломка темы — область видимости: переменная, объявленная в теле цикла, снаружи не существует.

# Блок 1. `while` — пока условие держится

`while` проверяет условие **перед** каждым повторением. Держится — тело выполняется снова; перестало — цикл заканчивается. Хорош, когда заранее не знаешь, сколько будет повторений.

## Практика с преподавателем

### Задание 1. Обратный отсчёт

Запустим ракету. Наберите:

```idyllium
use console;

main() {
    int n = 5;
    while (n >= 1) {
        console.writeln(n);
        n -= 1;
    }
    console.writeln("Пуск!");
}
```

```
5
4
3
2
1
Пуск!
```

Счётчик `n` уменьшается на каждом круге. Как только он дойдёт до нуля, условие `n >= 1` станет ложным — и цикл закончится. Уберите строку `n -= 1;` мысленно: что будет? (Правильно — беда; проверим это в задании 6.)

### Задание 2. Долго ли копить

Пока цель не достигнута — продолжаем. Наберите:

```idyllium
use console;

main() {
    int saved = 0;
    int days = 0;
    while (saved < 100) {
        saved += 15;
        days += 1;
    }
    console.writeln("За ", days, " дней накопится ", saved, " монет.");
}
```

```
За 7 дней накопится 105 монет.
```

Мы не считали заранее, сколько дней нужно, — цикл сам крутился, пока `saved` не дорос до сотни. Вот за это и любят `while`: число повторений выясняется по ходу дела.

# Блок 2. `for` — когда число повторений известно

`for` собирает всё управление счётчиком в одну строку: `for (старт; условие; шаг)`. Старт — один раз в начале, условие — перед каждым кругом, шаг — после каждого круга. Идеален, когда повторить нужно ровно столько-то раз.

## Практика с преподавателем

### Задание 8. Таблица умножения

Напечатаем таблицу умножения на 7. Наберите:

```idyllium
use console;

main() {
    for (int i = 1; i <= 10; i += 1) {
        console.writeln("7 x ", i, " = ", 7 * i);
    }
}
```

```

7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```

Читается как фраза: «заведи счётчик `i` от 1, повторяй, пока `i <= 10`, после каждого круга прибавляй 1».

# Блок 3. `do…while` — сначала сделай, потом проверь

## Практика с преподавателем

### Задание 17. Пароль: сначала «в лоб», потом красиво

Познакомимся с третьим циклом на живой задаче — проверке пароля. Сперва решим её обычным `while`. Наберите:

```idyllium
use console;

main() {
    console.write("Слово-пароль: ");
    string pass = console.get_string();
    while (pass != "жёлудь") {
        console.write("Слово-пароль: ");
        pass = console.get_string();
    }
    console.writeln("Проходи в штаб!");
}
```

```
Слово-пароль: привет
Слово-пароль: жёлудь
Проходи в штаб!
```

Работает — но приглядитесь: строчки «спроси пароль» пришлось написать **дважды**. Один раз до цикла (иначе `while` нечего проверять на первом круге) и точно такой же — внутри. Некрасиво и легко ошибиться, поправив одну копию и забыв другую.

Вот тут и выручает `do…while`: он сначала выполняет тело, а условие проверяет **потом** — значит, лишний запрос до цикла не нужен:

```idyllium
use console;

main() {
    string pass;
    do {
        console.write("Слово-пароль: ");
        pass = console.get_string();
    } while (pass != "жёлудь");
    console.writeln("Проходи в штаб!");
}
```

Тот же результат, а дублирования нет. `do…while` создан ровно для таких случаев: сначала спроси — потом решай, повторять ли.

### Задание 23 ⭐. Строковый повторитель

### Задание 24 ⭐. Таблица квадратных корней

Программа спрашивает верхнюю границу и печатает квадратные корни всех чисел от 0 до неё — по строчке на число. Корень берём функцией `math.sqrt` из урока про математику (не забудьте `use math;`). У большинства чисел корень дробный, так что тип результата — `float`.

### Задание 25 ⭐. Как крутят циклы у соседей

Ещё с урока про инкремент вы знаете: короткой записи `i++` в Idyllium нет — шаг пишется `i += 1`, в том числе и в заголовке `for` (проверьте: `for (int i = 1; i <= 5; i++)` не соберётся). Но у соседей по цеху на этот счёт свои порядки.
- В **C++, Java и JavaScript** есть короткая запись `i++` (то же, что `i += 1`) — привычная, но новичков путает: чем `i++` отличается от `++i`? Idyllium убрал этот вопрос, оставив ясное `i += 1`.
- Ещё коварнее — **лишняя точка с запятой**: в C++ строка `while (i < 3);` спокойно компилируется, но означает пустой цикл — программа зависает, а ошибки не видно. Напишите `while (i < 3);` с точкой с запятой в Idyllium — язык сразу откажется.

Idyllium специально проще и строже: одна очевидная форма шага и никаких «пустых» циклов исподтишка.

### Задание 26 ⭐. Таблица Пифагора (для смелых)

Настоящая таблица умножения — квадратом, и его размер программа спрашивает: в каждой строке `i` перечислены произведения `i * j`. Здесь понадобится **цикл внутри цикла**: внешний гонит номер строки `i`, внутренний по каждой строке гонит `j` и печатает `i * j`, а после внутреннего цикла — перенос строки.

```
Размер таблицы: 5
1 2 3 4 5
2 4 6 8 10
3 6 9 12 15
4 8 12 16 20
5 10 15 20 25
```

Подсказка: внутренний цикл печатает числа через `console.write` (без переноса), а перенос строки `"\n"` ставится уже во внешнем, после того как строка допечатана. Вложенные циклы — мощная штука; со следующими темами (массивы) они станут вашим главным инструментом.
