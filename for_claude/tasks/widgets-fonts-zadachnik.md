# Задачник: Шрифты в GUI

Урок №6 раздела «Виджеты». Составлен 2026-08-03 по [лестнице навыков GUI](../ladder/gui-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Особенность темы: первая программа урока — **консольная**, поэтому блок 1 проверяется живым запуском (все выводы и тексты ошибок в книге получены на рантайме 1.2.8 с настоящими файлами шрифтов); оконные блоки — `check` + глазами и кликом.

**Для преподавателя.**
- *Подготовка урока (обязательно!):* это первая тема с файлами-ресурсами — до занятия положите в проект (или раздайте для загрузки в Web IDE) три шрифта: **декоративный с кириллицей** (в уроке — `Lobster-Regular.ttf` с Google Fonts), **строгий с кириллицей** (например, `PTSans-Regular.ttf`), **латинский без кириллицы** (например, `Bangers-Regular.ttf` — нужен для з.9). Имена файлов в заданиях — примерные: раздали другие — замените по ролям. Ещё пригодится любой текстовый файл (з.4).
- *Доступно:* весь консольный курс (багаж) + №1–5 (окно, кнопки со счётчиками и сторожами, Label с динамикой, ProgressBar, вся палитра `colors` и наследование цвета). Из новой темы — библиотека `fonts`, класс `fonts.Font`: единственный метод `load_from_file(путь)` (формат ttf/otf/woff/woff2 определяется **по содержимому**, не по расширению); read-only свойства `src`/`format`/`is_loaded` («их заполняет только сам Font — поэтому они всегда говорят правду»); свойство виджета `font` (рисунок букв) при отдельном `font_size` (размер); **наследование от окна**: `win.font` и `win.font_size` — как у `text_color`; отсутствующие в шрифте символы рисуются запасным системным шрифтом.
- *Нельзя (рано):* SpinBox/Slider (№7–8), LineEdit (№9), IdySS-стили и `font-weight`/`font-style` (№11), `visible`/`enabled` (№17), массивы виджетов (№20), `sender` (№21), Timer (№22).
- *Проверенные диагностики (1.2.8):* файла нет → `runtime error: Font.load_from_file() cannot load '...': file does not exist`; не-шрифт в шкуре `.ttf` → `runtime error: Font.load_from_file() cannot decode '...': unsupported font format (expected TTF, OTF, WOFF, or WOFF2)`; запись в паспорт → `compile error: property 'src' is read-only`.
- *Градиент:* **блок 1 — атомарные консольные** (файл и его паспорт), **блок 2 — шрифт в окне**, **блок 3 — наследование**, **блок 4 — динамика**, **блок 5 — звёздочки**. Карта — в заметке.
- *Словарь:* шрифт, файл шрифта, формат, загрузка, паспорт (read-only свойства), наследование, запасной шрифт, панграмма.

`font_size` менял буквам рост, но не характер: какими были, такими и оставались. Сегодня буквы получают характер — строгий, округлый, рукописный — из **файла шрифта**. Заодно случится событие поважнее шрифтов: программа впервые обзаводится **ресурсами** — файлами, которые лежат рядом с кодом и без которых она не работает. Дальше этой дорогой придут картинки и звуки.

# Блок 1. Паспортный стол

Файл шрифта — штука с секретами, и удобнее всего допрашивать его без окон: консоль никуда не делась.

## Практика с преподавателем

### Задание 1. Паспорт шрифта

Положите файл шрифта рядом с программой и наберите:

```idyllium
use console;
use fonts;

main() {
    fonts.Font pero;
    pero.load_from_file("Lobster-Regular.ttf");

    console.writeln("Файл: ", pero.src);
    console.writeln("Формат: ", pero.format);
    console.writeln("Загружен: ", pero.is_loaded);
}
```

```
Файл: Lobster-Regular.ttf
Формат: ttf
Загружен: true
```

Один класс `Font`, один метод `load_from_file` — а формат он определил сам, заглянув внутрь файла. Три свойства — паспорт шрифта, и паспорт этот **только для чтения**: допишите строку `pero.src = "хитрость.ttf";` и запустите — компилятор отрежет: `property 'src' is read-only`. Заполнять паспорт имеет право только сам `Font` — поэтому паспорт никогда не врёт.

## Самостоятельная практика

### Задание 2. Файла нет

Поломка, с которой начнётся почти каждый ваш урок с ресурсами. В программе из задания 1 испортите имя файла — например, потеряйте одну букву: `"Lobstr-Regular.ttf"`. Запустите и прочитайте отказ: `Font.load_from_file() cannot load '...': file does not exist`. Программа не делает вид, что всё хорошо, — она останавливается и называет файл, которого не нашла. Почините и запомните порядок осмотра: имя, расширение, папка.

### Задание 3. Детектив по содержимому

Эксперимент — проверим слова урока «формат определяется по содержимому, а не по расширению». Сделайте **копию** файла шрифта и переименуйте её во что-нибудь бессмысленное: `misterio.bin`. Загрузите копию в программу-паспорт из задания 1. Предскажите до запуска: что скажет `format` — «bin»? Откажется? Запустите: паспорт невозмутимо сообщает настоящий формат — `Font` смотрел внутрь файла, а расширение ему безразлично. Вывод для жизни: расширение — это обещание, а формат — правда; верить стоит второму.

### Задание 4. Волк в овечьей шкуре

Обратный эксперимент. Создайте обычный текстовый файл со строкой «Это просто текст, а не шрифт» и переименуйте его в `wolf.ttf`. Загрузите. Овечья шкура не помогла: `Font.load_from_file() cannot decode 'wolf.ttf': unsupported font format (expected TTF, OTF, WOFF, or WOFF2)`. Сравните отказы из заданий 2 и 4 — они разные, и это подарок: по тексту ошибки сразу ясно, файла **нет** или файл **не тот**. Умение различать такие отказы — половина работы с ресурсами.

# Блок 2. Шрифт выходит на экран

## Практика с преподавателем

### Задание 5. Вывеска пекарни

Наберите:

```idyllium
use fonts;
use gui;

main() {
    fonts.Font pero;
    pero.load_from_file("Lobster-Regular.ttf");

    gui.Window win;
    win.width = 440;
    win.height = 150;
    win.title = "Пекарня";

    gui.Label sign;
    sign.text = "Плюшки у Плюшкина";
    sign.x = 40;
    sign.y = 40;
    sign.width = 360;
    sign.font = pero;
    sign.font_size = 34;

    win.add_child(sign);
    win.show();
}
```

Вывеска написана рукописно — характер букв приехал из файла. Разделение труда запомните навсегда: `font` отвечает за **рисунок** букв, `font_size` — за **размер**, и живут они отдельно. Закомментируйте строку `sign.font = pero;` и запустите ещё раз: размер остался, характер пропал — вывеска снова казённая.

## Самостоятельная практика

### Задание 6. Один рисунок — три роли

Один объект `Font` не обязан служить одному виджету. Загрузите шрифт **один раз** и раздайте его трём лейблам: «Заголовок» (36), «Подзаголовок» (22), «мелкая подпись» (13). Принимается глазами: характер у всех троих один, роли — разные, и в программе ровно один `load_from_file`. Загружать один файл трижды — как покупать три одинаковые ручки, чтобы подписать три тетради.

### Задание 7. Дуэт шрифтов

Главное правило типографики: шрифта в работе — **два**, декоративный для заголовка и строгий для текста. Страница кулинарной книги: «Блинчики бабушкины» — рукописным (30), рецепт «Мука, два яйца, стакан молока, щепотка соли.» — строгим (15). Два объекта `Font`, два файла. Принимается глазами: заголовок зовёт, текст читается. Контрольный вопрос: почему не наоборот — рецепт завитушками, заголовок казённо? (Попробуйте поменять местами и почитать рецепт вслух.)

# Блок 3. Типографика через окно

### Задание 8. Кафе «Клякса»

Назначать шрифт каждому виджету — надоест к третьему. Меню кафе: заголовок «Наше меню» и три строки с ценами. Шрифт и базовый размер задайте **окну**: `win.font = pero;` и `win.font_size = 18;` — все виджеты возьмут их сами, как брали `text_color` в уроке о цветах. Заголовку — личный `font_size = 32` (личное побеждает родительское, размер — а характер остаётся общим). Проверка знаний одной строкой: сколько мест в программе придётся менять, чтобы всё кафе сменило почерк? (Правильный ответ — одно.)

### Задание 9. Запасной игрок

Эксперимент с подвохом, ради которого преподаватель принёс латинский шрифт. Надпись «GAME OVER, приятель!» оформите шрифтом без кириллицы (`Bangers-Regular.ttf`). Запустите и приглядитесь: «GAME OVER» — фирменным начертанием, а «приятель» — обычным. Ошибки нет, программа молчит: отсутствующие буквы тихо дорисовал **запасной системный шрифт**. Это самая коварная поломка урока — без единого сообщения; лечится она на этапе выбора шрифта: скачиваете — проверьте, что кириллица в нём есть.

# Блок 4. Живая типографика

### Задание 10. Машина времени

Шрифт — такое же свойство, как текст и цвет: его можно менять по клику. Фраза «Idyllium forever» и три кнопки-эпохи: «Рукопись», «Газета», «Комикс» — каждая надевает на фразу свой из трёх загруженных шрифтов. Проверка кликом: преподаватель щёлкает эпохи в произвольном порядке — фраза обязана переодеваться мгновенно и в любом направлении; заодно он спросит, сколько раз в программе встречается `load_from_file` (правильно — три: по разу на файл, а не на клик!).

### Задание 11. Пульт типографа

Соедините машину времени с приёмом «размер — тоже свойство» (шарик из задачника про Label помните?). Образец «Съешь ещё этих мягких булок» и две пары кнопок: «Рукописный»/«Строгий» меняют `font`, «Крупнее»/«Мельче» гоняют `font_size` по ±4 — со сторожами, чтобы размер жил в пределах 8–72 («полоска не имеет права врать» — и образец не имеет права ни исчезнуть, ни лопнуть). # Блок 5. Со звёздочкой

### Задание 12 ⭐. Афиша фестиваля

Помните афишу из задачника про Label? Пересоберите её как настоящий типограф: афиша школьного фестиваля минимум из четырёх надписей, заголовок — декоративным шрифтом (36 и больше), детали — строгим (16 и меньше), палитра — максимум два цвета из библиотеки `colors` (цвет — акцент, а не карнавал). Оба шрифта — через два объекта `Font`; базовый шрифт и цвет ведите **через окно**, личными настройками выделяйте только акценты. Принимается глазами с другого конца кабинета: заголовок должен читаться, характер — чувствоваться.

### Задание 13 ⭐. Дегустация панграмм

Панграмма — фраза со всеми буквами алфавита, профессиональный дегустационный стенд шрифтовиков. Покажите «Съешь же ещё этих мягких французских булок» двумя-тремя шрифтами: под каждой строкой — серая мелкая бирка, которую программа собирает **сама** из паспорта: `"из файла: " + first.src + " (" + first.format + ")"`. Склейка строк — из багажа, паспорт — из задания 1, и бирка не может соврать: она читает те же read-only свойства, что и вы. Проверка: преподаватель сверяет бирки с настоящими именами файлов в проекте.

### Задание 14 ⭐. Фирменная типографика

Творческий финал с домашней подготовкой: выберите на Google Fonts **свой** шрифт (проверив кириллицу — задание 9 научило, чем это кончается), скачайте, положите в проект. Соберите витрину любимого продукта — игры, канала, кафе — по чек-листу: два шрифта (свой + строгий), базовая типографика через `win.font`/`win.font_size`, иерархия минимум из трёх размеров, цвета из №5 согласованы с характером шрифта. Сдача-защита: покажите паспорт своего шрифта программой из задания 1 и объясните, почему выбрали именно этот характер букв.

### Минутка из внешнего мира. Буквы как профессия

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- Фраза про мягкие французские булки — не шутка, а рабочий инструмент: **панграмма**, в которой встречаются все буквы алфавита. Английские шрифты дегустируют фразой «The quick brown fox jumps over the lazy dog». Показал панграмму — показал весь шрифт: с 33 буквами иначе пришлось бы листать таблицы.
- Каждый шрифт кто-то нарисовал — буква за буквой, со всеми начертаниями это месяцы работы. Поэтому шрифты продаются и лицензируются, как музыка. Google Fonts — библиотека из полутора с лишним тысяч шрифтов, которые дизайнеры подарили всем: то, что вы скачали файл и подключили его строкой кода, — это тот же путь, каким собирается типографика больших сайтов и приложений.
- Русский строгий шрифт из нашего урока, PT Sans, создан к 300-летию гражданского шрифта — азбуки, которую утвердил лично Пётр I, собственноручно вычеркнув лишние буквы. Так что реформы типографики в наших краях начались задолго до компьютеров.

**Карта градиента** (для подбора под силу группы):
- *атомарные консольные* — з.1–4 (паспорт и read-only; «файла нет»; детектив по содержимому; волк в овечьей шкуре — все проверяются живым запуском);
- *шрифт в окне* — з.5–7 (вывеска у доски; один объект на три роли; правило двух шрифтов);
- *наследование* — з.8–9 (типографика через окно; запасной шрифт — молчаливая ловушка кириллицы);
- *комплексные* — з.10–11 (смена шрифта по клику; пульт со сторожами размера);
- *звёздочки* — з.12–14 (афиша, панграммы с самоподписью из паспорта, свой шрифт с защитой).

Красная нить — **ресурс и его паспорт**: файл лежит рядом с программой, загружается по имени, о проблемах говорит внятными отказами (нет файла / не тот файл), а его свойства-паспорт не умеют врать. Вторая ценность — базовая типографика: рисунок отдельно от размера, два шрифта на работу, стиль через окно. Единственная молчаливая ловушка темы — запасной шрифт на месте отсутствующей кириллицы — отработана отдельным экспериментом, чтобы встреча с ней в жизни не была первой.
