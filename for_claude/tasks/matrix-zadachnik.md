Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод», со случайностью — помечены «например».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–29; из новой темы — объявление `array<array<int, 6>, 4>` (внутренний тип — строка, внешний — стопка строк: 4 строки × 6 столбцов), строгий инициализатор (размеры обязаны сойтись!), доступ `mx[строка][столбец]` (порядок!), запись в ячейку, вложенные `for` (внешний — по строкам), агрегирование `total += mx[r][c]`.
- *Нельзя (рано):* динамических матриц (`dyn_array<dyn_array<…>>` уроком не введён), рекурсии (№31). Трёхмерный куб — только упомянуть, не задавать.
- *Градиент:* **блок 1 — атомарные** (ячейки и границы), **блок 2 — полукомплексные** (+ один инструмент), **блок 3 — комплексные** (турнир, кинозал, клад), **блок 4 — звёздочки**. Карта — в заметке.
- *Словарь:* двумерный массив, таблица, строка, столбец, вложенные циклы.

Одномерный массив — это линия, двумерный — **таблица**, а таблица — это почти весь мир: игровые поля, кинозалы, журналы оценок, пиксельные картинки. Тема сшивает всё пройденное: массивы, вложенные циклы, условия — и впервые даёт по-настоящему **пространственные** задачи. **Важно:** двойные границы и прочие сюрпризы ученик открывает сам.

# Блок 1. Таблица и её ячейки

## Практика с преподавателем

### Задание 1. Турнирная таблица

Четверо друзей сыграли по шесть раундов — вот и таблица: строка на игрока, столбец на раунд. Наберите:

```idyllium
use console;

main() {
    array<array<int, 6>, 4> mx = [
        [26, 41, 73, 19, 87, 52],
        [65, 20, 42, 67, 18, 38],
        [74, 55, 93, 10, 24, 89],
        [12, 53, 40, 63, 94, 76]
    ];

    console.writeln(mx[0][0]);
    console.writeln(mx[1][3]);

    mx[1][3] = 99;
    console.writeln(mx[1][3]);
}
```

```
26
67
99
```

Разбор типа `array<array<int, 6>, 4>`: внутри — строка из шести чисел, снаружи — четыре такие строки. Адрес ячейки — два индекса: **сначала строка, потом столбец**, счёт с нуля. А запись `mx[1][3] = 99` — судья пересмотрел запись матча и поправил очки второго игрока в четвёртом раунде.

## Самостоятельная практика

### Задание 2. Мини-расписание

Составьте таблицу-расписание 2×3: две строки (пн, вт), три столбца (первый, второй, третий урок), в ячейках — номера кабинетов. Выведите кабинет второго урока понедельника и третьего урока вторника. Не перепутайте, что здесь строка, а что столбец!

```
Пн, 2-й урок: кабинет 215
Вт, 3-й урок: кабинет 108
```

### Задание 3. Промах в двух измерениях

Поломка, два опыта. У таблицы границ вдвое больше — и промахнуться вдвое проще. На турнирной таблице из задания 1 попробуйте: (а) `mx[10][0]` — десятый игрок; (б) `mx[0][10]` — десятый раунд. Запустите оба и **сравните сообщения**: числа в них разные! Разберитесь, почему в первом случае ошибка говорит про размер 4, а во втором — про размер 6.

### Задание 4. Потерянное очко

Ещё поломка. Объявите таблицу 2×3, но во второй строке «потеряйте» одно число:

```idyllium
    array<array<int, 3>, 2> mx = [
        [1, 2, 3],
        [4, 5]
    ];
```

Запустите и прочитайте отказ: инициализатор обязан совпадать с типом по размерам — ровно 2 строки по ровно 3 числа, дырок таблица не терпит.

# Блок 2. Плюс один инструмент

## Практика с преподавателем

### Задание 5. Вся таблица на экран

Печать таблицы — фирменное движение темы: вложенные циклы, внешний по строкам, внутренний по столбцам. Наберите (таблица — из задания 1):

```idyllium
    for (int row = 0; row < 4; row += 1) {
        for (int col = 0; col < 6; col += 1) {
            console.write(mx[row][col], " ");
        }
        console.write('\n');
    }
```

```
26 41 73 19 87 52 
65 20 42 67 18 38 
74 55 93 10 24 89 
12 53 40 63 94 76 
```

Внутренний цикл печатает одну строку таблицы, перенос — и внешний берётся за следующую. Запомните это движение: сумма, максимум, поиск — всё ходит по таблице именно так.

## Самостоятельная практика

### Задание 6. Справочная касса *(+ ввод)*

В таблице 3×4 — цены мест кинотеатра (ближние ряды дешевле, задние дороже — заполните по вкусу). Программа спрашивает ряд и место и называет цену: просто чтение `hall[r][c]`, но координаты — от пользователя. Преподаватель спросит про несколько разных мест.

```
Ряд (0-2): 1
Место (0-3): 2
Цена: 350 монет
```

### Задание 7. Поле случайностей *(+ случайность)*

Заполните таблицу 4×4 случайными числами от 1 до 9 (вложенные циклы с записью `mx[r][c] = ...`) и выведите её. Каждый запуск — новое поле; так генерируются уровни в настоящих играх.

```
3 7 1 9
2 2 8 4
5 1 6 3
9 4 2 7
```

(Числа случайные — у вас своё поле.)

### Задание 8. Печатник таблиц *(+ функции)*

Печать таблицы нужна в каждом задании — оформите её раз и навсегда: функция `print_field(field)` принимает таблицу 3×3 **параметром** и печатает её. В `main` — две разные таблицы, два вызова. Да, матрицы ходят в функции как обычные аргументы!

```
1 2 3 
4 5 6 
7 8 9 
5 5 5 
5 5 5 
5 5 5
```

# Блок 3. Турнир, кинозал и клад

## Практика с преподавателем

### Задание 9. Общий котёл

Сколько очков заработали все игроки вместе? Обойти таблицу и сложить всё в накопитель:

```idyllium
    int total = 0;
    for (int r = 0; r < 4; r += 1) {
        for (int c = 0; c < 6; c += 1) {
            total += mx[r][c];
        }
    }
    console.writeln("Сумма очков турнира: ", total);
```

```
Сумма очков турнира: 1231
```

Тот же обход, что при печати, — только вместо `write` в теле копится сумма.

## Самостоятельная практика

### Задание 10. Кто чемпион

Главный вопрос турнира! Для каждой строки (игрока) посчитайте сумму очков — внутренний цикл с накопителем, обнуляемым на каждого игрока, — выведите её и по пути ищите рекордсмена знакомым приёмом чемпиона. В финале — объявление победителя.

```
Игрок 1: 298 очков
Игрок 2: 250 очков
Игрок 3: 345 очков
Игрок 4: 338 очков
Чемпион — игрок 3!
```

### Задание 11. Разрез по вертикали

А теперь — вопрос про **столбец**: сколько очков всеми игроками набрано в раунде N? Программа спрашивает номер раунда и суммирует его столбец: цикл бежит по строкам, а столбец стоит на месте (`mx[r][col]`). Прочувствуйте разницу с задании 10 — там резали по горизонтали, тут по вертикали.

```
Какой раунд посчитать (1-6): 3
Все очки раунда 3: 248
```

### Задание 12. Кинозал

Таблица 3×4 — зал: 0 — свободно, 1 — занято (заполните частично). Программа печатает карту зала (`.` свободно, `X` занято), спрашивает ряд и место, и: свободно — продаёт (запись 1 в ячейку!) и поздравляет, занято — извиняется. В конце — обновлённая карта. Настоящая система бронирования в двадцать строк.

```
Ряд (0-2): 1
Место (0-3): 2
Билет продан!
.X..
XXXX
...X
```

### Задание 13. Остров сокровищ

Пираты зарыли клад в случайной клетке поля 3×3 (`random` для строки и столбца — координаты держатся в секрете). Игрок вводит догадку: попал — триумф, промазал — программа честно показывает, где лежал клад. Сыграйте несколько партий.

```
Строка (0-2): 1
Столбец (0-2): 2
Пусто. Клад был в клетке [0][0]
```

### Задание 14. Шахматная доска

Не всякая таблица хранится — иные вычисляются на лету. Напечатайте шахматную доску 8×8: клетка чёрная (`█`), если сумма её индексов чётная, и белая (пробел) — если нечётная (`mod(r + c, 2)` решает всё). Полюбуйтесь: две строчки условия — и целая доска.

```
█ █ █ █ 
 █ █ █ █
█ █ █ █ 
 █ █ █ █
...
```

# Блок 4. Со звёздочкой

### Задание 15 ⭐. Пиксель-арт

Каждая картинка на экране — таблица точек. Нарисуйте свою: таблица 7×7 из нулей и единиц, где единица — закрашенный пиксель (`█`), ноль — пробел. Сначала «проявите» наш узор, потом сотрите и нарисуйте своё: смайлик, сердце, первую букву имени. Рисовать придётся прямо в инициализаторе — как настоящие художники по пикселям.

```
  ███  
 █   █ 
█ █ █ █
█     █
█ █ █ █
 █ █ █ 
  ███  
```

### Задание 16 ⭐. Таблица Пифагора 2.0

В теме циклов вы **печатали** таблицу умножения. Теперь — **постройте** её как данные: заполните таблицу 9×9 значениями `(r + 1) * (c + 1)` вложенными циклами, а потом выведите. Разница тонкая, но важная: напечатанное исчезло с экрана, а заполненная таблица осталась в руках — у неё можно спросить любую ячейку. Докажите: после вывода спросите у пользователя два числа и покажите их произведение **чтением из таблицы**, без умножения.

```
Сколько будет 7 на 8? Смотрим в таблицу: 56
```

### Задание 17 ⭐. Бинго по диагонали

Поле «крестиков-ноликов» 3×3 (0 — пусто, 1 — крестик, заполните инициализатором). Проверьте, победил ли крестик **по главной диагонали** — клетки, у которых номер строки равен номеру столбца (`mx[i][i]`!). Догадайтесь, как обойти диагональ одним циклом с одним счётчиком — и как флагом `bool` убедиться, что крестик занял все три клетки.

```
Диагональ крестика: победа!
```

### Минутка из внешнего мира. Мир как таблица

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- Экран, на который вы смотрите, — двумерный массив: Full HD — это таблица 1920×1080, больше двух миллионов ячеек-пикселей, и в каждой — цвет (те самые три байта из урока про types!). Ваш пиксель-арт 7×7 и киношный кадр различаются только размером.
- Шахматисты записывают ходы как «e2–e4» — это те же два индекса, строка и столбец, только столбцы названы буквами. А «Морской бой» на бумажке в клеточку — чистый двумерный массив, в который вы играли задолго до этого урока.
- Ну и главное: современные нейросети — это, по сути, гигантские таблицы чисел, которые перемножают друг друга. Слово «матрица» вы теперь понимаете буквально — и оно куда прозаичнее и прекраснее, чем в кино.
