# Задачник: Работа с файлами

Урок №27 раздела «Консоль». Составлен 2026-08-03 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор — с настоящими файлами; содержимое файлов в образцах показано дословно.

**Для преподавателя.**
- *Доступно:* всё из уроков 1–26, **включая собственные функции**; из новой темы — `use file;`, `file.open(имя, "write"|"read")` → `file.ostream`/`file.istream`, запись `write(...)`/`write_line(...)` (как `console.write`/`writeln`, только в файл), чтение `read_line()` (**с хвостиком `'\n'`!**), `has_next_line()`, `read_all()`, `read(n)`, обязательный `close()`, полноценный `.trim()`. Файл для записи создаётся сам; файл для чтения обязан существовать. Режим `"write"` **перезаписывает** существующий файл — режима дописывания нет.
- *Нельзя (рано):* папок и проверок (`exists`, `copy`, `list_directory` — №28; защищаемся не проверками, а порядком действий), `try/catch` (№33 — отсутствие файла честно роняет программу с понятной ошибкой).
- *Анти-обход здесь природный:* результат задания — **сам файл**, и `writeln`-ом его не подделать. А для заданий на чтение есть приём-страховка: «преподаватель подложит свой файл» — программа обязана справиться с любым содержимым, не только со своим.
- *Градиент:* **блок 1–2 — атомарные** (запись; чтение), **блок 3 — полукомплексные** (+ один инструмент), **блок 4 — комплексные**, **блок 5 — звёздочки**. Карта — в заметке.
- *Словарь:* файл, поток, запись, чтение, построчное чтение, закрытие.

До этого урока всё, что делали программы, испарялось при завершении. Сегодня появляется **память навсегда**: сейвы, дневники, журналы — всё, что переживает выключение. Тема сама просится в руки: почти каждое задание оставляет после себя настоящую вещь, которую можно открыть в дереве проекта и потрогать. **Важно:** сюрпризы (хвостатые строки, перезапись) ученик открывает сам.

# Блок 1. Записать

Начинаем с записи — и это не случайность, а тот же порядок, что был у консоли: сначала вы научились **выводить**, и лишь потом — вводить. К тому же создать собственный файл проще и веселее, чем разбирать чужой: через минуту у вас появится вещь, которой ещё не существовало.

## Практика с преподавателем

### Задание 1. Первый файл

Наберите и запустите:

```idyllium
use file;

main() {
    file.ostream fout = file.open("output.txt", "write");
    fout.write_line("Привет, мир!");
    fout.write_line("Рекорд: ", 9000, " очков");
    fout.write("Файл создан с помощью Idyllium!");
    fout.close();
}
```

Консоль промолчала — а работа сделана: найдите в дереве проекта новорождённый `output.txt` и откройте его:

```
Привет, мир!
Рекорд: 9000 очков
Файл создан с помощью Idyllium!
```

Разбор: `file.open` с режимом `"write"` открывает поток (файл создаётся сам), `write_line` пишет строку с переносом, `write` — без, а `close()` — обязательный финал: закрыл файл — работа завершена честно. Впервые ваш результат **переживёт** программу.

# Блок 2. Прочитать

## Практика с преподавателем

### Задание 5. Хвостатые строки

Прочитаем файл вручную и наткнёмся на сюрприз. Наберите (файл `tools.txt` сначала создайте программой: строки «Кирка», «Топор», «Меч»):

```idyllium
use console;
use file;

main() {
    file.istream fin = file.open("tools.txt", "read");
    string a = fin.read_line();
    string b = fin.read_line();
    string c = fin.read_line();
    fin.close();
    array<string, 3> t = [a, b, c];
    console.writeln(t);
}
```

```
["Кирка\n", "Топор\n", "Меч"]
```

Видите хвосты `\n`? `read_line` честно отдаёт строку **вместе с переносом** (у последней его нет — потому она без хвоста). Лекарство вы знаете со времён методов строк: `.trim()`. Допишите его к каждому `read_line()` и убедитесь, что хвосты отвалились.

### Задание 6. Читать, пока читается

Ручное чтение годится, только когда число строк известно. Для остальных случаев — `has_next_line()`. Наберите:

```idyllium
use console;
use file;

main() {
    dyn_array<string> lines;
    file.istream fin = file.open("tools.txt", "read");
    while (fin.has_next_line()) {
        lines.add(fin.read_line().trim());
    }
    fin.close();
    console.writeln(lines);
}
```

```
["Кирка", "Топор", "Меч"]
```

Цикл «пока есть строки — читай» проглотит файл любой длины. Эта пара строк — главный рабочий приём всей темы.

### Задание 8. Письмо целиком

Запишите в файл `letter.txt` короткое письмо (три-четыре строки), а второй программой прочитайте его **одним глотком** — `read_all()` — и выведите в консоль. Никаких циклов: когда нужен весь текст сразу, он берётся одной командой.

### Задание 9. Заголовок отдельно

В файле `story.txt` — дневник шахтёра: первая строка «Дневник шахтёра», дальше записи по дням. Прочитайте **заголовок** отдельно (`read_line` + `trim`), а весь остаток — одним `read_all()`, и выведите с пометками. Чтение продолжается с того места, где остановилось, — этим и пользуемся.

```

День 1. Нашёл уголь.
День 2. Нашёл алмазы!
```

### Задание 10. Первые буквы

Метод `read(n)` читает ровно `n` символов. Запишите в файл слово «котики», а второй программой прочитайте сначала три символа, потом весь остаток — и выведите обе части. Считаются именно символы, не байты, — кириллица не ломается (привет, урок про кодировки!).

```
Первые три символа: кот
Остаток: ики
```

# Блок 4. Собираем настоящие вещи

## Практика с преподавателем

### Задание 15. Дневник до стопа

Соединим ввод-до-стопа с записью. Наберите:

```idyllium
use console;
use file;

main() {
    file.ostream fout = file.open("diary.txt", "write");
    console.write("Событие (стоп — конец): ");
    string entry = console.get_string();
    while (entry != "стоп") {
        fout.write_line(entry);
        console.write("Событие (стоп — конец): ");
        entry = console.get_string();
    }
    fout.close();
    console.writeln("Дневник сохранён!");
}
```

```
Событие (стоп — конец): Проснулся
Событие (стоп — конец): Поел
Событие (стоп — конец): стоп
Дневник сохранён!
```

Файл `diary.txt`:

```
Проснулся
Поел
```

Знакомый сбор «до стопа» — только копится он теперь не в массив, а прямо в вечность. Слово «стоп» в дневник, конечно, не попало.

### Задание 24 ⭐. Программа читает саму себя

Файл с вашим кодом — тоже файл. Откройте из программы… её собственный исходник (`main.idyl`) и выведите его первую строку. Голова кружится? Это нормально: программа, читающая собственный текст, — любимый фокус информатики. А если вывести исходник целиком — программа напечатает всю себя, включая строку, которая печатает.

```
Первая строка меня самого: use console;
```

### Минутка из внешнего мира. Всё вокруг — файлы

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- Сейв любимой игры — файл. Фотография — файл. Эта страница учебника, ваш код, даже сами программы — файлы. Всё, что переживает выключение компьютера, лежит в файлах — и сегодня вы научились главному действию цифрового мира.
- Расширение — `.txt`, `.idyl`, `.png` — не магия, а просто хвост имени, подсказка «чем меня открывать». Переименование `песня.mp3` в `песня.txt` не превратит музыку в текст — байты внутри останутся теми же (привет, урок про кодировки).
- А режим «дописать в конец», которого вам, возможно, не хватило в дневнике, в больших языках существует — называется *append*. Idyllium приберёг его на будущее: сначала стоит накрепко усвоить честный цикл «прочитал — обработал — записал», которым сегодня и пользовались.
