# Задачник: Виджет Label

Урок №3 раздела «Виджеты». Составлен 2026-08-03 по [лестнице навыков GUI](../ladder/gui-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все программы прогнаны через компилятор (`check`); поведение при кликах описано по шагам и **проверяется живым кликом в Web IDE**, статические композиции принимаются глазами — тут вид и есть продукт.

**Для преподавателя.**
- *Доступно:* весь консольный курс (багаж) + №1 (окно, кнопка-мебель, координаты, `theme`) + №2 (событие `on_click`, счётчики между кликами, `win.close()`); из новой темы — `gui.Label` полноправно: `text` (**string!** — числа только через `to_string`), `x`/`y`, `font_size` (int, пиксели; «влияет на отображение, но не на координаты»), `text_color`; динамическая смена `text` из обработчиков; **перекрытие** (виджеты не двигаются сами — при пересечении координат накладываются); **z-порядок = порядок `add_child`** (первый — снизу, последний — сверху).
- *Ход конём:* из библиотеки `colors` разрешены **только** `colors.RED`, `colors.GREEN`, `colors.BLUE` — урок сам ограничивает: «пока нам хватит трёх самых простых», полная палитра — №5. В заданиях не выходить за тройку!
- *Нельзя (рано):* `background_color`/`border_color` и остальные цвета (№5), свои шрифты (№6), SpinBox/Slider/LineEdit (№7+), `visible`/`enabled` (№17), массивы виджетов (№20 — лейблы только поштучно!), Timer (№22 — никакой автосмены текста, только по кликам).
- *Градиент:* **блок 1 — атомарные** (окно + Label), **блок 2 — цвет** (тройка констант), **блок 3 — динамика** (+кнопка из №2), **блок 4 — слои**, **блок 5 — звёздочки**. Карта — в заметке.
- *Словарь:* надпись (лейбл), размер шрифта, перекрытие, порядок добавления (z-порядок).

Кнопка была голосом пользователя — Label станет голосом **программы**: всё, что окно хочет сказать, оно говорит надписями. Тема тихая, но именно из лейблов состоит львиная доля любого интерфейса: заголовки, подписи, счётчики, статусы. Учимся говорить красиво: размером, цветом, местом и — впервые — **слоями**.

# Блок 1. Надпись на своём месте

## Практика с преподавателем

### Задание 1. Первая надпись

Наберите:

```idyllium
use gui;

main() {
    gui.Window win;
    win.width = 400;
    win.height = 200;
    win.title = "Первая надпись";

    gui.Label greeting;
    greeting.text = "Привет, окно!";
    greeting.x = 100;
    greeting.y = 60;
    greeting.font_size = 24;

    win.add_child(greeting);
    win.show();
}
```

Лейбл — виджет-надпись: ничего не нажимает, просто показывает текст. Всё хозяйство знакомо по кнопке: `text`, координаты, `add_child`. Новичок один — `font_size`: размер букв в пикселях. Поменяйте 24 на 12 и на 48, запустите трижды — почувствуйте масштаб.

## Самостоятельная практика

### Задание 2. Бейдж участника

Соберите себе бейдж конференции юных программистов — три надписи в одном окне: имя (крупно, 28), роль «Юный программист» (средне, 16), девиз (мелко, 12). Выровняйте по левому краю — одинаковый `x`, разные `y`. Типографика начинается с иерархии: главное — крупнее.

### Задание 3. Число не пролезет

Поломка. Выведите на лейбл «счастливое число» напрямую:

```idyllium
    lucky.text = random.create_int(1, 100);
```

Запустите `check` и прочитайте отказ — старый знакомый из мира консоли: `text` ждёт строку, а не число. Лекарство вы знаете тридцать уроков как: `to_string`. Почините — и на каждом запуске на бейдже своё число.

### Задание 4. Слон и мышка

Эксперимент. Поставьте два лейбла на **одинаковый** `y = 60`: «мышка» размером 12 и «СЛОН» размером 40. Запустите и приглядитесь: стоят ли они «на одной строке»? Правило урока — размер шрифта влияет на отображение, но не на координаты: `y` задаёт точку крепления, а не линию, на которой стоят буквы. Слон и мышка приколоты на одной высоте — но выглядят по-разному. Запомните это, пригодится при вёрстке.

# Блок 2. Три краски

Полная палитра ждёт через два урока — а пока урок выдал нам ровно три тюбика: `colors.RED`, `colors.GREEN`, `colors.BLUE` (не забудьте `use colors;`).

## Практика с преподавателем

### Задание 5. Пешеходный светофор

У пешеходного светофора две секции. Наберите:

```idyllium
use gui;
use colors;

main() {
    gui.Window win;
    win.width = 220;
    win.height = 240;
    win.title = "Светофор";

    gui.Label red_lamp;
    red_lamp.text = "СТОЙ";
    red_lamp.x = 70;
    red_lamp.y = 40;
    red_lamp.font_size = 24;
    red_lamp.text_color = colors.RED;

    gui.Label green_lamp;
    green_lamp.text = "ИДИ";
    green_lamp.x = 78;
    green_lamp.y = 150;
    green_lamp.font_size = 24;
    green_lamp.text_color = colors.GREEN;

    win.add_child(red_lamp);
    win.add_child(green_lamp);
    win.show();
}
```

`text_color` принимает значение из библиотеки `colors` — так надпись обретает голос погромче: красный кричит «стой», зелёный разрешает.

## Самостоятельная практика

### Задание 6. Статусы отряда

Панель отряда из трёх строк-статусов, цвет говорит сам за себя: «Аня — в сети» зелёным, «Боря — не в сети» красным, «Витя — думает» синим. Плюс заголовок «Мой отряд» покрупнее, обычного цвета. Цвет — не украшение, а информация: по такой панели статус считывается раньше, чем прочитан текст.

# Блок 3. Надпись оживает

Главная сила лейбла — его `text` можно менять из обработчиков. Табло, которое переписывает себя по клику, — сердце почти любого интерфейса.

## Практика с преподавателем

### Задание 7. Кубик

Пример из урока — соберите и прочувствуйте связку: кнопка «Бросить кубик», лейбл с результатом.

```idyllium
use gui;
use random;

main() {
    gui.Window win;
    win.width = 300;
    win.height = 180;
    win.title = "Кубик";

    gui.Label result;
    result.text = "Жми на кнопку!";
    result.x = 90;
    result.y = 40;
    result.font_size = 18;

    gui.Button roll;
    roll.text = "Бросить кубик";
    roll.x = 80;
    roll.y = 110;
    roll.width = 140;
    roll.on_click = void function() {
        int r = random.create_int(1, 6);
        result.text = "Выпало: " + to_string(r);
    };

    win.add_child(result);
    win.add_child(roll);
    win.show();
}
```

Цепочка на разбор: клик → случайное число → `to_string` → склейка → на табло. Четыре консольных навыка выстроились за одной кнопкой.

## Самостоятельная практика

### Задание 8. Настроение дня

Лейбл-вопрос «Какое у тебя настроение?» и три кнопки: «Отличное», «Сонное», «Боевое». Каждая переписывает лейбл своим ответом (придумайте реплики с характером: «Код сам себя не напишет!»). Проверка кликом: три кнопки — три разных ответа.

### Задание 9. Генератор комплиментов

Кнопка «Похвали меня» и лейбл: каждый клик — случайный комплимент из трёх (`random` + три `if`). Пишите комплименты от души — программа, которая хвалит, обязана делать это убедительно. Кликайте, пока не выпадут все три.

### Задание 10. Книжка-листалка

Микрорассказ в три страницы на одном лейбле. Кнопка «Дальше» листает: счётчик страниц + `if` выбирают текст; на последней странице кнопка меняет надпись на «Сначала» и следующий клик возвращает к первой странице. Сочините свою историю в три предложения — и вы автор первой интерактивной книги. Проверка: полный круг кликов.

### Задание 11. Вывеска-переводчик

Вывеска пекарни: название и часы работы (два лейбла) + кнопка «EN». Клик — вся вывеска переключается на английский, кнопка становится «RU»; клик — обратно (тумблер через `if` по тексту кнопки, как выключатель света из прошлой темы — только теперь переключается **контент**). Пригодится каждому приложению планеты.

# Блок 4. Слои

## Практика с преподавателем

### Задание 12. Авария на перекрёстке

Эксперимент из урока. Поставьте длинный лейбл и кнопку на **пересекающиеся** координаты — и запустите. Виджеты не умеют расступаться: кто добавлен `add_child` **позже**, тот и сверху, и наплевать ему на соседа. Поменяйте порядок двух `add_child` местами и запустите снова — верхний и нижний поменялись! Два правила в одном опыте: виджеты не двигаются сами; порядок добавления — это порядок слоёв.

## Самостоятельная практика

### Задание 13. Гриф «СЕКРЕТНО»

Архивный документ: лейбл с текстом «Рецепт бабушкиных блинчиков: мука, молоко...» — и поверх него наискось встал крупный красный штамп «СЕКРЕТНО» (размер 36, `colors.RED`). Сначала нарочно добавьте штамп в окно **первым** — и удивитесь: документ лёг поверх грифа, безобразие! Исправьте порядок `add_child` — штамп обязан быть сверху. Слоями управляют не координаты, а очередь добавления.

# Блок 5. Со звёздочкой

### Задание 14 ⭐. Пульт космического корабля

Приборная панель: заголовок «Системы корабля» и три цветных датчика-лейбла — «Топливо» (зелёный), «Корпус» (синий), «Метеоры» (красный), — все со значением «?». Кнопка «Сканировать» обновляет все три случайными показаниями (`random` + `to_string` + склейка: «Топливо: 87%»). Каждый скан — новая сводка; цвет держит смысл датчика, текст несёт данные.

### Задание 15 ⭐. Надуй шарик

Игра из одного лейбла. «Шарик» — буква «О» размером 16 — и кнопка «Надуть»: каждый клик прибавляет к `font_size` восьмёрку (да, размер шрифта — такое же свойство, его можно наращивать `+=`!). Шарик раздувается на глазах... а на размере 80 — лопается: текст меняется на «БАХ!», кнопка виновато пишет «Ой...». Догадайтесь сами, как поймать момент хлопка. Проверка кликом — до победного «БАХ».

### Задание 16 ⭐. Афиша

Творческий финал: соберите афишу события (концерт, турнир по Idyllium, день рождения кота) минимум из четырёх лейблов. Требования: явная иерархия размеров (заголовок ≥ 32, детали ≤ 14), максимум два цвета из тройки (цвет — акцент, а не карнавал), ни одного случайного перекрытия — а одно **намеренное** (штамп «СКОРО!» поверх) приветствуется. Покажите афишу классу: хорошая типографика читается с другого конца кабинета.

### Минутка из внешнего мира. Мир из надписей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- Присмотритесь к любому приложению: почти всё в нём — лейблы. Заголовок чата, имя контакта, время сообщения, счётчик непрочитанного — десятки надписей на одном экране, и у каждой продуманы размер, цвет и место. Профессия, которая это решает, называется «типографика», и ей больше пятисот лет — со времён печатного станка.
- Правило иерархии из вашего бейджа — всерьёз рабочее: дизайнеры так и проверяют макет «прищуренным глазом» — если при расфокусе главное всё ещё главное, вёрстка удалась.
- А порядок слоёв из задания 13 в больших интерфейсах зовётся «z-index» — и войны за то, чей баннер окажется поверх чьего, — реальная часть жизни веб-разработчика.

**Заметка для преподавателя (запас времени).** Прорешали всё — не открывайте новую тему, а развивайте сделанное:
- книжку-листалку (з.10) дополнить кнопкой «Назад» (счётчик умеет и убывать — но что делать на первой странице?);
- пульт корабля (з.14) скрестить с логикой: после «сканирования» отдельный лейбл-вердикт «Все системы в норме» — но только если топлива больше 20 (обработчик умеет `if` по свежесгенерированному);
- шарик (з.15) сделать честнее: кнопка «Сдуть» уменьшает размер — но не даёт сдуться ниже 16 (`math.clamp` из багажа — для тех, кто помнит).

**Карта градиента** (для подбора под силу группы):
- *атомарные* — з.1–4 (надпись, бейдж, поломка `int`→`text`, опыт «размер ≠ координаты»);
- *цвет* — з.5–6 (тройка констант хода конём; за неё не выходить!);
- *динамика* — з.7–11 (кубик у доски; настроение, комплименты, листалка, переводчик — всё принимается кликом);
- *слои* — з.12–13 (перекрытие и очередь `add_child`);
- *звёздочки* — з.14–16 (пульт, шарик с растущим `font_size`, творческая афиша).

Красная нить — **лейбл как голос программы**: статичный он подписывает, динамичный — отвечает. Вторая ценность — первые законы вёрстки (иерархия размеров, цвет-информация, слои), которые дальше будут работать в каждом уроке раздела. Проверка двухрежимная: композиции — глазами (вид и есть продукт), всё живое — только кликом.
