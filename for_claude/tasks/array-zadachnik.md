**Для преподавателя.**
- *Доступно:* всё из уроков 1–15 — переменные, ввод, арифметика, `writeln` и цвета, `to_string/to_int/to_float`, `math.*`, `if`/`bool`, `random`, логические операции, **циклы**, `time`, **`const`**; из новой темы — `array<тип, размер> имя = [...];` (размер — литерал или именованная константа), фиксированная длина, дефолты без инициализатора, чтение/запись по индексу `a[i]`, **индексация с нуля** (валидные `0..размер-1`), вывод всего массива `writeln(a)`, перебор циклом `for` + `a[i]`, массивы любых базовых типов.
- *Нельзя (рано):* **динамических массивов** (№18 — длина НЕ меняется, «добавить элемент» невозможно!); функций `max/min/sum/avg` (№19 — **всё считаем циклом вручную**); методов `sort/find/contains` (№20); **свойства `.length`** (в этом уроке не введено — размер берём из объявления, циклы пишем `for i < РАЗМЕР`); операций над всем массивом сразу (сравнение/сложение — ошибки, только поэлементно).
- *Словарь:* массив, ячейка, индекс (с нуля), размер, выход за границы, перебор, контейнер, параллельные массивы.

Массивы — тема, которой дети пугаются при поверхностной подаче и на которой скучают при тираже одинаковых задач. Поэтому здесь: сначала делаем массив **осязаемым** (ряд пронумерованных ячеек, как шкафчики в раздевалке), затем показываем его сверхсилу (**один цикл вместо сотни переменных**), и лишь потом — аналитику (чемпион, поиск, подсчёт), где массив перестаёт быть скучным хранилищем и начинает **отвечать на вопросы**. Каждая операция — своя живая история, а не голые числа. **Важно:** поломки (выход за границы, операция над всем массивом) ученик открывает сам.

# Блок 1. Ячейки, индексы и границы

Массив — это ряд пронумерованных ячеек под одним именем. Как шкафчики в раздевалке: одна табличка «5А», а внутри — десяток дверок с номерами. Каждая ячейка хранит своё значение, а добраться до неё можно по номеру — **индексу**.

## Практика с преподавателем

### Задание 1. Ряд ячеек

Заведём массив из пяти чисел — очки пяти игроков — и выведем его целиком. Наберите:

```idyllium
use console;

main() {
    array<int, 5> scores = [120, 340, 90, 500, 210];
    console.writeln(scores);
}
```

```
[120, 340, 90, 500, 210]
```

В угловых скобках `<int, 5>` — тип ячеек и их количество; в квадратных — начальные значения. Пять чисел живут под одним именем `scores`, и весь массив вывелся одной командой.

### Задание 2. Достаём по номеру

К любой ячейке обращаются по индексу в квадратных скобках. Но есть подвох: **ячейки нумеруются с нуля**. Наберите:

```idyllium
use console;

main() {
    array<int, 5> scores = [120, 340, 90, 500, 210];
    console.writeln("Первый игрок: ", scores[0]);
    console.writeln("Третий игрок: ", scores[2]);
    console.writeln("Последний игрок: ", scores[4]);
}
```

```
Первый игрок: 120
Третий игрок: 90
Последний игрок: 210
```

Смотрите внимательно: `scores[0]` — первая ячейка, `scores[2]` — уже **третья**, а последняя из пяти — `scores[4]`, а не `scores[5]`. Программисты обожают считать с нуля; к этому нужно привыкнуть.

# Блок 2. Сила перебора: массив плюс цикл

Помните, зачем вообще нужен массив? Чтобы не заводить сто переменных. Но настоящая сила раскрывается в паре с циклом: одна короткая петля обходит хоть пять ячеек, хоть тысячу. Счётчик цикла бежит по индексам, а `a[i]` на каждом шаге — новая ячейка.

## Практика с преподавателем

### Задание 8. Перебор по одной

Выведем каждую ячейку с новой строки — но не пятью командами, а циклом. Наберите:

```idyllium
use console;

main() {
    array<int, 5> nums = [29, 84, 16, 35, 43];
    for (int i = 0; i < 5; i += 1) {
        console.writeln("Ячейка ", i, ": ", nums[i]);
    }
}
```

```
Ячейка 0: 29
Ячейка 1: 84
Ячейка 2: 16
Ячейка 3: 35
Ячейка 4: 43
```

Счётчик `i` пробегает индексы от 0 до 4, `nums[i]` — каждый раз следующая ячейка. Было бы чисел тысяча — поменяли бы одно число в условии цикла, и всё.

# Блок 3. Массив отвечает на вопросы

Массив — не просто склад. У него можно **спрашивать**: кто рекордсмен? сколько раз случилось то-то? есть ли тут нужное значение? Ответ добывается перебором: пробегаем все ячейки и по дороге что-то запоминаем или считаем. Вот тут массивы и становятся по-настоящему интересными.

## Практика с преподавателем

### Задание 13. Кто рекордсмен

Найдём самое большое число в массиве. Приём такой: считаем рекордсменом нулевую ячейку, а потом сравниваем с ней все остальные — если встретили больше, запоминаем нового чемпиона. Наберите:

```idyllium
use console;

main() {
    array<int, 5> jumps = [129, 84, 165, 91, 143];
    int record = jumps[0];
    for (int i = 1; i < 5; i += 1) {
        if (jumps[i] > record) {
            record = jumps[i];
        }
    }
    console.writeln("Лучший прыжок: ", record, " см");
}
```

```
Лучший прыжок: 165 см
```

Цикл начинается с индекса 1 — нулевую ячейку мы уже назначили временным рекордом. Каждый, кто прыгнул дальше, становится новым рекордсменом.

# Блок 4. Таблицы и превращения

Пока в каждом массиве жил один вид данных. А если про каждого предмета нужно знать сразу и имя, и цену? Заводят **параллельные массивы**: ячейки с одинаковым индексом описывают один и тот же объект. А ещё массив можно менять целиком — проходя по нему циклом.

## Практика с преподавателем

### Задание 18. Турнирная таблица

Имена игроков — в одном массиве, их очки — в другом, «параллельном». Игрок под индексом `i` — это `names[i]` с очками `points[i]`. Наберите:

```idyllium
use console;

main() {
    array<string, 3> names = ["Аня", "Боря", "Витя"];
    array<int, 3> points = [50, 80, 65];
    for (int i = 0; i < 3; i += 1) {
        console.writeln(names[i], ": ", points[i], " очков");
    }
}
```

```
Аня: 50 очков
Боря: 80 очков
Витя: 65 очков
```

Два массива работают как таблица: один индекс — одна строка таблицы. Так связывают разнородные данные, пока у нас нет ничего сложнее.

# Блок 5. Со звёздочкой

### Задание 23 ⭐. Нельзя оптом

Массив — это контейнер, и работать с ним «оптом» нельзя. Проверьте на опытах:

```idyllium
    array<int, 5> P = [78, 91, 63, 50, 24];
    if (P > 50) { console.writeln("больше"); }
```

```idyllium
    console.write(P + 4);
```

Запустите каждый и прочитайте отказы компилятора. «Больше 50» может быть одно число, но не коробка с пятью числами; прибавить 4 ко всему массиву разом — тоже нельзя. А вот к **ячейке** — сколько угодно: `P[0] > 50` и `P[1] + 4` работают отлично. Сделайте вывод: массив обрабатывают **поэлементно**, через перебор.

### Задание 24 ⭐. Предскажи поломку

Загадка на внимательность. Массив из 5 ячеек, а цикл написан так:

```idyllium
    array<int, 5> a = [10, 20, 30, 40, 50];
    for (int i = 0; i <= 5; i += 1) {
        console.writeln(a[i]);
    }
}
```

**Сначала предскажите**: программа отработает целиком, или сломается, и если да — на каком числе? Потом запустите и проверьте. Почему коварно именно `<=`, а не `<`? Это самая частая ошибка при работе с массивами — «на единицу больше».

### Минутка из внешнего мира. Счёт с нуля у соседей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Привычка считать с нуля — не причуда Idyllium, а почти всеобщий закон:
- в **C++, Java, JavaScript, Python** массивы и списки тоже начинаются с индекса `0` — первый элемент везде `a[0]`;
- а вот в **Lua** и старом **Паскале** считают с `1` — там первый элемент `a[1]`. Мигрируя между языками, об этом легко споткнуться.

И ещё одно тонкое различие — что бывает при выходе за границы:
- **Idyllium** честно останавливается с понятным сообщением: «индекс 6 вне границ, допустимы 0–5»;
- а **C++** в этом случае молча лезет в чужую память: программа то ли выдаст мусор, то ли рухнет позже в неожиданном месте — ищи потом причину. Наша читаемая ошибка бережёт часы отладки.

Наконец, наши массивы **фиксированной** длины: сколько ячеек объявили — столько и будет, добавить нельзя. В Python и JavaScript списки умеют расти на ходу — с такими «резиновыми» массивами мы познакомимся уже на следующем уроке.
