# Задачник: Первая программа

Урок №2 раздела «Консоль» — самый первый после установки среды. Составлен 2026-07-30 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все образцы прогнаны через компилятор; вывод здесь полностью предсказуем (ввода, переменных и вычислений ещё нет — программа выводит ровно то, что в неё вписали).

**Для преподавателя.**
- *Доступно (и только это):* структура программы `use console;` + `main() { … }`; вывод `console.write(...)` с любым числом аргументов через запятую; текст в кавычках `"…"` и числа без кавычек; перенос строки `'\n'` (отдельным аргументом или приклеенным к строке); комментарии `//`; точка с запятой `;` после команды; отступ 4 пробела.
- *Нельзя (рано):* переменных и типов (№3), ввода `get_*` (№4), арифметики (№5 — **нельзя** просить «посчитай 2+3 программой», только вывести готовый текст и числа), `writeln` (№6 — перенос ставим сами через `'\n'`), условий, циклов. Экранирования кавычек `\"` тоже ещё нет (№6) — внутри текста кавычки не ставим.
- *Словарь:* библиотека, точка входа, аргументы, точка с запятой, управляющая последовательность (`'\n'`), комментарий.

Тема крохотная по инструментам — весь язык здесь это одна команда `console.write`. Зато самое время подружиться со средой, привыкнуть к аккуратности (кавычки, `;`, скобки) и **научиться читать сообщения об ошибках** — этот навык пригодится на каждом следующем уроке. Idyllium ругается по-английски, но по делу; незнакомое сообщение смело отдавайте онлайн-переводчику. **Важно:** поломки ученик находит и чинит сам.

# Блок 1. Первая программа

## Практика с преподавателем

### Задание 1. Здравствуй, мир

По давней традиции первая программа программиста здоровается с миром. Наберите её в точности и запустите (▶ или Ctrl+Enter):

```idyllium
use console;

main() {
    console.write("Привет, мир!", '\n');
}
```

```
Привет, мир!
```

Разберём по кусочкам: `use console;` подключает библиотеку вывода; `main()` — точка входа, отсюда программа стартует; фигурные скобки `{ }` держат её тело; `console.write(...)` печатает то, что в скобках; `'\n'` переводит строку; а `;` завершает команду. Много новых слов — но скоро они станут родными.

### Задание 2. Одна строка или две

`console.write` выводит ровно то, что попросили, — сам переносов не делает. Наберите и запустите:

```idyllium
use console;

main() {
    console.write("Привет");
    console.write("мир");
}
```

```
Приветмир
```

Слова слиплись! Чтобы разнести их по строкам, нужно самим вставить `'\n'`. Добавьте его — `console.write("Привет", '\n');` в первой строке — и запустите снова. Вот он, «полный контроль над выводом», о котором говорил урок.

## Самостоятельная практика

### Задание 3. Представься

Напишите программу, которая здоровается и называет ваше имя — одной строкой.

```
Привет! Меня зовут Мира.
```

### Задание 4. Три строки о себе

Программа выводит три строки: имя, город и любимое занятие — каждую с новой строки. Перенос ставьте сами через `'\n'`.

```
Имя: Мира
Город: Казань
Люблю: рисовать драконов
```

### Задание 5. Выводим числа

Числа пишутся **без** кавычек — так Idyllium отличает их от текста. Выведите пару фактов о себе, вставив числа прямо в `console.write` рядом с текстом.

```
Мне 10 лет
Мой счастливый номер — 7
```

# Блок 2. Переносы, запятые и комментарии

## Практика с преподавателем

### Задание 6. Перенос где угодно

`'\n'` можно ставить в любом месте между аргументами — и текст, и числа в одном вызове. Наберите:

```idyllium
use console;

main() {
    console.write("Считаю до трёх:", '\n', 1, '\n', 2, '\n', 3);
}
```

```
Считаю до трёх:
1
2
3
```

Один вызов `console.write`, а строк на выходе — четыре. `'\n'` срабатывает ровно там, где вы его поставили.

## Самостоятельная практика

### Задание 7. Список покупок

Программа выводит список покупок столбиком — заголовок и три пункта, каждый с новой строки.

```
Список покупок:
- хлеб
- молоко
- яблоки
```

### Задание 8. Ценник

В одном вызове `console.write` соедините текст и число без кавычек — получится ценник.

```
Мороженое — 25 монет
```

### Задание 9. Оставь заметку

Возьмите программу из задания 7 и добавьте перед выводом **комментарий** — строку, начинающуюся с `//`, которая по-человечески поясняет, что делает программа. Запустите и убедитесь: комментарий в вывод не попадает, он только для тех, кто читает код.

```idyllium
    // печатаю список покупок на неделю
    console.write("Список покупок:", '\n');
```

# Блок 3. Учимся читать ошибки

Программисты половину времени не пишут код, а чинят его. Специально сломаем программу несколькими способами — и потренируемся понимать, на что жалуется компилятор. Сообщения не заучивайте: читайте (при нужде — через переводчик) и исправляйте.

### Задание 10. Потерянная точка с запятой

Её забывает рано или поздно каждый. Наберите код, «случайно» пропустив `;` в первой команде:

```idyllium
use console;

main() {
    console.write("Раз", '\n')
    console.write("Два", '\n');
}
```

Запустите. Хитрость: компилятор укажет на **строку ниже** — ту, что выглядит совершенно нормальной. А пропажа-то строкой выше! Запомните этот фокус: жалуется на нормальную строку — загляните на предыдущую. Верните `;` и убедитесь, что всё заработало.

### Задание 11. Забытая библиотека

Уберите из рабочей программы самую первую строку — `use console;` — и запустите:

```idyllium
main() {
    console.write("Привет", '\n');
}
```

Прочитайте отказ. Без подключённой библиотеки команда `console.write` языку незнакома — он прямо подсказывает, чего не хватает. Верните строку на место.

### Задание 12. Текст без кавычек

Выведите слово, «забыв» надеть на него кавычки:

```idyllium
    console.write(Привет, '\n');
```

Запустите и прочитайте замечание. Без кавычек Idyllium думает, что `Привет` — это чьё-то имя (переменная), а такого он не знает. Кавычки — это и есть разница между «выведи текст Привет» и «выведи то, что лежит в Привет». Наденьте кавычки — и порядок.

### Задание 13. Незакрытая скобка

Сотрите закрывающую фигурную скобку `}` в конце программы и запустите. Прочитайте, чего ждёт компилятор. Скобки `{ }` ходят парами: открыл — закрой. Верните `}` и проверьте.

> Кстати, Idyllium различает большие и маленькие буквы: `console` и `Console`, `main` и `Main` для него — разные слова. Наберёте с заглавной — получите такой же отказ «не знаю такого». Проверьте на досуге и запомните: пишем ровно так, как в примерах.

# Блок 4. Со звёздочкой

### Задание 14 ⭐. Нарисуй ёлку

Раз уж мы умеем печатать текст построчно — нарисуем картинку из символов! Соберите из звёздочек, пробелов и палочки маленькую ёлку. Каждая строка — свой `console.write` с `'\n'` в конце.

```
  *  
 *** 
*****
  |  
```

Придумайте свой рисунок: домик, кораблик, мордочку кота. Главное — следите за пробелами в начале строк, они тоже часть картинки. (Только без наклонной черты `\` внутри текста — с ней познакомимся позже.)

### Минутка из внешнего мира. «Привет, мир» на других языках

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Традиция начинать с «Hello, World!» есть во всех языках — а вот команда вывода у каждого своя. Вот как та же первая программа звучит у соседей:
- **Python:** `print("Hello, World!")`
- **JavaScript:** `console.log("Hello, World!")` — почти как у нас, даже `console` на месте!
- **C++:** `std::cout << "Hello, World!";`
- **Java:** `System.out.println("Hello, World!");`

У Idyllium это `console.write("Hello, World!", '\n');`. Присмотритесь: JavaScript нам почти родня (тоже `console`), а `println` в Java уже сам добавляет перенос строки — то, что у нас пока делает `'\n'` (до `writeln` доберёмся в теме про улучшенный вывод). Языков много, а идея одна: скажи компьютеру, что напечатать, — и он напечатает.

- «числа без кавычек» (з.5) обыграть устно: спросить, что выведет `console.write("2 + 2 = ", 4)` — и почему `4` мы написали сами, а не поручили посчитать (арифметику программа освоит только на уроке №5);
- список (з.7) переписать так, чтобы весь вывод уместился в **один** `console.write` с несколькими `'\n'` внутри, — и сравнить с версией из нескольких команд: обе верны, а какая читается легче?

«Битый код / эксперименты» здесь — задания 10–13: во всех ученик сам ломает программу и учится **читать сообщение об ошибке**, а это главный практический навык темы (наравне с умением вообще запустить программу). Формулировки заданий держим короткими и ободряющими: для многих детей это самый первый код в жизни, и важно, чтобы поломки воспринимались как забавные опыты, а не провалы.
