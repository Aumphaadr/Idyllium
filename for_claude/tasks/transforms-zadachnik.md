# Задачник: Преобразования данных

Урок №7 раздела «Консоль». Составлен 2026-07-31 по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод» (число после двоеточия — ввод пользователя).

**Для преподавателя.**
- *Доступно:* всё из уроков 1–6 — переменные, ввод (`get_int/get_float/get_string`), арифметика (`+ - * /`, `div`, `mod`), `console.writeln` и ANSI-цвета (`"\e[..m"`, сброс `"\e[0m"`, коды 30–37 из урока №6); из новой темы — `to_string(число)` (число → строка), `to_int(строка)` и `to_float(строка)` (строка → число), склейка строк через `+` (конкатенация). Ключевая идея: **преобразования всегда явные** — язык не смешивает текст и числа сам.
- *Нельзя (рано):* `if`/условия (№9 — «проверить, число ли в строке» пока нельзя; негодную строку просто **наблюдаем**, как ломается), `math.*` (№8), `random` (№11), циклов (№13), методов строк (`substring` и т.п. — №21). `is_int()`-проверок тоже ещё нет.
- *Словарь:* преобразование типов, конкатенация (склеивание), явное преобразование, ошибка выполнения (runtime error).

Тема отвечает на вопрос «а как же всё-таки соединить число и текст, если язык их не смешивает?». Ответ — три честные функции-переводчика. Практикум: `to_string` (число→текст) → `to_int`/`to_float` (текст→число) → динамическая сборка строк с красками → звёздочки. **Важно:** поломки ученик открывает сам; проверить ввод условием мы ещё не умеем — только смотреть, как язык честно спотыкается.

# Блок 1. `to_string`: число превращаем в текст

## Практика с преподавателем

### Задание 1. Один плюс, два смысла

Знак `+` ведёт себя по-разному с числами и со строками. Наберите:

```idyllium
use console;

main() {
    int NA = 20;
    int NB = 30;
    console.writeln("Числовая сумма: ", NA + NB);
    console.writeln("Строковая сумма: ", to_string(NA) + to_string(NB));
}
```

```
Числовая сумма: 50
Строковая сумма: 2030
```

`20 + 30` для чисел — это сложение, `50`. А `to_string` превратил числа в строки `"20"` и `"30"`, и для строк `+` означает уже **склейку** (конкатенацию): `"20" + "30"` = `"2030"`. Одни данные, один знак — а результат разный. `to_string` даёт вам контроль, как трактовать данные: как числа или как текст.

### Задание 2. Собрать одну строку

Иногда нужно не просто вывести, а **склеить** текст и число в одну строку-значение. Напрямую нельзя — язык откажется соединять текст и число. Спасает `to_string`. Наберите:

```idyllium
use console;

main() {
    int level = 5;
    string label = "Уровень " + to_string(level);
    console.writeln(label);
}
```

```
Уровень 5
```

Число `5` стало строкой `"5"` и приклеилось к `"Уровень "`. Теперь `label` — цельная строка, её можно хранить, склеивать дальше, красить.

## Самостоятельная практика

### Задание 3. Игровой ник

Программа собирает игровой ник из прозвища и номера: спрашивает прозвище (строкой) и номер (числом), склеивает их в одну строку и выводит. Номер — число, поэтому без `to_string` не склеить.

```
Прозвище: Дракон
Номер: 42
Твой ник: Дракон42
```

### Задание 4. Штрихкод

Программа собирает артикул товара: спрашивает букву-категорию (строка) и три числа (код склада, полку, место), склеивает всё в одну строку через `to_string` и выводит.

```
Категория: A
Склад: 7
Полка: 12
Место: 3
Артикул: A-7-12-3
```

### Задание 5. Забыли перевести

Поставьте опыт. Заведите число-счёт и попробуйте склеить его с текстом **напрямую**, без `to_string`:

```idyllium
    int score = 100;
    string msg = "Очки: " + score;
```

Запустите — программа откажется ещё до старта. Прочитайте замечание: склеивать текст и число напрямую нельзя. Почините — оберните `score` в `to_string(...)` — и всё соберётся. Запомните: хочешь число внутри строки — переведи его явно.

# Блок 2. `to_int` и `to_float`: текст превращаем в число

Обратная дорога: если число записано **в виде текста** (строкой), посчитать с ним нельзя, пока не переведёшь обратно в число. Для этого — `to_int` (в целое) и `to_float` (в дробное).

## Практика с преподавателем

### Задание 6. Из текста в число

Наберите:

```idyllium
use console;

main() {
    int n = to_int("345");
    console.writeln("Число плюс пять: ", n + 5);

    float x = to_float("1.6");
    console.writeln("Дробь плюс один: ", x + 1);
}
```

```
Число плюс пять: 350
Дробь плюс один: 2.6
```

`to_int("345")` породил настоящее число `345` — и оно сразу пошло в арифметику. `to_float("1.6")` сделал то же с дробным. Кавычки исчезли, осталось число.

## Самостоятельная практика

### Задание 7. Рекорд из СМС

Друг прислал СМС-кой свой рекорд в игре, а СМС — это всегда **текст**. Программа читает рекорд через `get_string` (нарочно — строкой!), переводит в число через `to_int` и прибавляет 50 бонусных очков за ежедневный вход.

```
Рекорд из СМС: 250
С бонусом за вход: 300
```

### Задание 8. Цена с сайта

Цену товара скопировали с сайта — а всё, что копируется, приходит текстом. Программа читает её через `get_string`, переводит в `float` через `to_float` и считает стоимость двух таких товаров.

```
Цена, скопированная с сайта: 19.99
Два товара обойдутся в 39.98 монет.
```

### Задание 9. Склеить или сложить

Программа спрашивает два числа, но читает оба **нарочно строками** (`get_string`) — и показывает два действия рядом: сначала склеивает их знаком `+` как строки, потом переводит обе в числа через `to_int` и складывает. Запустите с разными парами и сравните результаты.

```
Первое число: 20
Второе число: 30
Склейка строк: 2030
Сумма чисел: 50
```

Один и тот же `+`: для строк — склейка, а после `to_int` — уже настоящее сложение. Вот зачем нужны явные преобразования.

### Задание 10. Число, которого нет

Функции-переводчики честны: если в строке нет числа, они не выдумывают его, а честно останавливаются. Проверьте:

```idyllium
    int n = to_int("десять");
    console.writeln(n);
```

Запустите и прочитайте ошибку выполнения. Слово «десять» — это не цифры `10`, и `to_int` отказывается гадать. (Проверить заранее, число ли в строке, мы пока не умеем — этому научит урок про условия. Сейчас просто наблюдаем, как язык честно спотыкается.)

### Задание 11. Дробь в целую дверь

Ещё опыт на строгость. Попробуйте перевести строку с точкой через `to_int`:

```idyllium
    int n = to_int("3.14");
```

Запустите. `to_int` ждёт **целое**, а `"3.14"` — дробное, и он отказывается. Почините двумя способами и сравните: либо возьмите строку без точки (`"3"`), либо, если дробь нужна по-настоящему, переводите через `to_float`. Разным числам — разные переводчики.

# Блок 3. Собираем строки динамически

Самая вкусная сила преобразований — собирать строки, которых заранее не существовало. Например, код цвета из урока про краски: сам код — число, а управляющая последовательность — строка. Склеить их поможет `to_string`.

## Практика с преподавателем

### Задание 12. Краска по выбору

Соберём код цвета на лету. Коды цветов: 31 — красный, 32 — зелёный, 33 — жёлтый, 34 — синий. Наберите:

```idyllium
use console;

main() {
    console.write("Выберите цвет (1 красный, 2 зелёный, 3 жёлтый, 4 синий): ");
    int choice = console.get_int();
    int code = choice + 30;
    string seq = "\e[" + to_string(code) + "m";
    console.writeln(seq, "Покрашено!", "\e[0m");
}
```

```
Выберите цвет (1 красный, 2 зелёный, 3 жёлтый, 4 синий): 2
Покрашено!      (зелёными буквами)
```

Пользователь выбрал `2`, программа прибавила 30 → код `32` (зелёный), `to_string` сделал из него строку `"32"`, та склеилась между `"\e["` и `"m"` — вышла готовая последовательность `"\e[32m"`. Без `to_string` так собрать было бы нельзя. И не забудьте `"\e[0m"` в конце — сброс, иначе цвет «потечёт» дальше.

## Самостоятельная практика

### Задание 13. Прямой код цвета

Теперь без арифметики: программа спрашивает код цвета сразу (число от 31 до 36), собирает из него последовательность `"\e[" + to_string(код) + "m"` и печатает этим цветом слово «Радуга».

```
Код цвета (31-36): 35
Радуга      (фиолетовыми буквами)
```

### Задание 14. Цветной ярлык

Программа спрашивает название команды (строка) и её номер (число), а потом печатает ярлык вида «Команда №N: имя» — жёлтым цветом (код 33). Здесь пригодятся сразу оба приёма: `to_string` для номера в тексте и готовая строка цвета.

```
Название команды: Молнии
Номер команды: 7
Команда №7: Молнии      (жёлтыми буквами)
```

# Блок 4. Со звёздочкой

### Задание 15 ⭐. Почему 5 и 3 дают 53

Загадка на понимание. Как думаете, что выведет эта строка — `8` или `53`?

```idyllium
    console.writeln(to_string(5) + to_string(3));
```

Запустите и объясните результат. Числа `5` и `3` мы **сначала** превратили в строки `"5"` и `"3"`, а строки `+` не складывает, а склеивает. Чтобы получить `8`, преобразовывать не нужно вовсе — просто `5 + 3`. Мораль: `to_string` меняет не только вид числа, но и смысл знака `+`.

### Задание 16 ⭐. Туда и обратно

Программа спрашивает число, превращает его в строку через `to_string`, приклеивает к ней восклицательный знак (`"!"`), выводит эту «украшенную» строку, а затем переводит **исходное** число обратно… впрочем, проверьте сами, что будет, если к «числу с восклицательным знаком» применить `to_int`. Сделайте вывод, почему украшенную строку числом уже не вернуть.

```
Введите число: 7
Украшенная строка: 7!
```

### Минутка из внешнего мира. Как это делают в других языках

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

В Idyllium преобразования **явные**: хочешь число в строке — скажи `to_string`, хочешь число из строки — скажи `to_int`. А у соседей по цеху правила разные:
- **Python** строг, как и мы: `"Очки: " + 100` — сразу ошибка, нужно писать `"Очки: " + str(100)` (это их `to_string`), а обратно — `int("100")`;
- **JavaScript** наоборот, чересчур покладист: `"Очки: " + 100` он молча превратит в `"Очки: 100"`, но за эту доброту берёт коварством — `"5" + 3` даёт `"53"` (склейка!), а `"5" - 3` вдруг `2` (вычитание чисел). Угадай, что имелось в виду!
- **C++** требует особых приёмов (`std::to_string`, `std::stoi`).

Idyllium выбрал ясность Python: пусть на одну функцию больше, зато никаких «молчаливых» превращений, из-за которых `"5" + 3` внезапно оказывается текстом. Вы всегда видите, где число становится текстом и наоборот.
