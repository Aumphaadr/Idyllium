# Задачник: Случайные числа

Урок №11 раздела «Консоль». Составлен 2026-07-30, доработан по замечаниям владельца проекта (минимум спойлеров, покрытие float, «математика над случайностью», лексические таблицы, звёздочки, разговорный тон). Основан на [лестнице навыков](../ladder/console-skill-ladder.md) и [критериях заданий](../reports/task-design-criteria.md). Все решения и образцы прогнаны через компилятор: выводы с сидом — точные, остальные — «например».

**Для преподавателя.** Доступно: переменные, ввод, арифметика (`div`/`mod`), `math.*` (в т.ч. `math.floor(x, знаки)`), `if`/`else` (включая вложенный) и несколько независимых `if`, сравнения, `bool`, короткие формы. Запрещено: `and`/`or`/`not` (№12), циклы (№13), массивы, `else if`, тип `char` в переменных. Инструменты урока: `create_int`, `create_float` (обе границы включительно), `choose_from`, `set_seed`; для звёздочек — `mulberry32`. Словарь: диапазон, границы, сид, воспроизводимость.

20 обязательных заданий + 5 «со звёздочкой». Слабой группе хватит первой половины обеих практик; звёздочки — задел для тех, кому мало. **Важно:** в самих заданиях мы почти нигде не показываем, «что получится», — открытие оставлено ученику. Не подсказывайте раньше времени.

## Практика с преподавателем: часть 1

### Задание 1. Кубик

С этого урока ваша программа умеет удивляться сама себе. Наберите:

```idyllium
use console;
use random;

main() {
    int roll = random.create_int(1, 6);
    console.writeln("Выпало: ", roll);
}
```

Запустите **три раза подряд** — и полюбуйтесь, как одна и та же программа выдаёт разное.

А теперь спор на честность. Ответьте (и проверьте запусками, если хочется поспорить с самим собой):
- Может ли выпасть `1`?
- Может ли выпасть `6`?
- Может ли выпасть `7`?

> Тонкость: у `create_int(min, max)` **обе границы включаются**. Это настоящий шестигранный кубик, а не какой-то жульнический пятигранный.

### Задание 2. Кубик героя

В настолках судьбу героев решают кубиком на двадцать граней. Переделайте программу под бросок от 1 до 20 и покидайте несколько раз. Выпадет ли заветная 20 — критический успех?

### Задание 3. Сломаем генератор

Программисты часто узнают правила, нарочно всё ломая. Давайте сломаем: попросим число «от 10 до 1», задом наперёд.

```idyllium
use console;
use random;

main() {
    int roll = random.create_int(10, 1);
    console.writeln(roll);
}
```

Запустите и гляньте, что выйдет. Наткнётесь на что-то непонятное — не пугайтесь: Idyllium ругается по-английски, но по-человечески, без шифров. Скормите сообщение онлайн-переводчику и узнайте, о чём он вас предупреждает. Разобрались — верните границы на место и убедитесь, что программа снова ожила.

### Задание 4. Сундук с монетами

Герой откинул крышку сундука — а внутри звенит случайное богатство, от 50 до 200 монет. Напишите программу, которая объявляет добычу:

```
В сундуке звенят 137 монет!
```

Откройте сундук трижды: суммы разные, но всегда где-то между 50 и 200. Жадничать генератор не даёт.

### Задание 5. Орёл или решка

Программа подбрасывает монетку — разыгрывает число 0 или 1. Выпал 0 — «Орёл!», выпала 1 — «Решка!».

```
Орёл!
```

```
Решка!
```

Запускайте, пока не поймаете оба варианта. Как думаете, что выпадает чаще — орёл или решка? Проверьте свою догадку десятком запусков.

### Задание 6. Вариант на контрольной

Знакомая с первого класса драма: учитель раздаёт варианты контрольной, и вся надежда — на жребий. Пусть программа честно его бросит, вытянув букву варианта из строки `"АБВГ"`:

```
Твой вариант: Б
```

> `random.choose_from("АБВГ")` возвращает один случайный символ — суньте его прямо в `console.writeln()`, как в уроке.

А теперь фокус: эту программу запускают **двое соседей по парте**.
- Выпал одинаковый вариант — повезло, можно потихоньку свериться (только чтоб учитель не заметил).
- Выпали разные — увы, включаем собственную голову.

Запустите вместе с соседом. Часто ли совпадает? Прикиньте на глаз: из скольких вариантов тянем и велик ли шанс на «двойника».

### Задание 7. Критический удар

Меч героя бьёт со случайной силой от 10 до 20. Если урон вышел **не меньше** 18 — это критический удар, и программа гордо объявляет о нём отдельной строкой. Обычный удар — программа показывает только урон и про крит помалкивает.

```
Урон: 19
КРИТИЧЕСКИЙ УДАР!
```

```
Урон: 12
```

Поймайте запусками оба случая. Крит выпадает нечасто — так и задумано: посчитайте, сколько значений из диапазона 10–20 дотягивают до крита.

### Задание 8. Конфеты поровну

Бабушка принесла пакет конфет и хочет разделить их **поровну** между двумя внуками. Значит, конфет обязано быть чётное число — иначе будет обида и слёзы. Но сколько именно их в пакете — сюрприз.

Хитрость на будущее: чтобы случайное число всегда было чётным, разыграйте половину (от 0 до 50) и умножьте на 2.

```
В пакете 46 конфет — по 23 каждому!
```

Программа показывает и общее число, и долю каждого. Проверьте запусками: нечётного числа конфет не бывает никогда, а «каждому» всегда делится ровно, без обиженных.

> Это первый приём **математики над случайностью**: генератор даёт грубую заготовку, а арифметика придаёт ей нужную форму. Дальше таких фокусов будет ещё.

### Задание 9. Скидка дня

В лавке волшебных товаров скидка меняется каждый день — от 5 до 30 процентов. Плащ-невидимка стоит 800 монет. Программа разыгрывает сегодняшнюю скидку и считает цену. Проценты удобно брать целочисленно: `div(price * discount, 100)`.

```
Скидка дня: 13%
Плащ-невидимка сегодня стоит: 696 монет
```

Себя проверить легко: при скидке 13% должно выйти ровно 696. Погоняйте несколько дней — дешевле 560 монет (это скидка 30%) плащ не подешевеет.

### Задание 10. Намайнил биткоинов

Слыхали про криптовалюту? Биткоин — это цифровые монеты, которые живут только внутри компьютеров, а зарабатывают их «майнингом»: компьютер долго считает и время от времени выдаёт немного монет. Причём биткоины дробные — их считают с точкой.

До сих пор мы разыгрывали целые числа. Но у `create_int` есть дробный близнец — `random.create_float(min, max)`, и назван он так похоже не случайно: работает точно так же, только выдаёт число с точкой.

Пусть ваш компьютер за ночь намайнит от 0 до 10 биткоинов. Сырое число вроде `7.38104529` показывать не будем — оставим два знака после точки через `math.floor(добыча, 2)`:

```
За ночь намайнено: 7.38 биткоинов
```

Проверьте на глаз: `math.floor(x, 2)` отрезает всё после второго знака, добыча всегда с точкой и всегда от 0 до 10.

> Крошка на будущее: у настоящего биткоина аж **восемь** знаков после точки — самая мелкая долька называется «сатоши». Захотите — попробуйте `math.floor(добыча, 8)`.

### Задание 11. Куда упадёт метеорит

Игровое поле — сетка 10 на 10. Метеорит бьёт в случайную клетку: разыграйте столбец и строку, оба от 1 до 10, и аккуратно объявите точку удара.

```
Метеорит упал в клетку (8, 9)
```

Покидайте камни с неба несколько раз — метеорит должен уметь угодить в любой уголок поля, от (1, 1) до (10, 10).

### Задание 12. Тренажёр таблицы умножения

Сделаем программу-учителя. Она разыгрывает два числа от 2 до 9, спрашивает пример и ждёт ответа. Угадали произведение — хвалит; ошиблись — показывает правильный ответ (и, может, слегка подтрунивает).

```
Сколько будет 7 x 8?
Введите ответ: 56
Верно! Таблица умножения дрожит от страха.
```

```
Сколько будет 9 x 2?
Введите ответ: 20
Не совсем. Правильный ответ: 18
```

Проверьте обе ветки: раз ответьте верно, раз — нарочно мимо. Реплики придумайте свои — программа-персонаж скучной быть не должна.

### Задание 13. Капризный синоптик

Программа предсказывает завтрашнюю температуру — **целое** число от −10 до +25. Синоптик у нас ленивый и комментирует только крайности, двумя **независимыми** проверками:
- не больше 0 — добавляет «Надевай шубу!»;
- не меньше 20 — добавляет «Можно в футболке!».

Если погода так себе, посередине, — синоптик молчит, выводится только число.

```
Завтра будет -3 градусов
Надевай шубу!
```

```
Завтра будет 12 градусов
```

Гоняйте прогноз, пока не поймаете все три настроения синоптика.

### Задание 14. Заклинание повторяемости

У «случайности» в компьютере есть тайна: её можно вызвать заново, слово в слово. Наберите:

```idyllium
use console;
use random;

main() {
    random.set_seed(2026);
    console.writeln(random.create_int(1, 100));
    console.writeln(random.create_int(1, 100));
    console.writeln(random.create_int(1, 100));
}
```

Запустите **дважды** — и оба раза выпадет одна и та же тройка чисел. Совпадение? Не совпадение.

```
3
5
4
```

Теперь сотрите строку с `set_seed` и запустите ещё дважды — числа снова разбежались кто куда. Верните строку, но поставьте вместо `2026` свой год рождения: тройка сменится на новую — и опять будет повторяться от запуска к запуску.

> Это число-заклинание и есть **сид**: из него разворачивается вся «случайная» последовательность. Одинаковый сид — одинаковая судьба.

### Задание 15. Код мира

Программа спрашивает у игрока код мира (целое число), ставит его сидом и разыгрывает три параметра: высоту гор (80–250 м), глубину пещер (10–60 м) и число деревень (0–5).

```
Введите код мира: 42

Глубина пещер: 14 м
```

Самое вкусное — проверка. Введите код `42` и сверьтесь с образцом выше (должно совпасть до метра!). А потом обменяйтесь кодами с соседом: у одинаковых кодов обязаны родиться одинаковые миры. Не родились — ищите, где потерялся `set_seed`.

### Задание 22 ⭐. Загадочный ценник

### Задание 23 ⭐. Точность по заказу

`math.floor(x, знаки)` умеет отрезать не только два знака, а сколько закажете. Исследуйте на воспроизводимом примере:

```idyllium
use console;
use random;
use math;

main() {
    random.set_seed(3);
    float raw = random.create_float(0.0, 100.0);
    console.writeln("сырое:  ", raw);
    console.writeln("0 знаков: ", math.floor(raw, 0));
    console.writeln("1 знак:   ", math.floor(raw, 1));
    console.writeln("2 знака:  ", math.floor(raw, 2));
}
```

Благодаря сиду вы увидите ровно это:

```
сырое:  23.72306302
0 знаков: 23
1 знак:   23.7
2 знака:  23.72
```

Теперь прикиньте, где какая точность к месту: сколько знаков нужно у цены в рублях? у показаний термометра? у счётчика лайков (там дробей не бывает вовсе)? Подберите `math.floor` под каждый случай — и поймёте, что «сколько знаков после точки» решает не компьютер, а вы.

### Задание 24 ⭐. Укрощение дикого генератора

В Idyllium живёт ещё один генератор — дикий зверь `random.mulberry32()`. Он выдаёт огромное целое **от 0 до 4294967295** и никаких «от и до» не принимает. Как из такого чудища добыть, скажем, число от 70 до 73? Двумя ударами математики: остаток от деления на 4 даёт 0, 1, 2 или 3, а прибавив 70, сдвигаем этот кусочек куда надо.

```idyllium
use console;
use random;

main() {
    int raw = random.mulberry32();
    console.writeln("Дикое число: ", raw);
    console.writeln("После укрощения: ", mod(raw, 4) + 70);
}
```

Запустите несколько раз: «дикое число» каждый раз новое и гигантское, а «после укрощения» — всегда одно из 70, 71, 72, 73.

```
Дикое число: 1781839555
После укрощения: 73
```

```
Дикое число: 1967120014
После укрощения: 72
```

**А теперь — зачем это вообще знать.** Во «взрослом» языке C++ случайные числа десятилетиями добывают ровно так. Там есть функция `rand()` — почти двойник `mulberry32()`: тоже выдаёт большое число без всяких границ (обычно от 0 до 2147483647). Чтобы получить число от 70 до 73, программист на C++ пишет:

```cpp
rand() % 4 + 70
```

где `% 4` — это наш `mod(…, 4)`, а `+ 70` — сдвиг. Один в один то, что вы только что проделали руками!

Сравните два мира:

```text
C++:       int x = rand() % 4 + 70;              // укрощаем дикую rand()
Idyllium:  int x = random.create_int(70, 73);    // просто говорим, чего хотим
```

`create_int(70, 73)` делает ту же работу — но за вас, и читается как человеческая просьба. Приём с `mod` полезно **понимать** (вдруг встретится чужой код на C++), но в Idyllium так мучиться не нужно: язык уже обо всём позаботился.
