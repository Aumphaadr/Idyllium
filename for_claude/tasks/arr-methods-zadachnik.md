### Задание 1. Три вопроса к инвентарю

Есть ли Ключ? Где лежит Факел? Сколько факелов в запасе? Наберите:

```idyllium
use console;

main() {
    dyn_array<string> inv = ["Кирка", "Факел", "Ключ", "Факел"];
    console.writeln(inv.contains("Ключ"));
    console.writeln(inv.find("Факел"));
    console.writeln(inv.count("Факел"));
}
```

```

1
2
```

`contains` отвечает «да/нет», `find` — «где» (индекс **первого** вхождения, или −1, если нет вовсе), `count` — «сколько». Помните, как мы искали значение циклом с переменной-находкой? Вот куда переехал тот цикл.

### Задание 2. Навести порядок

Наберите и следите за массивом до и после:

```idyllium
use console;

main() {
    dyn_array<int> scores = [90, 30, 70, 10, 50];
    scores.sort();
    console.writeln(scores);
    scores.reverse();
    console.writeln(scores);
}
```

```

[90, 70, 50, 30, 10]
```

Заметьте: `sort` и `reverse` ничего не возвращают — они **переставляют ячейки в самом массиве**. После `sort` порядок по возрастанию, после `reverse` — задом наперёд. А вместе они дают убывание — запомните это комбо.

### Задание 14. Какое я занял место

Жемчужина урока. В таблице — результаты пяти участников, и тут финишируете вы. Наберите:

```idyllium
use console;

main() {
    dyn_array<int> results = [520, 340, 410, 480, 290];
    console.write("Твой результат: ");
    int mine = console.get_int();
    results.add(mine);
    results.sort();
    results.reverse();
    console.writeln("Таблица: ", results);
    console.writeln("Ты занял место №", results.find(mine) + 1);
}
```

```
Твой результат: 430
Таблица: [520, 480, 430, 410, 340, 290]
Ты занял место №3
```

Разберите цепочку: `add` вписал вас в таблицу, `sort` + `reverse` выстроили её от лучшего к худшему, `find` нашёл вашу строчку, а `+ 1` перевёл индекс в человеческий номер места. Четыре метода — и готовый рейтинг, как в настоящей игре.

### Минутка из внешнего мира. Сортировка у соседей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

- В **Python** всё родное: `список.sort()`, `список.reverse()`, `x in список` (наш `contains`), `список.count(x)`. Совпадение почти буквальное.
- В **JavaScript** у `arr.sort()` есть легендарная ловушка: без специальной настройки он сортирует всё **как строки** — и массив `[10, 9, 1]` превращается в `[1, 10, 9]`, потому что «10» по алфавиту раньше «9»! На этом сюрпризе подорвались поколения новичков.
- В **C++** сортировка — это `std::sort(begin, end)` с загадочными «итераторами» на края массива.

Idyllium сортирует честно: числа — как числа, строки — по алфавиту, и никаких настроек. А ещё держите в голове: за одну строчку `sort()` компьютер проделывает громадную работу по перестановке ячеек — как именно он это делает, целая наука, и до неё вы ещё доберётесь.
