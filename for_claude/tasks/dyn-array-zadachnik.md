# Задачник: Динамические массивы

Урок №18 раздела «Консоль». Составлен 2026-07-31 (переработан с явным градиентом сложности) по [лестнице навыков](../ladder/console-skill-ladder.md), [критериям заданий](../reports/task-design-criteria.md) и [методичке Real-IT](../reports/real-it-methodology-extract.md). Все решения и образцы прогнаны через компилятор; задания с вводом дают точный образец «ввод → вывод», со случайностью — помечены «например».

**Для преподавателя.**
- *Доступно:* всё из уроков 1–17 — переменные, ввод, арифметика (`div`/`mod`), `writeln`/цвета, преобразования, `math.*`, `if`/`bool`, инкремент, `random`, логические операции, циклы, `time`, `const`, статические массивы, `char` и `.length` строк; из новой темы — `dyn_array<T>` (пустой или с инициализатором), `add(v)` (в конец), `remove_at(i)` (со сдвигом влево), `resize(n)` (рост → дефолты, ужатие → безвозвратная потеря), свойство `.length`, перебор `for i < arr.length`, любые типы ячеек.
- *Нельзя (рано):* `insert/clear/pop`, `sort/find/contains` (№20 — не давать, хотя рантайм часть уже понимает); `max/min/sum/avg` (№19 — агрегируем циклом вручную); методов строк (№21). Границы прежние: индексы `0..length-1`, выход — runtime error (сам массив НЕ растёт).
- *Градиент сложности.* **Минимальная обвязка** темы — вывод и литералы: `writeln(arr)` печатает массив целиком, так что `add`/`remove_at`/`resize`/`length` наблюдаемы вообще без циклов и ввода. Отсюда строение книги: **блок 1 — атомарные** (только тема + вывод), **блок 2 — полукомплексные** (тема + ровно один старый инструмент), **блоки 3–4 — комплексные** (тема + 2–3 инструмента), **блок 5 — звёздочки** (комбинацию нужно угадать). Слабой группе хватит блоков 1–3; сильная пройдёт всё.
- *Словарь:* динамический массив, добавление, удаление, длина, изменение размера, сдвиг влево, накопление.

Динамический массив — ответ на вопрос «а если размер заранее неизвестен?». Статический был как коробка для яиц: сколько ячеек отлили, столько и есть. Динамический **растёт и сжимается на ходу** — и это открывает две сверхспособности, недоступные раньше: копить данные, пока они идут, и собирать результат, размер которого выяснится только в конце. **Важно:** поломки ученик открывает сам.

# Блок 1. Растущий массив в чистом виде

Здесь — только новая тема и вывод: никаких циклов, ввода и условий. Сначала пощупаем сам инструмент.

## Практика с преподавателем

### Задание 1. Добавить ячейку

Объявляется `dyn_array` почти как обычный массив, только размер нигде не указан — и это не забывчивость. Метод `add(значение)` пристраивает новую ячейку в конец. Наберите:

```idyllium
use console;

main() {
    dyn_array<int> nums = [11, 22, 33];
    nums.add(44);
    nums.add(55);
    console.writeln(nums);
}
```

```
[11, 22, 33, 44, 55]
```

Массив начал с трёх ячеек, а стал с пятью — без переписывания программы. Со статическим так нельзя: там длина отлита намертво.

### Задание 2. Сколько сейчас ячеек

Раз длина всё время меняется, её надо уметь узнавать — свойство `length` (без скобок: читаем состояние, а не приказываем). Наберите:

```idyllium
use console;

main() {
    dyn_array<string> inventory = ["Кирка", "Меч", "Факел"];
    console.writeln("Предметов: ", inventory.length);
    inventory.add("Щит");
    console.writeln("Стало: ", inventory.length);
}
```

```
Предметов: 3
Стало: 4
```

### Задание 3. Выбросить лишнее

Метод `remove_at(индекс)` удаляет ячейку, а всё, что правее, сдвигается влево — дырок не бывает. Наберите:

```idyllium
use console;

main() {
    dyn_array<string> inventory = ["Кирка", "Гниль", "Меч", "Факел"];
    inventory.remove_at(1);
    console.writeln(inventory);
}
```

```
["Кирка", "Меч", "Факел"]
```

Гниль (индекс 1) исчезла, «Меч» и «Факел» сдвинулись на позицию влево.

# Блок 3. Копим неизвестное

Главная сверхспособность. Раньше размер массива нужно было знать заранее — а если гостей придёт неизвестно сколько? Здесь тема встречается сразу с несколькими старыми инструментами: вводом, циклами, условиями.

## Практика с преподавателем

### Задание 16. Собери числа до стопа

Классика: собираем числа, пока пользователь не введёт ноль. Сколько их будет — не знает никто. Наберите:

```idyllium
use console;

main() {
    dyn_array<int> nums;
    console.write("Число (0 — стоп): ");
    int x = console.get_int();
    while (x != 0) {
        nums.add(x);
        console.write("Число (0 — стоп): ");
        x = console.get_int();
    }
    console.writeln("Собрано ", nums.length, " чисел: ", nums);
}
```

```
Число (0 — стоп): 5
Число (0 — стоп): 8
Число (0 — стоп): 3
Число (0 — стоп): 0
Собрано 3 чисел: [5, 8, 3]
```

Ноль — сигнал остановки (сам в массив не попадает). Пустой массив копил числа по одному, пока их подавали, — именно этого статический не умел.

# Блок 4. Фильтруем

Вторая сверхспособность: отобрать из данных только «подходящие», когда заранее неизвестно, сколько их окажется. Решение — пустой массив-результат, куда `add`-ится только прошедшее проверку.

## Практика с преподавателем

### Задание 22. Только пятёрки

Наберите:

```idyllium
use console;

main() {
    dyn_array<int> grades = [5, 3, 5, 4, 5, 2];
    dyn_array<int> fives;
    for (int i = 0; i < grades.length; i += 1) {
        if (grades[i] == 5) {
            fives.add(grades[i]);
        }
    }
    console.writeln("Пятёрок: ", fives.length, " — ", fives);
}
```

```
Пятёрок: 3 — [5, 5, 5]
```

Массив `fives` родился пустым и принимал только то, что прошло проверку. Сколько наберётся — мы узнали лишь в конце, из `length`.

### Минутка из внешнего мира. Как это зовут у соседей

*Это не задание — делать ничего не нужно. Просто любопытное из большого мира, читается за минуту.*

Растущие массивы есть почти везде, только имена разные:
- в **JavaScript** это обычный массив с методом `push()` (добавить) и `splice()` (удалить); длину даёт `.length` — прямо как у нас;
- в **Python** — список (`list`) с методами `append()` и `pop()`, а длину меряют функцией `len(список)`;
- в **C++** это `std::vector` с `push_back()` и `.size()`.

А статический массив из прошлой темы у них тоже есть: в C++ это `std::array`, в старом стиле — обычный `int a[5]`. Idyllium просто дал двум видам ясные имена: `array` — фиксированный, `dyn_array` — растущий. Кстати, наш `dyn_array` умеет пока не всё: вставлять ячейку в середину, чистить массив разом и доставать последнюю ячейку вы освоите в уроке про методы массивов.
